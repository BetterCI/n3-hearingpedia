# 基础词条起草模板

复制下方正文骨架起草，替换全部方括号中的说明文字。模板标题和使用说明不进入正式词条；正文不再重复词条大标题。建议约 2,000 至 4,000 个中文汉字，章节可以合并或改名。填写来源与图源记录时使用配套交稿说明。

**词条信息**：中文名 [填写]；英文名 [填写]；作者 [填写]；摘要 [用一至两句概括]；建议相关词条 [填写]。

## 可复制的正文骨架

```markdown
**[中文术语]**（[英文名称及必要缩写]）是[准确的一般定义]。[1]

[说明在听觉研究或实际聆听中的作用，以及与一个容易混淆的概念的区别。]

## 定义与概念范围

[说明对象、基本分类或关键属性。必要时给简短对照表，不罗列与主题无关的分类。]

## 核心原理

[按过程或变量关系解释核心机制。适用时给一条必要公式，定义变量、单位和条件。]

## 如何测量或分析

[介绍一种代表性方法：研究对象、刺激或输入、任务、指标及其含义。说明最重要的控制条件。]

## 例子与应用

[给一个具体例子、对照或图解，说明它帮助理解什么。教学数字明确标为假设，不冒充实测。]

## 适用边界与常见误读

[说明至少一个影响解释的边界或误读，保留人群、任务和技术条件。]

## 相关概念

[推荐二至四个相关概念，并简述它们与本词条的联系。]
```

## 最低完成条件

定义、核心原理、方法或观察依据、例子、应用边界均有实质内容，关键论断有来源。删除模板说明与占位符后，随正文提交来源表、实际图片或配图计划、交稿说明。新稿保留 Draft。
