# n³ Hearingpedia 词条编写规范

协作版 v0.1，2026 年 10 月 9 日。

本规范供参与 n³ Hearingpedia 的作者和审阅者使用，适用于独立撰写及 AI 辅助生成的新词条。词条以中文解释听觉科学概念，帮助学生、研究者和专业读者建立理解、查找证据并连接相关知识。基础词条提供完整的入门解释；深度词条进一步支持论文阅读、方法选择和结果解释。两类词条采用相同的科学准确性与来源要求。

“必须”表示交稿前应满足的要求；“建议”用于规划篇幅与呈现，可以根据主题调整。字数、章节数、图数和文献数量均为建议范围，不作为质量评级或机械验收门槛。

## 使用本规范

先确认主题与已有词条是否重叠，再选基础或深度版本。复制对应模板，结合提供的材料撰写，最后按交稿说明整理证据与图片。

- [基础词条模板](basic-entry-template.md)
- [深度词条模板](in-depth-entry-template.md)
- [AI 辅助撰写提示词](ai-writing-prompts.md)
- [交稿说明模板](submission-template.md)
- [网站接入说明](technical-integration.md)

作者可以先提交 Markdown、Word 或纯文本正文及配套材料，由维护者转换为网站格式。直接向仓库贡献的作者另按接入说明填写元数据、参考注册表和知识关系。

## 基础词条与深度词条的区别

| 项目 | 基础词条 | 深度词条 |
| --- | --- | --- |
| 阅读目标 | 理解定义、核心原理、用途与常见误读 | 理解机制、研究范式、方法选择、结果与证据边界 |
| 建议篇幅 | 约 2,000 至 4,000 个中文汉字 | 约 6,000 至 10,000 个中文汉字 |
| 建议章节 | 约 4 至 8 个一级章节 | 约 8 至 12 个一级章节 |
| 机制解释 | 讲清主要过程或变量关系 | 说明不同机制或模型、关键参数及各自解释范围 |
| 方法内容 | 介绍代表性测量或分析方式 | 解释刺激、人群、任务、操作流程、指标、控制与限制 |
| 例子与比较 | 至少一个有助理解的例子、对照或图解 | 至少一个展开的分析例子或研究设计比较，必要时含计算 |
| 建议配图 | 约 1 至 2 张，按需要配置 | 约 3 至 5 张，复杂主题可增加 |
| 建议来源规模 | 约 3 至 8 项关键来源 | 约 15 至 30 项，按论断覆盖调整 |
| 进展与争议 | 简要说明与定义直接有关的限制 | 结合经典证据和后续研究解释进展、分歧及未解决问题 |
| 网站深度字段 | `depth: standard`，页面显示“基础词条” | `depth: in-depth`，页面显示“深度词条” |

篇幅按正文及图注大致估算，不计元数据和文献列表。两类词条都必须覆盖定义、原理、方法或观察依据、应用和边界；内容可以分章，也可以合并。狭窄主题可以较短，系统性主题可以较长。基础词条也可以包含必要公式；深度词条无需为增加难度而添加数学推导。

研究人物词条也按内容的解释范围标注。以生平、代表工作简介和阅读线索为主的版本采用“基础词条”；若进一步展开代表性原始研究的方法、结果或图表分析，并联系后续研究解释贡献与证据边界，可标为“深度词条”。人物的重要性、头衔、照片数量和篇幅不决定这一标注。

## 两类词条共同遵守的写作要求

### 定义与导言

正文以“**中文术语**（英文名称，必要时附缩写）是……”起笔，直接定义对象。用两至三段交代作用、研究背景及与相邻概念的区别，不另设“概述”标题。不能只用应用实例替代定义，也不能把一种特定实现的条件写成概念的一般定义。

标题与术语保持统一，英文缩写首次出现时解释。项目采用“频位映射关系”对应 Tonotopy，“普通话汉语声调”对应 Mandarin lexical tone；Temporal 在信号表征与编码中优先译为“时域”，实际时间差、延迟和时长按其含义表述。

### 内容组织与语言

一个词条围绕一个概念展开，并明确范围。优先用自然段解释因果、过程和条件；表格用于方案或指标对照，列表用于步骤和并列要素。一级标题使用 `##`，二级标题使用 `###`，按内容命名，不预先制造空栏目。

用具体例子帮助读者理解，避免宣传式表述和无依据的“最佳”“突破”“显著提高”。不按固定模板反复罗列“意义、优势、挑战”；研究沿革应说明研究改变了什么认识，作者年份只承担来源定位。

### 变量与科学边界

公式必须说明用途、变量、单位、条件和来源。数值必须带单位或明确无量纲，并保留材料、人群、任务、测量位置或设备版本等决定其意义的条件。

区分声学信号、神经表征与行为结果；区分计算模型、动物、正常听力模拟与真实患者研究。声码器结果不能直接写成植入者疗效，指标预测不能冒充行为测量，教学参数不能冒充设备推荐设置。对于尚有分歧的解释，应说明支持条件和可替代解释。

## 基础词条的内容要求

基础词条必须形成自足的解释。读者无需跳转多个词条，便能理解概念的基本含义、核心原理和主要用途。

1. **定义与区别。** 说明对象及最容易混淆的相邻概念。
2. **核心原理。** 解释一个主要过程、关系或代表性现象；必要公式以最少数量表达。
3. **方法与指标。** 介绍如何观察、测量或分析，指出所得结果是什么；纯理论概念可说明计算或验证方式。
4. **例子与应用。** 至少给一个具体例子、对照或图解，连接听觉研究、设备或实际聆听。
5. **限制与关联。** 指出关键误读和适用边界，推荐二至四个相关概念。

可以不展开完整模型比较、详细实现和广泛研究史。不能省略直接影响理解的条件或以“详见文献”代替核心解释。

## 深度词条的内容要求

深度词条在以上基础上，必须使读者能够理解相关研究怎样获得结论，并评估结果的意义。

1. **机制解释完整。** 连接现象、变量和候选机制；存在多种解释时作有依据的比较，不强行制造争议。
2. **方法可理解。** 至少展开一种代表性范式，说明对象、刺激或输入、任务、输出指标、控制和可能混杂因素。适用时说明版本、参数及复现入口；不要求每篇都提供完整实验操作手册。
3. **分析有实质内容。** 展开一个计算例子、指标比较、图表解读或研究设计对照，明确其数据与假设来源。
4. **证据分层。** 结合经典研究与与主题直接相关的后续工作，说明一致性、分歧和推广范围。
5. **应用与前沿相连。** 解释机制或方法怎样影响研究及实际应用，并提出有证据背景的未解决问题。

感知类词条可以沿“现象—线索—机制—行为任务”展开；生理类沿“结构—过程—功能—测量—损伤”展开；技术类沿“系统—处理—参数—验证—获益”展开。章节按主题调整。

## 文献与引用要求

关键定义、机制、方法、数值及效果论断必须有可核对的来源。优先使用教材、权威综述、原始研究和对应官方方法文档，按所支持的论断选择。新论文补充进展，不能凭单篇研究自动替代已有共识。

每项来源必须记录题名、作者、年份、期刊或出版机构、DOI 或稳定链接，并说明支持的论断及实际访问范围。全文相关段落、摘要、书目信息和方法文档应分别记录；只有书目信息不能支持具体结果。关键方法或数值仅凭摘要无法核实时，应补充材料或删去超出证据的表述。

引文放在相关句子或段落附近，不能只在文末列书目。草稿可用 `[1]` 等编号，交稿时提供对应来源表；直接接入网站时转换为站点引用锚点。预印本标注未同行评审，同一研究的不同版本不当作独立重复证据。

未能核实的来源放入交稿说明，不混入已核实引用。不得虚构作者、DOI、数据、结果或阅读记录。AI 输出不能充当科学来源。

## 配图规范

图必须帮助解释对象、机制、方法或结果，放在相应正文附近。缺少适合配图的内容时，可以用清楚的表格或文字说明；建议图数不构成强制门槛。

| 项目 | 要求或建议 |
| --- | --- |
| 原创曲线与示意 | 优先 SVG，另保留 PNG 预览；提供可编辑源文件或生成代码 |
| 教材或论文原图 | 保留清晰来源图，记录作者、原始图号、来源、许可及修改 |
| 视觉形式 | 白底、少量强调色、统一线型；中文为主要说明语言，多面板用（a）（b）（c） |
| 标注 | 坐标、单位、图例和对象名称准确；不单独依赖颜色区分条件 |
| 尺寸 | 原创 SVG 可按约 1,200 至 1,600 横向坐标设计，纵横比随内容；实际展示文字需清楚 |
| 数据与参数 | 明确实测、文献数据、计算或教学设定，保存影响结果的参数和数据出处 |
| 网页阅读 | 提供替代文本，支持查看原图，检查约 390 像素宽手机视图和桌面视图 |

每张图附完整图注：**图号与短标题、分面内容、关键条件和单位、主要关系、数据或图的性质、边界和来源**。转载许可必须单独核对，论文公开可读不自动意味着图片可自由转载。英文原图可保留，并在图后列关键标签的中文对照。

原创教学图注明具体简化条件，不能仅写一句“示意图”。没有测量依据的曲线、误差线、空间距离或箭头不得暗示实测效果。科学关系图优先使用可检查的绘图工具；AI 生成的解剖或机制插图必须逐项核对结构与标注。

## AI 辅助生成与交付

使用 AI 时，将本规范、相应模板、可访问的文献材料和目标读者一起提供。先形成提纲和论断来源表，再撰写正文。AI 可以帮助解释、组织和生成教学代码；作者负责检查论断、公式、图和引用，并在交稿说明中记录 AI 的实际用途。缺材料时缩小范围或标明待核实，不让 AI 填造细节。

交付正文、来源表、图与图注，以及填写好的交稿说明。原创计算图附参数或脚本；转载图附来源与许可。尚未生成的图用配图计划单独交付，不伪装为已有图片链接。

两类新词条默认 `status: draft`。`depth` 只表示解释范围，审阅状态另行记录。只有实际具名专业审阅完成后，才能记录审阅者与日期；AI 自检、工程检查或作者核验不自动形成专业审阅。

## 交稿前检查

- [ ] 定义准确，术语统一，导言可以独立理解。
- [ ] 已达到所选类型的内容要求，例子与边界具体。
- [ ] 变量、单位、参数和研究对象交代清楚。
- [ ] 重要论断与来源对应，访问范围据实记录，待核实项另列。
- [ ] 图片、图注、数据性质和许可完整，图文一致。
- [ ] 标题、目录、公式、表格及图片适合阅读，模板占位符已替换。
- [ ] 作者与 AI 使用情况清楚，审阅状态真实。
- [ ] 已填写交稿说明；直接提交仓库时已完成接入检查。

不要求非技术合作者运行网站构建。维护者接入后负责分类、参考锚点、知识关系、资源路径和工程验证；科学内容则由作者与专业审阅者核对。
