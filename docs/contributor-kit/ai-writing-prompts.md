# AI 辅助撰写提示词

将本包的编写规范、相应起草模板和实际参考材料一起提供给 AI。以下提示词可直接复制，方括号需替换。只有提示词而未提供材料时，应先收集和核验来源，不能直接生成貌似有依据的完整稿。

## 基础词条提示词

```text
请为 n³ Hearingpedia 撰写基础词条。

主题：[中文名及英文名]
目标读者：初次接触该概念的学生及跨领域专业读者。
范围：[明确对象及范围]
已有材料：[附文献、全文相关段落、摘要或官方方法文档]
相关词条：[附已存在的概念清单，或说明尚未提供]

遵守随附的《n³ Hearingpedia 词条编写规范》与基础词条模板。
建议约 2,000 至 4,000 个中文汉字，以内容完整性为准。

请依次完成：
1. 提出简洁提纲，列出关键论断、对应来源及实际可阅读范围。
2. 根据来源撰写正文，以定义开头，讲清核心原理、代表性方法、一个具体例子、应用和边界。
3. 提供一至两张按需配置的配图计划及拟用图注。
4. 在正文之外提供来源表和待核实项。

正文用自然段连接解释，避免宣传式表述。公式说明变量、单位与条件。
关键论断附近使用编号引用，并确保编号与来源表一致。
不能虚构参考文献、DOI、数据、实验结果、图片或阅读记录。
只阅读摘要时，不扩写摘要无法支持的精确方法或结果。
未提供的相关词条可以列为建议，不能编造已存在的链接。
没有实际生成或取得的图，只提供计划，不声称图片已经存在。
证据不足时缩小表述或放入待核实项。
词条审阅状态为 Draft。
```

## 深度词条提示词

```text
请为 n³ Hearingpedia 撰写深度词条。

主题：[中文名及英文名]
目标读者：需要阅读论文、理解方法和解释结果的学生与研究者。
范围：[明确对象及范围]
已有材料：[附经典来源、相关综述、原始研究及方法资料]
相关词条与实现入口：[附已核实清单，或说明尚未提供]

遵守随附的《n³ Hearingpedia 词条编写规范》与深度词条模板。
建议约 6,000 至 10,000 个中文汉字，按主题组织约八至十二个主要章节。

请依次完成：
1. 提出提纲与论断来源表，区分已核实内容、争议和待补材料。
2. 撰写百科式导言，完整解释定义、现象、机制、方法、应用与边界。
3. 展开至少一种代表性研究范式，交代对象、刺激或输入、任务、流程、指标、控制及替代解释。
4. 展开一个计算例子、图表解读或研究设计比较，说明数据与假设来源。
5. 结合经典与后续研究说明进展及未解决问题。
6. 提供三至五张按需配置的配图计划、拟用图注、来源表与待核实项。

不同证据层次必须分开：声学参数、神经表征、行为结果不能互相替代；计算模型、动物、正常听力模拟和患者研究不能直接互相外推。
公式解释变量、单位和条件；技术参数保留版本与配置。
重要论断附近放编号引用，编号与来源表一致。
不以增加篇幅为由堆叠公式、文献或空章节。
不得虚构 DOI、数据、结果、图片、代码入口或阅读记录。
未取得的全文、图和实现另列待核实，不声称已读、已生成或已复现。
词条审阅状态为 Draft。
```

## 作者核对提示词

```text
请按随附的编写规范检查这篇词条，不直接改动证据含义。
逐项检查定义、范围、机制、方法、变量单位、例子、图文一致性、引用与适用边界。
列出具体问题位置、问题原因和建议改法。
将语言问题、科学论断问题、来源待核实项和工程格式问题分开。
如果没有材料可核对某论断，说明需要什么材料，不声称该论断已经验证。
最后判断它满足基础词条还是深度词条的内容要求，并给出理由。
你的检查是 AI 辅助检查，不自动构成具名专业审阅。
```
