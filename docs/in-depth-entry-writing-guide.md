# 深度词条的早期经验与撰写参照

向合作者提供的基础词条与深度词条要求、起草模板和交稿清单，见[词条编写规范](contributor-kit/README.md)。本文保留早期样本与经验依据。

深度词条面向需要理解研究问题、阅读论文和设计实验的学生及研究者。早期较成熟的词条采用百科式导言，以定义为起点，逐层连接机制、测量、应用和证据边界。后续写作应延续这种解释方式，让读者能够回答“它是什么、怎样起作用、如何研究、结果意味着什么”。

本文以 2026 年 10 月 4 日至 6 日形成的深度词条为参照。历史统计固定到 10 月 6 日提交 `2c0e321`，该版本有 18 个标记为 `in-depth` 的词条；后续更新的词条不混入这组统计。下文分别列出已有形式和建议采用的写作标准。整理日期为 2026 年 10 月 9 日。

## 词条形式

### 导言先建立概念与问题

已有词条通常以 **中文术语**（英文名称，必要时附缩写）开头，直接给定义，接着说明用途及与相邻概念的区别。导言不另设“概述”标题，正文不重复网页自动生成的词条大标题。

人物词条中，外国研究者已有可靠的国内中文译名时，以中文名为标题及首次介绍的主名称，并保留原文姓名。译名依据正式中译本、中文专业文献或机构资料，记录出处；未确认已有译名时采用原文，不自行音译，也不以姓氏译法拼凑中文全名。华裔研究者已有本人中文姓名时直接使用。

建议用两至三段完成入口：第一段说明对象和基本含义，第二段说明听觉研究或日常聆听中的作用，第三段在需要时交代主要解释层次。重要论断从导言开始就应有引用。避免把复杂公式、设备目录或长段研究史放在读者尚未建立概念的位置。

### 信息框保存稳定事实

早期词条通过 `key_facts` 展示性质、关键线索、主要测量或系统组成；部分通过 `illustration` 展示简洁系统图。当前元数据校验要求至少两项关键事实。

建议选择三至五项最有辨识度的事实。会随刺激、任务、设备版本和人群改变的参数应放入有条件说明的正文，避免将某篇论文的数值写成概念的普遍属性。

### 正文分层并随概念调整

一级标题承担主要解释任务，二级标题拆开不同机制、方法和条件。自然段负责解释关系；表格用于比较种类、指标或策略；列表用于步骤和并列项目。公式放在已经说明其用途的位置，并逐项定义变量、单位和适用条件。

| 概念类型 | 建议的内容顺序 | 早期参照 |
| --- | --- | --- |
| 感知功能 | 定义与现象 → 声学线索 → 神经或计算解释 → 行为测量 → 人群差异 → 应用 | 音高感知、言语可懂度 |
| 解剖与生理机制 | 结构与位置 → 物理或生化过程 → 细胞功能 → 神经输出 → 测量 → 损伤后果 | 耳蜗 |
| 信号表征与模型 | 一般定义 → 数学表示 → 提取或计算方法 → 参数影响 → 感知用途 → 解释边界 | 时域包络、时域精细结构、听觉滤波器 |
| 技术与策略 | 系统位置 → 处理流程 → 参数与方案比较 → 验证方法 → 实际获益 → 实现与研究问题 | 助听器、人工耳蜗及其编码策略 |
| 指标或测量 | 对象与定义 → 单位与端点 → 操作流程 → 结果表征 → 混杂因素 → 应用 | 动态范围中的测量与报告部分 |

研究沿革与近期进展可以作为独立章节，也可以放入相应机制或方法中。应说明研究解决了什么、留下什么问题；不以连续罗列作者年份代替解释。参见、参考文献与关系导航复用站点功能，避免重复手工维护。

## 深度应达到什么程度

### 从介绍概念进入可用解释

建议以以下问题验收深度，而不是只检查字数。

| 读者应该能回答的问题 | 词条需要提供的内容 |
| --- | --- |
| 它是什么，与什么容易混淆 | 明确定义、对象范围和相邻概念的区别 |
| 为什么出现这种现象 | 连贯机制、变量关系或候选解释，并保留尚存争议 |
| 实验实际上操纵和测量什么 | 刺激、人群、任务、自变量、因变量、单位及必要控制 |
| 怎样读懂曲线、指标和模型 | 坐标解释、计算条件，以及至少一个有帮助的例子或对照 |
| 结论能推广到哪里 | 对材料、任务、听力状态、模型和设备的适用边界 |
| 如何继续学习或复现 | 相关词条、支持关键论断的来源，适用时给出实现入口 |

成熟的新深度词条可以先按约 6,000 至 10,000 个正文区汉字、8 至 12 个一级章节规划，再依据内容删减或扩展。这是从早期样本归纳的编辑建议，不能用来将篇幅不足或较长的词条直接判定为不合格。

### 保持不同证据层次的区别

早期词条反复保留三类边界，后续应继续执行。

1. **信号、神经与行为。** 能提取周期性，不等于神经有效编码；存在神经响应，不等于听者能利用；正确率提高，也不必然意味着音质或日常体验改善。
2. **模型、模拟与实际使用。** 正常听力声码器模拟、计算模型、动物研究和真实植入者研究各有适用对象，不能直接互相替代。
3. **参数与测量条件。** 分析带数、电极数与有效信息通道数不同；声学与电刺激的单位不同；阈值、函数斜率和上限表现不同。

例如，“包络负责言语、精细结构负责音乐”过度压缩了条件。包络和精细结构词条通过分解方法、听觉滤波、再生包络及具体任务说明哪些信息实际可用。这种解释比追加术语或公式更能构成深度。

### 引用支持具体论断

基础定义保留经典证据，机制和方法引用对应研究，进展补充与主题直接相关的新工作。参考数量服从论断覆盖，避免为了增加来源而添加无关研究。

站点通过参考注册表记录 `access` 和 `supports`，分别说明实际访问范围和引用用途。书目信息核验、摘要阅读、全文相关段落阅读应据实区分。预印本保留未同行评审标识；官方方法文档可以支持实现和规格，不能代替生理或临床效果证据。

## 配图内容与视觉形式

### 每张图承担一个解释任务

早期图示大致分为场景、结构、机制、方法、结果解释和设备应用。音高词条从日常场景进入缺失基频、谐波可分辨性与实验任务；助听器词条按处理链、压缩、方向性、延迟和真耳验证配置五张图。图的位置与相应解释紧邻。

建议普通深度词条先规划三至五张图：一张建立直观对象，一至两张说明核心机制，一张解释测量或结果；主题复杂时增加应用对照。能用简洁表格说明的分类不必强行转为图片。每张图用一句话写出读者应该理解的关系，再决定画什么。

### 原创科学图采用统一风格

早期原创图以白底、细线、中文标注和少量强调色为主，多面板采用字母标识。蓝色、橙色等用于区分信号或条件；坐标、单位、图例和线型共同解释内容。长段方法说明与文献放在网页图注中，图内保留短标签。

后续建议统一使用“（a）（b）（c）”等分面标识。同一词条中同一对象保持相同颜色与名称；同时使用实虚线、点形或文字，使区别不依赖颜色。相互比较的波形尽量共享尺度，无法共享时直接说明；不要分别归一化后继续声称展示原有强度或信噪比差异。

避免大量装饰、拟真背景和长段图中文字。解剖图中的简化结构、机制图中的箭头、示意曲线的高度与位置，都应有明确含义；没有测量依据的几何关系不能暗示解剖距离、因果强弱或临床效果。

### 文件格式按图的性质选择

| 图的性质 | 已有形式 | 后续建议 |
| --- | --- | --- |
| 原创曲线、框图、机制或算法图 | SVG 主文件，PNG 预览 | 网页优先 SVG，另保留 PNG 便于预览与审阅 |
| 教材、论文原图 | WebP、JPEG 等来源格式 | 保留清晰原图及来源；确有需要才另作展示副本，记录转换和修改 |
| 显微或其他连续色调图像 | 使用来源提供的位图 | 按清晰度和来源性质选 PNG、WebP 或 JPEG，不能靠放大增加细节 |
| 原创数值图的复现材料 | 绘图代码、参数说明、验证 JSON | 与图一起保存，适用时保留输入数据或教学信号 |

音高场景图的 SVG 画布为 1,400 × 730；耳蜗的教材 WebP 原图为 2,063 × 996，而另一张论文 JPEG 为 735 × 894。早期图并没有统一像素尺寸或固定纵横比。SVG 可以任意缩放，但图中文字在手机上仍可能过小。

新图可按约 1,200 至 1,600 的 SVG 横向坐标规划，宽高由内容决定。位图按实际展示尺寸与清晰度准备，不将低分辨率图片放大后称为高清。字号以网页缩小后的可读性为准，不能只看绘图软件中的字号。复杂多面板图需要点击原图，必要时拆图。早期预览也提示需特别检查中文缺字和手机缩图文字。

### 图注完整解释图的含义

图注应提供：**图号与短标题 → 分面内容 → 关键参数与单位 → 比较关系 → 图或数据性质 → 适用边界 → 来源与许可。**

原创教学图的图注可以写成：

> **图 3　滤波带宽怎样改变输出包络。**（a）窄带条件；（b）宽带条件。两种条件使用相同输入和幅度尺度，带宽与中心频率见图中标注。图为解析合成信号的教学计算，显示通过不同频率分量后输出的幅度起伏；滤波器未拟合特定听者，不是实测数据或临床常模。原理依据在此引用对应来源。

“教学示意”应结合具体边界，而不是一句通用免责声明。纯概念图无需制造数值刻度；有数值的图需要解释数值来自实测、文献数据、经验公式还是教学设定。依据论文原理独立生成的图，应写“根据某原理绘制”；“复现论文结果”需要对应数据、方法和核验。

转载图除科学来源外，还需记录作者或权利人、原始图号与来源页、许可及链接、修改情况。公开可读的论文不自动意味着图片可自由转载。保留英文原图时，可在图后给中文标签对照，早期耳蜗词条采用了这种处理。

### 保存可复现材料并核对图文

合成信号和数值图应记录采样率、滤波条件、时间窗、归一化方式与随机种子等实际影响结果的参数。核对周期、频谱间距、面积、端点或事件数量等与图意直接相关的量。音高、听觉滤波器和言语可懂度的图源记录提供了这类范例。

视觉检查覆盖标签遮挡、单位、图例、坐标和正文一致性，以及缩小后中文是否清晰。桌面可读不代表手机可读；PNG 预览正确也不代表 SVG 在网页上没有字体问题。只有实际实验数据才标注实验误差或不确定性；教学图不能虚构误差线、样本量或显著性。

## 网站中的实现方式

词条保存在 `src/content/concepts/<slug>.md`，图片保存在 `public/figures/<主题>/`。正文优先使用已有通用类 `encyclopedia-figure`，沿用点击打开原图、替代文本、实际尺寸和延迟加载。以下为格式模板，文件名及尺寸均需替换为真实资源：

```html
<figure class="encyclopedia-figure">
  <a href="/n3-hearingpedia/figures/<主题>/<文件名>.svg"
     target="_blank" rel="noopener" aria-label="查看完整图">
    <img src="/n3-hearingpedia/figures/<主题>/<文件名>.svg"
         alt="简要描述图中对象与主要关系"
         width="<实际宽度>" height="<实际高度>" loading="lazy" />
  </a>
  <figcaption><strong>图 1　短标题。</strong>分面、条件、图意和边界。
    <a href="#ref-<实际文献ID>">1</a>
  </figcaption>
</figure>
```

现有正文图片路径包含部署前缀 `/n3-hearingpedia/`，新增时需要与站点配置一致。信息框中的 `illustration.src` 则按已有实现填写 `figures/...`，由页面处理路径。正文中的概念链接使用 `../<slug>/`；引文使用 `[1](#ref-<文献ID>)`，编号与元数据 `references` 的顺序一致。参考列表由站点生成，不再在正文重复排版。

`depth: in-depth` 表示编辑深度，`status: draft` 表示审阅状态，两者独立。扩写、文献核验或发布授权都不能自动变成专业审阅。`last_updated`、`literature_checked_at` 与 `reviewed_at` 分别记录修改、文献检查和专业审阅日期；只有真实具名审阅才能填写审阅记录。

## 新词条的写作骨架与验收

以下为起草骨架，按概念性质调整标题；没有对应内容的部分可以合并或删除。

```text
元数据：中英文名称、slug、摘要、分类、类型、关键事实、来源和日期
无标题导言：定义、用途、与相邻概念的区别

定义与概念范围
核心现象或结构
原理与机制
测量或计算方法
影响因素与实验控制
结果解释与分析示例
应用及证据边界
研究沿革与尚待解决的问题
参见或相关词条

参考文献和关联导航由站点生成
```

1. **概念清楚。** 导言能独立理解，中文术语统一；首次出现的重要英文缩写有解释。
2. **解释充分。** 机制与方法形成连续论证，变量和单位明确；至少有一个有助理解的例子、对照或图解。
3. **证据匹配。** 关键论断有对应来源，实际阅读范围据实记录；不把模拟结果直接写成临床效果。
4. **图片准确。** 图意、参数、坐标和正文一致，示意与实测有明确标识；转载图来源与许可齐全。
5. **阅读顺畅。** 目录不过度切碎，多面板图在桌面与手机可读，点击原图有效，表格和公式无异常溢出。
6. **工程可用。** 引文编号、图源、概念链接和关联数据完整；词条或页面资源修改后执行 `pnpm check`、`pnpm build`、`pnpm verify`。
7. **状态真实。** AI 草稿保留 Draft，专业审阅与发布核验分别记录。

后续撰写时，可先选最相近的代表词条，再用上述骨架起草。需要概念区分时参考音高或时域线索，需要方法细节时参考听觉滤波器或言语可懂度，需要系统与实际使用时参考助听器和人工耳蜗。
