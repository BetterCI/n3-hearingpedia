# 客观语音可懂度与音质评价：证据与发布记录

检索与编写日期：2026-11-06。正文为AI辅助撰写，保持Draft，无具名专业审阅记录。用户授权在内容核对后推送；本记录不将工程验证等同于专业审阅。

## 问题与范围

问题是：客观语音指标预测什么、需要什么参考、怎样计算和验证，以及结果可推广到哪些材料、听者和处理条件。覆盖SII/STI、STOI/ESTOI、HASPI/HASQI、PESQ/POLQA、DNSMOS/NISQA及SI-SDR；不构建所有指标排行榜，不提供临床处方，不执行受许可的标准算法。

经典文献不限定起始年。近期定向核查区间为2024-01-01至2026-11-06，纳入VoiceMOS 2024、FUSE 2025、双耳HASPI前端2026和P.835的2026修订。它们用于解释方法演进与局限，不代表全面覆盖截至日期的全部研究。

## 公式与原创图核对

- STOI的包络幅度归一化使用二范数比；截断项为`(1 + 10^(-beta/20)) x`，beta为−15 dB；幅度比使用20。随后去均值相关；本文没有实际运行STOI包。
- STOI原文的30帧／约384 ms口径与单帧256点／25.6 ms分别说明；不将普通Pearson相关冒充STOI。
- SI-SDR投影使用`alpha = estimate dot reference / reference energy`，输出残差与参考正交；平方范数比使用10 log10。退化向量和数值小量需单独处理。
- SII仅给概念加权式，不假称标准完整实现；logistic映射只是可选标定例，不是通用正确率换算。
- 四图为原创：评价流程、8点包络相关、等能正交序列的增益指标、相关与校准／局部排序。无受试者、误差线、实测算法排名或经验临床阈值。
- `public/code/objective-speech-evaluation/demo.py`确定性生成SVG/PNG及JSON。500/900 Hz、16 kHz、16000点的正弦构造互相正交，能量均为1。
- 数值断言验证解析曲线、SI-SDR尺度不变和投影正交性，相关尺度／平移性质、RMSE 0.5及总体r≈0.862但各条件相关−1。
- 已逐张视觉检查四个PNG，无中文缺字、遮挡或截断；网站使用同纵横比SVG并提供完整图入口。
