# 来源范围与复核

本篇为机械振动和流体线性声学的基础课程，连接具体词条；不是所有弹性波、非线性声学、噪声法规或听力临床的综述。18份来源均为作者/机构教学资料或官方接口文档，原文件哈希及提取方法见source-index.json。

- va-free/forced：Lebl作者教材的常系数振动与强迫响应。本文质量、刚度、初值、能量与速度半功率公式另行推导；位移峰条件不套到速度或所有阻尼模型。
- va-modal：MIT2.003SC双摆模态教学例，核对广义特征值、质量正交和模态力；本文另造两平移质量矩阵，不声称复现原双摆。比例阻尼C=αM+βK及单位另明确。
- va-measurement/plane/spherical：MIT6.551J的幅度/相位、双向平面波与球面波。本文统一峰值相量、e^(iωt)，实际SI算例另算；不直接沿用其他相量约定。球面近场保留纯外向波净强度恒等式，未推广为任意声源关系。
- va-lumped/tubes：MIT声学端口、短管、自然频率和输入阻抗。va-tubes为11页手写扫描，文本提取仅作定位，另逐页视觉核对PDF第1–6页，覆盖惯抗/顺性、Helmholtz、波动关系、压力/体积速度、开闭边界、管道频率及cot/tan输入阻抗。未声称可靠转写手写全文。
- va-wave-equation/intensity/compliance：UNSW作者教学页，小扰动方程、声强与压力速度相位、比声阻抗/端口阻抗和集总元件。rho=1.2与c=343在本篇得411.6，不沿用原页约写420的数值；表明单位和条件，不复制原动画。
- va-decibels：原music/dB.html仅含meta刷新，实际读取其指向的/jw/dB.html正文并以真实URL登记。核对10log、20log和参考，另外推导相关交叉项；不将0dB写成全部人的统一听阈。
- va-pipes/helmholtz：UNSW开闭管与Helmholtz教学，核对压力/速度节点、有效颈长、长波假设与能量输入；不从理想无损模型直接推真实吸声率。
- va-diffraction：定性波长/几何尺度与绕射；未拿光学演示拟合头影或给出实际屏障衰减。
- va-ir：REW官方脉冲响应文档，核对时窗和响应解释。本文两抽头是指定数字路径，不是实际房间数据，未运行REW。
- va-eigh/ivp：SciPy官方stable文档快照；本地运行1.17.1。广义特征向量的M归一化、局部误差控制和内部步长与输出采样的区别保留。

所有图、矩阵及数值均另行构造。来源支持物理与方法定义，不将教学页面的简化表述视为高精度测量标准；也未宣称完成外部专业审阅。
