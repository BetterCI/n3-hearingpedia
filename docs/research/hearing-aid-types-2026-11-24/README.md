## 科学与图文核对

- BTE/RIC按受话器位置区分，声管传声和导线传电信号分别标识。
- ITE明确广义家族与狭义外形；CIC/IIC不设未经证实的毫米边界。
- RIC可配多种耦合；开放、定制、充电和OTC均不与外形混作互斥类别。
- 适用表为候选比较，未凭平均听阈或外形直接推荐设备，未虚构统一dB适配区间。
- CROS/BiCROS输出送向较好耳；区分声源可达性和恢复两耳独立输入。噪声与言语位置分别评价。
- 骨导传导性听损与单侧聋用途分开；人工耳蜗保留电刺激边界。
- 三个案例均是教学情形，无患者数据、效应量或型号承诺。

四组图位于public/figures/hearing-aid-types/，包括SVG、PNG、generate.py及validation.json。以统一位置参照绘制六种形式；功能链、耦合、跨耳路由各承担一个解释任务。解剖与耳道均已简化、不按比例；箭头不表示效果或声级。已查看四张PNG，核对中文字体、受话器位置、连线方向、图例及标签遮挡。图可在网页中点击原图放大。
