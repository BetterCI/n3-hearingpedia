## 审查结论与范围
未发现阻止作为待审阅教学词条发布的科学性问题。数学结论均给出必要的模型与缩放约定；所有数值为原创指定例子，不作临床、神经机制或真实任务性能保证。100项独立数学/模型/媒体检查通过，3个正文代码示例运行通过。数值检查不证明真实生物系统与模型相符，也不替代专业审阅。

## 逐主题核对
| 主题 | 核对内容与边界 |
| --- | --- |
| 学习任务 | 区分样本行与独立个体、特征维数与信息独立性；分类/回归用“通常”，不把数据类型与任务僵硬等同。 |
| 范式 | 监督、无监督、自监督、半监督和强化学习定义；强化学习给策略、折扣及回报存在性条件，不把有分数的分类一概称为强化学习。 |
| 风险 | 总体风险与训练经验风险分别定义；独立测试估计须对应目标总体和未用于选择的固定模型。 |
| 过拟合 | 训练测试差距还可能来自分布变化；近似、估计、优化分开，不宣布参数数大于样本必败或曲线必为U形。 |
| 偏差方差 | 只在平方损失、零均值条件噪声及独立测试条件下使用；不把残差方差称作估计器方差。有限分布枚举另验恒等式。 |
| 线性回归 | 对参数线性；中心化、截距、秩与系数唯一性；求解不要求显式求逆。平方dB误差为dB²。 |
| 岭回归 | 明确损失除2n、惩罚lambda/2、截距不惩罚，正规方程出现n lambda；与软件alpha/C不直接混用。独立增广最小二乘和优化器交叉核对。 |
| 尺度与稀疏 | 改单位后固定系数惩罚改变预测；Lasso置零不证明因果或生理无关；MAP不是完整后验。 |
| 逻辑回归 | Bernoulli假设、log-odds、平均交叉熵、自然对数与稳定softplus；完全分离时无惩罚MLE可能无有限解。 |
| 多分类 | softmax互斥穷尽条件，分数平移不变、梯度与多标签区别；归一化不等于校准。 |
| 决策阈值 | 推导C_FP/(C_FP+C_FN)，要求使用总体中的可信后验和明确零正确代价；避免再乘一次先验。 |
| 近邻/核/树 | 距离与尺度、软间隔、合法核半正定；SVM分数不是概率，树与集成不是因果解释或性能排名。 |
| PCA | 中心化矩阵的最优秩k近似与加回均值区分；样本方差和解释比例；符号/退化方向非唯一；高方差不保证任务信息。 |
| 聚类 | k均值是距离优化，局部解与尺度依赖；簇不等于音素或疾病亚型。 |
| 神经网络 | 仿射复合、激活、ReLU零点、链式梯度；前向/求导/更新区分，不把网络单元当真实细胞。9个参数的梯度另作有限差分。 |
| 优化 | SGD、批量、epoch与学习率；非凸目标无一般全局最优保证；早停属于选择。 |
| 卷积/注意力 | 互相关与数学卷积不同；时频轴的结构假设；每个查询对键归一化，掩码与完整Transformer区分；权重不是生物注意或因果贡献。 |
| 验证 | 训练/验证/测试职责，折内拟合预处理，先分组再切窗/增强；明确传导学习的例外协议。 |
| 分组反例 | 40身份×6重复，独热身份无跨身份类别规律；行内100%、新身份50%由明确平局和均衡构造得出。两种训练规模不同，不解读为真实性能下降量。 |
| 嵌套CV | 内层选择外层评价，全部流程重跑；外层评价训练规模和程序，不把相关折当独立实验。 |
| 指标 | 混淆矩阵行列和全部分母，正类5%时全部报负95%准确率；精确率/召回率/特异度/F1/平衡准确率独立有理数核对。 |
| 回归 | MAE/RMSE单位、R²可负和常数目标零分母；相关高不等于绝对预测好。 |
| 校准 | 条件频率定义与有限分箱限制；同组常数0.8和0.95示例不虚构个体区分能力。Brier/对数损失不是纯校准误差。 |
| 不确定性 | 样本随机性、估计不确定性、分布变化分别说明；明确协变量/标签偏移的不同不变性假设。 |
| 语音自监督 | wav2vec 2.0潜在遮蔽对比与HuBERT离线聚类遮蔽目标分开；只用摘要可支持范围，不报当前排名或把伪标签称真实音素。 |
| 神经及听觉应用 | 任务得分、神经预测、生物实现、因果机制与真实听者获益分别论证；不把Kell网络层直接等同脑区。 |
| 来源 | 28项全部有正文对应，访问范围如实标记；HuBERT期刊元数据由Crossref核对；wav2vec作者按当前正式会议页登记。 |
