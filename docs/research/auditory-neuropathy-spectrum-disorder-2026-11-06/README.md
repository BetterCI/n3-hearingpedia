## 核验中特别避免的错误

- ABR缺失不直接推算行为听阈，OAE／CM存在不证明全部耳蜗及神经功能正常。
- CM极性翻转不能排除电磁伪迹；声路阻断保持电驱动，与直接关闭刺激器不同。
- 保存历史OAE／CM及中耳状态；不因后续OAE消失自动否定既往证据。
- OTOF突触前、OPA1末端树突、CND及较广泛神经病变不可合为单一预后。
- 助听器可听度验证、言语获益及语言发展分别评价；不以等候病因或新疗法暂停交流支持。
- 中国指南的年龄建议与BSA按持续性／病因分层的时机表述并非通用年龄规则；正文不制定固定等待年龄。
- 2024论文中的“尚无药物治疗”是当时背景；2026年当前状态以FDA官方资料为准。
- FDA适应证、标签试验入组条件及疗效终点是不同口径；任一频率>90 dB HL与四频平均入组条件不混写。
- AAV1-hOTOF与DB-OTO不混为同一产品，不合并人数／治疗耳数或成功率，不宣称优于人工耳蜗的随机证据。
- dB HL、dB nHL、μV、言语正确率及信噪比分开标注。
