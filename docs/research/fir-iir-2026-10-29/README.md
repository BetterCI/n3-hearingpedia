## 数值图与验证

`scripts/generate-fir-iir.py` 生成原创教学图，不转载第三方图像。软件执行版本为 NumPy 1.26.4、SciPy 1.17.1；在线 SciPy 文档为 1.18.0，二者分别记录。

- 16 kHz 采样，2 kHz 通带边界、3 kHz 阻带边界，最大通带损失1 dB、阻带衰减至少60 dB。
- FIR：Kaiser 设计量66 dB，67抽头、66阶，33样本群延迟（2.0625 ms）；网格通带范围约−0.00266至+0.00579 dB，阻带最小衰减65.945 dB。
- IIR：椭圆6阶，3个SOS，最大极点半径0.97140；0、1、2 kHz的近似群延迟分别为0.265、0.362、2.427 ms。
- FIR与最小相位近似：显式使用half=False；重新绘出幅度，保留数值近似边界。
- 一阶r=0.95响应相对初始值下降至−60 dB的最早样本为135；全通幅度恒1另作数值核验。
- 以固定种子20261029产生输入，验证携带SOS状态的256样本分块与整段处理一致。
- 频率网格验证不冒充连续域严格证明。数值指标、全部系数、软件版本见 `figure-verification.json`。

五张PNG均检查中文、轴、图例、单位和曲线。合并前两篇独立预览已检查桌面及390px页面宽度；合并后重新通过HTML、KaTeX、引文、图片资源与交叉链接专项验证。浏览器工具拒绝打开file协议地址，因此未声称完成合并页的浏览器验证；预览的长代码和表格保留独立横向滚动。
