# 来源使用范围

本篇是普通心理学基础课程入口，结合听觉问题，非系统综述或临床实践指南。以25条可核对来源支持概念、研究框架和模型，避免给没有指定人群、材料、任务与效应范围的概括配一篇经典论文作全面背书。

- psych-scope/science/design/measurement：学科、科学推断与测量；观察性多变量分析、有限随机化平衡和分数用途另作条件限定。
- psych-perception/sdt/psychometric/attention：感觉、知觉、注意与测量；曲线和阈值数字为原创教学设定，SDT仅等方差高斯是/否版本。
- psych-memory/retrieval/learning/rw：记忆结构、提取实验和学习机制；RW原扫描打印页74–76视觉核对，未复制原实验图或把数字认作实际联结强度测量。
- psych-decision/ddm：判断的规范参照与双选择模型；Bayes频数及对称扩散算例另计算，半边界a约定与原文章常用全间距区分。
- psych-emotion/motivation：体验、功能、目标与投入；不提供单表情读心或单一“意志力”量表。
- psych-development/aging/traits/social/culture：发展、个体、人格与情境；不把队列算例当老化常模，也不将五因素或一类文化框架当唯一完整理论。
- psych-reverse：神经活动反向推断的选择性和先验；不宣称所有反向推断均无效。
- psych-asa/replication：p值解释、选择性报告与指定复制项目；36%不作为全学科真伪比例。
- psych-ethics：APA 2017生效修订版§8–9的研究与评估原则；非全球法律汇编，具体研究需遵守本地和机构要求。

来源索引区分原始HTTP文件哈希与网页工具所返回文本的哈希；两种访问方式均有记录。复制项目、提取练习等文章已经阅读用于正文的相关设计与结论，未把摘要以外未读细节归于研究结果。
