## 关键论断与适用条件

| 项目 | 核对与处理 |
| --- | --- |
| 建模目标 | 状态、参数、输入、输出、初值与事件规则分开；机制、统计和功能目标不互相替代。与既有听觉计算模型词条区分为基础课程。 |
| 观测层级 | 细胞内电压、分离脉冲、场电位、脑电和fMRI不混同；点神经元电压不直接当EEG，课程范围不宣称覆盖全部细胞或胶质。 |
| 被动膜 | 正注入电流、漏电方向、RC解析解与时间常数含义明确。100 MΩ×200 pF=20 ms，0.2 nA×100 MΩ=20 mV。 |
| LIF完整定义 | 阈值、复位、2 ms保持复位的不应期均说明；首发27.726 ms与稳态周期29.726 ms不同。0.15 nA等界只渐近接近阈值；参数不是某种细胞实测常数。 |
| 简化限制 | 阈下线性不等于完整模型线性；固定阈值复位不声称自发模拟全部适应、爆发、反跳或树突行为。脉冲标记不当动作电位形状。 |
| HH机制 | 原始1952研究来自鱿鱼巨轴突，电流守恒和m³h/n⁴门控按原文及作者教材核对。后者2.2表为特定皮层参数，未冒称原始鱿鱼参数；正文未混用不同电压原点。 |
| HH单位 | 单位面积电容/电导/电流密度与整细胞量分开；µF/cm²×mV/ms和mS/cm²×mV均对应µA/cm²。门控变量不当通道分子结构的字面照片。 |
| 突触电导 | 内向g(E−V)与外向g(V−E)约定明确，非负电导与可变电流方向分开；指数电导核增量、时间常数与事件因果范围定义。 |
| 分流抑制 | EI等于静息时，静息无电流仍可改变总电导、EPSP及有效时间常数。平衡−43.333/−52 mV、时间常数13.333/8 ms；图只解被动方程，不把越过阈值但不发放当真实细胞。 |
| 树突与隔室 | 轴向电流gij(Vj−Vi)、空间离散与参数辨识说明；不称隔室越多必然越好，不把所有详细模型限制为胞体唯一活性通道。 |
| 脉冲及平均 | Dirac事件积分得到计数，不是电压和；时间、跨重复和群体平均分开，PSTH有试次数和箱宽分母，不当单次脑内直接可用信号。 |
| Poisson与历史 | 齐次过程、非齐次确定强度和一般条件强度分开；不应期不是Poisson默认属性；有限箱Poisson计数允许多事件，与0/1发生概率1−exp(−λΔt)分开。历史GLM不当无条件独立增量。 |
| Fano与ISI | 固定条件/窗下计数方差除均值；理想Poisson为1，有限样本Fano1.067非强制1。CV=1限齐次Poisson指数间隔，不由单个统计量唯一反演机制。 |
| 编码与STRF | 条件响应分布、时频核、非线性强度和计数分开；指数无量纲，频带编号不表示Hz刻度，负核权重不当抑制性突触。Theunissen2000只按鸟类摘要范围使用。 |
| GLM拟合 | 计数均值λΔt，似然含无事件的积分或均值惩罚，阶乘只在相同数据模型差值中抵消。图核人工指定，另行直接生成标量投影特征，不冒称从自然录音估计该核。 |
| 留出增益 | 种子20261105，训练/测试各2000箱；测试661事件，对训练常数率基线增益78.9367 nat或0.172287 bit/spike。此量不等于直接测得神经互信息或容量。 |
| 解码条件 | 等先验、条件独立Poisson、对称错误代价、100 ms窗；logLR=(n1−n2)log4，平局随机，准确率0.824548。外部可读信息不直接证明脑内算法或行为因果必要性。 |
| 群体相关 | 信号相关和固定刺激下偏离均值的噪声相关分开；相关影响依信号/读出方向及规模，不说相关总是有害，降维轴不必是因果状态。 |
| 网络动力学 | 率固定点不等于微观不发放；率模型近似不自动保留脉冲网络瞬态。W列为来源、行接收，第一列兴奋第二列抑制。 |
| 稳定性 | 共同τ与局部导数下A=(−I+DφW)/τ；所有实部严格负与存在正实部分别判断，零实部留待高阶分析。矩阵指数图是线性偏离量，不是非线性发放率无限增长；允许瞬态放大。 |
| 学习 | Hebb共同活动、约束、短时/长期改变和机制辨识分开；STDP以tpost−tpre定义，幅度和20 ms窗均为教学设定，不伪装成Bi/Poo拟合或所有突触定律。 |
| 生物可塑性来源 | Bi/Poo1998限培养大鼠海马及细胞/初始强度条件；奖励资格迹只说明延迟信用分配，不把调节变量当全部多巴胺或训练机制。 |
| 听觉锁相 | VS为单位相位向量均值模，N=0不填0，N=1为1；不要求每周期发放。载波/包络参考分开，高斯时间误差模型不当真实频率上限。 |
| 抖动与延迟 | 高斯特征函数解析VS与独立相位样本分别记录；极坐标使用共同径向范围。500 Hz×200 µs为36°，整周期相位歧义明确；有限样本偏差按Vinck摘要使用。 |
| 任务网络 | Kell2018限语音/音乐识别与人类行为、fMRI预测背景；未把层等同脑区、反向传播当已证明生物算法，规范目标保留假设身份。 |
| 验证与辨识 | 数值稳定不同于准确，Euler被动膜0<h<2τ只是一阶线性条件；训练/验证/测试与相关泄漏分开，多指标和新条件推广范围明确。 |
| 时间重标度 | 条件强度正确及相应正则条件下积分间隔映射，边际指数与独立性均需检查；粗箱和估计参数不直接套连续定理，未拒绝不证明模型。Brown2002 DOI已按PubMed纠正为10.1162/08997660252741149。 |

## 独立计算复核

`python scripts/verify-computational-neuroscience.py`通过100项检查，范围为数学实现、单位、概率、模型与SVG：
