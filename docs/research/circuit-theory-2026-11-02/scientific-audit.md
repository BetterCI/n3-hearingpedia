日期：2026-11-02。状态：AI 辅助来源核对、推导与数值审校完成；待专业审阅。正文保留 draft，reviewer 与 reviewed_at 均为空。

## 审校范围与结论
完成概念定义、符号约定、适用条件、例题、图示、代码及引文一致性核对。当前未发现阻断发布的科学性问题。此记录不构成外部专家审稿或真实器件性能认证。

- 电压与电流先规定参考方向，p=ui 采用关联参考方向；负功率表示供能。KCL/KVL 的集总近似与磁通变化边界明确说明。
- RLC 元件关系及能量式采用理想模型；电容电压、电感电流连续性排除冲激情形。非线性器件只在工作点附近进行小信号线性化。
- 节点法含完整数值例题和功率守恒；网孔法限定平面电路。叠加只用于线性响应，不直接叠加功率；含受控源的等效电阻保留受控关系并使用测试源。
- 一阶响应区分初态、终态与时间常数；单边拉普拉斯变换保留初值项，传递函数为零初态定义。输入输出稳定性不替代内部稳定性。
- 相量统一采用 RMS，阻抗只用于正弦稳态。复功率采用电流相量共轭；非正弦情形不套用单频无功功率解释。
- 区分无阻尼自然频率、阻尼振荡频率和给定输出的幅频峰值；Q 与带宽关系限定串联 RLC 电流响应。二端口限定线性时不变网络及频率/零初态 s 域，明确端口电流方向。
- 互感模型检验能量半正定性；理想变压器关系遵循点标记与参考方向。最大功率传输与音频电压传输分开解释。
- 运放虚短明确负反馈、线性工作区和足够环路增益条件；反相、同相连接均给出 KCL 推导。GBW 采用单主极点模型，不视为任意器件恒等式；另核对压摆率与输出摆幅。
- 麦克风灵敏度明确 Pa 与参考声压、dBV 与 dBFS 的区别。示波器探头含阻容负载，并区分信号参考地与保护接地。
- 热噪声采用经典近似、单边功率谱；区分砖墙带宽、等效噪声带宽与 −3 dB 带宽，核对 RC 的 kT/C 结果及其模型前提。

## 独立数值与媒体验证
scripts/verify-circuit-theory.py 共 132 项通过。覆盖独立节点/支路方程、功率平衡、戴维南直接求解、受控源测试、RC 数值 ODE 与解析解、RLC ODE 与矩阵指数、半功率根、初值变换、互感能量、时域平均功率、复功率、最大功率数值优化、有限开环增益反馈解、探头阻抗、噪声积分与单位换算。10 幅 SVG 通过 XML 检验并逐图视觉检查。

正文 3 段 Python 示例与下载脚本均实际运行。节点电压 0.550 V、0.375 V；源与电阻功率均 0.525 mW；复功率 0.020+j0.015 VA；RC ODE 与解析解最大误差约 1.91e−10 V。结果仅验证所述理想模型，不代表实物测量。
