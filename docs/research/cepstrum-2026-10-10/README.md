## 核验与限制

- 核实 18 项引用，含 17 项新注册来源与复用的 NumPy 官方 FFT 文档。经典论文、工具文档和近期研究各承担不同论断；不是 18 项独立实验。
- MIT 的 1968 原文重点阅读 PDF 页 1–4（印刷页 221–224）；2004 历史论文阅读历史、同态与相位段落。2009 ISCA 论文阅读 PDF 页 1–3；2023 CPP 论文阅读 PDF 页 1–4 的方法、表格、讨论。全文级访问并不表示逐句阅读全文或复现研究。
- Noll 的出版方原始摘要由 Crossref 核实；Davis／Mermelstein 仅核实出版书目，IEEE 页面显示验证限制，不绕过，也不引用索引摘要的识别率。
- 2025 CPP 研究读取 PubMed 原始摘要；在线年份为 2024，卷期年份为 2025。子带倒谱研究读取 ISCA 原始摘要，不据此生成未读取的统计结果。

## 原创图与计算

运行 `python scripts/generate-cepstrum.py`。参数在 public/figures/cepstrum/parameters.json；Python、NumPy、Matplotlib 版本随参数保存。

1. 周期 DFT 源—滤波器模型：16 kHz、8000 点（500 ms），200 Hz 脉冲列加固定随机背景，三组稳定共轭极点；无窗。只绘出前 40 ms 波形，不能把绘图长度当作分析帧长。
2. 同一记录的 1、2.5、7 ms 对称矩形 lifter；谱形去均值后比较。已知滤波器只作为教学真值，不称盲估计的精确声道响应。
3. 单回声滤波器：延迟 128 点（8 ms）、系数 0.5、8192 点 DFT；验证前四个倒谱系数的解析展开。
4. 最小相位 FIR 与时间反转序列：4096 点 DFT；已知解析对数分支，反转序列单独移除并恢复一采样点延迟。不是一般语音复倒谱实现。

断言验证倒谱相加、整体增益只影响零阶、回声系数、实倒谱相位歧义和已知分支的逆变换，误差均小于 10⁻¹²。没有测量听者或临床对象，没有运行第三方 MATLAB、librosa 或 Praat 程序，没有复现 CPP 论文的分类结果。
