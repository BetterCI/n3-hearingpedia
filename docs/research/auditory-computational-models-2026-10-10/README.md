# 听觉计算模型：检索与写作记录

核对日期：2026-10-10。交付对象是百科的本地深度草稿，不是全面模型排行榜，也未运行文献中的完整模型。

## 问题与范围

听觉计算模型如何将声学输入连接到外周响应、神经编码与感知任务？模型的输入、输出、参数和验证证据怎样选择？覆盖生理、现象、功能和数据驱动路线，以及双耳、言语和设备研究中的使用边界。历史来源从 Jeffress 1948 年工作起；近期检索范围为 2021-01-01 至 2026-10-10。2026 年 EEG 工作为未同行评审预印本。

## 检索与来源核验

使用 deep-research 技能，以宽主题检索发现候选，以 Osses Vecchi 等 2022 年比较研究（OpenAlex W3180744963；DOI 10.1051/aacus/2022008）为种子，扩展第一层后向与前向引文，再定向补充代表模型、任务优化与模型匹配刺激检验。

- `search.json`、`seed.json`、`backward.json`、`forward.json` 保存发现结果；每组候选按一致的问题进行语义筛选，见 `relevance-prompt.txt` 和 `relevance-screening.md`。
- `verified-metadata.json` 保存 21 项原始 DOI 的 Crossref/Europe PMC 核对，`abstracts-read.jsonl` 记录实际阅读范围。原文摘要由对应原始记录返回，不用题名推断研究结果。
- `selected-sources.json` 按正文顺序保存 25 项引用、访问范围和支持用途：21 项 DOI 研究或综述，3 项官方实现文档和 1 项近期预印本。
- 比较论文访问了摘要和相关分类段落；PLOS 模型匹配论文访问了相关原文；STOI 为作者公开原稿首页可见摘要，HASPI 为原始出版页面可见摘要及局部方法信息，均没有标为已读全文。Jeffress 本轮只有书目核验，正文只据此使用年份与历史位置，后续模型结构另引原始研究。
- AMT 1.6.0 接口与 Verhulst 作者实现 README 支持实现细节和版本，不能支持听者或临床获益。没有将开放可读视为图片转载许可。

第一层扩展已覆盖外周、功能和公开实现，继续扩展主要增加特定应用；定向补充任务优化、模型匹配检验、2025 年下丘与 2026 年 EEG 研究后，主要路线均有直接来源，因此停止。这是有界的百科证据整理，不声称检索穷尽。

## 证据组织与未解问题

生理模型和行为模型需要不同的输出与检验终点。外周前端需要任务读出才能预测行为；数据驱动预测也要通过独立刺激与机制对照评价。文章保留 Breebaart 双耳模型在部分时域条件中的失败。动物单元、人类群体电位与个人功能之间的映射、参数可辨识性、跨语言与听损推广仍是重要问题。

近期路线包括机制模型的可微近似（CoNNear）、生理前端结合任务训练（Saddler）、动物下丘多单元响应建模（ICNet）和跨范式人类 EEG 预测预印本。物种、训练目标和审稿状态分别保留，没有将这些进展写成已验证诊断或设备获益。
