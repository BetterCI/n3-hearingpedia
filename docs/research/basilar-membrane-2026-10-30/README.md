# 基底膜深度词条与三维实验核验记录

日期：2026-10-30（Asia/Shanghai）。状态：AI 辅助草稿，未完成具名专业审阅。

## 检索与证据

围绕基底膜行波、Greenwood 频位函数、外毛细胞反馈、双音非线性及 OCT 微力学检索 PubMed、PMC、PNAS、Frontiers 与出版方页面。纳入经典机制证据以及 2025 年空间压缩研究、OCT 综述；有限主题检索，不宣称覆盖全部最新研究。

沿用项目已有九项来源，并为七项直接相关来源登记独立引用范围。Greenwood 原论文仅访问摘要，具体人耳参数交叉核对 Sridhar 等原文。Ren 2002、Ruggero 1992、Lee 2015 主要核对摘要和可访问图注／片段；Olson 综述核对出版方摘要、书目及作者稿片段。Kondylidis 研究访问公开正文相关段落；W3C Cookbook 核对数字滤波系数。每项访问范围见 `src/data/basilar-membrane-references.ts`，没有将摘要访问记为全文通读。

Olson 综述为 2024 年在线、2025 年卷期；Kondylidis 论文为 2025-01-29 发表、集合年份 2024。未据年份产生重复文献。

## 原创图与模型

三张原创教学图保存 SVG 与 PNG，生成代码为 `scripts/generate-basilar-membrane.py`，参数为 `public/figures/basilar-membrane/parameters.json`。所有数值图均为模型计算，没有转载实验图或虚构误差线。

互动路由：`/lab/basilar-membrane/`。96 个并联 Q=5 数字带通滤波器，中心频率按人耳 Greenwood 函数排列；叠加 0.3+6x² ms 延迟。界面声明该实现未求解流固耦合，不模拟主动非线性、真实径向振型或绝对位移。屏幕抽样会产生视觉混叠，提供平滑 RMS 包络与冻结功能。

输入支持浏览器可解码的本地音频、麦克风、纯音和双音。声道平均混合；数字读数不是校准声压。麦克风始终没有可听回放路径。音频数据保留在本地浏览器。

- `pnpm check`：类型检查无错误；仓库其他文件存在未使用变量提示。
- `node scripts/verify-basilar-membrane.mjs`：通过；覆盖 44.1/48 kHz、500/1000/3000 Hz 峰位与 RMS、静音衰减、双音、反相立体声平均、引文编号及概念链接。结果保存 `validation.json`。

## 图 2 动画及包络科学性复核（2026-10-30）

图 2 已改为可调频率的网页动画，支持 60–16000 Hz、数字输入、对数滑块、预设频率、暂停与慢动作速度。尊重系统减少动态效果设置；离开视口或后台暂停绘制。

科学性问题：旧图是固定 Q 并联滤波器响应，数学计算正确，但不能代表真实行波的非对称包络；添加纯延迟不会改变幅度。Robles & Ruggero 综述明确指出蜗顶侧斜率比蜗底侧更陡；Ren 2002 提供特定动物蜗底的空间测量证据。

默认图现采用一维被动流体耦合有限差分解，方程框架参照 Elliott & Ni (2018)。教学参数和压力边界完整写入正文，未拟合活体实验。每频率峰值归一化，计算峰位与 Greenwood 参考分开报告；保留旧并联滤波器作为可选对照。此图与实时三维实验模型不同，不混称为同一响应。

数值核验：浏览器使用复数三对角求解，独立 Python/SciPy solve_banded 结果保存 coupled-reference.json。60、250、500、1000、3000、8000、16000 Hz 的复响应抽样比较误差小于 1e-9（峰值归一化后）；1201/2401 网格比较通过。250–3000 Hz 的基侧半峰宽大于顶侧两倍；这只是当前教学模型数值特征，不是实验常模或所有频率的强制约束。

前端验证：频率预设、模型切换、暂停及速度选择正常；实际浏览器中，1000 Hz 耦合解峰位 57.9%，Greenwood 参考 60.0%；3000 Hz 分别为 36.6% 与 39.1%。浏览器控制台无错误。静态回退图已同步为被动耦合结果，旧曲线另存 parallel-filter-envelope.svg/png。

最终科学性复核与发布准备在 origin/main 最新版本的独立工作树完成，见 [逐项记录](scientific-audit.md)。旧本地快照的 auditory-cortex 缺失不是最终发布版本的构建阻碍。
