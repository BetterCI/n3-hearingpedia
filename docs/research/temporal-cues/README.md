## 证据与版本

`draft-evidence-records.json`记录审阅稿的书目及实际访问范围，`reference-id-map.json`记录审阅稿文献ID与站点ID的对应。已存在的同一论文复用站点记录，以保留其他词条的既有核验范围；新增论文集中在`src/data/temporal-cues-references.ts`。

文献核验包括经典包络／精细结构研究、调制及相位敏感度方法，以及2022—2025年相关研究。Borjigin与Bharadwaj 2025、Regev等2025选读公开全文的结果和讨论；其他来源按实际情况标为摘要、方法文档等，不能把书目可访问等同于全文已读。原始检索与全文工作副本保留在本地审阅目录。

## 发布转换

移除本地审阅提示和重复参考文献正文，使用站点自动生成的文献列表；上标按站点现有样式显示，避免双重上标或重复括号。两篇之间及其他词条的链接转换为正式相对路径，跨篇章节锚点与网站标题保持一致。

配图、生成代码及数值检查记录位于`public/figures/temporal-cues`，正文图片可点击打开原始SVG。生成代码使用Python、NumPy、SciPy及Matplotlib；当前默认中文字体为Windows微软雅黑，其他系统需要替换字体路径。
