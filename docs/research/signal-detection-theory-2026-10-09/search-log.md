# 《信号检测论》来源核验记录

日期：2026-10-09。完整书目、实际访问范围和支持用途见 source-ledger.json。

核心方法以 Stanislaw 与 Todorov（1999）原文相关段落核对，涉及四格响应、d′、c、ROC、任务换算与极端比例处理；历史依据 Wixted（2020）的历史研究相关段落。1953 年密歇根报告、1954 年 Tanner 与 Swets 论文和 1966 年 Green 与 Swets 专著仅核对原报告题名页索引或书目；不据此声称取得原报告或专著全文。2021 年方法教材仅核对作者官方书籍页面和出版目录。

心理声学应用采用原始研究：Leibold 与 Buss（2020）成人听者的观察者响应、是／否与二时段任务；Dai 与 Micheyl（2010）原文的逆相关与多备选响应方法；Jones 等（2013）频率辨别学习摘要；Hasan 等（2012）双次呈现方法摘要。Greenberg 与 Larkin（1968）只核对 probe-signal 经典研究书目，PubMed 无摘要，正文不引用具体实验结果。Levitt（1971）、Wichmann 与 Hill（2001）、Schütt 等（2016）复用站内已有来源，并核对相应方法相关原文。

Sumner 与 Sumner（2020）的原文相关段落用于判据、错误代价和奖励；另从作者机构仓储原稿题名页核对作者顺序为 Christian J. Sumner、Seirian Sumner：https://irep.ntu.ac.uk/39173/1/1287447_Sumner.pdf。动物例子不当作人类临床疗效证据。

Miyoshi、Rahnev 与 Lau（2026）只用于不等方差、zROC 和 d_a 的方法定义。通过 PMC 可检索原文段落与作者发表目录核对；直接页面遇到访问检查，未绕过，也未取得完整可下载原文。https://pmc.ncbi.nlm.nih.gov/articles/PMC12955650/。作者站的 Miyoshi2026.pdf 已对应另一篇 type-2 ROC 论文，不误作本研究全文。

SciPy 正态分布官方文档用于 PDF、CDF、SF、PPF 与 location/scale 定义核验。本站教学图、任务转换和有限计数算例由原创脚本解析计算，不称为论文结果复现或真实听者实验。

访问限制如实记录：部分 PMC 正文经原页面可检索索引读取相关段落，未取得全部正文；欧洲 PMC 全文 XML 请求未成功。artifacts/sdt-research 下的 Peterson-Birdsall-1953.pdf、Swets-1961.pdf 为不完整下载，不是已读全文，不作为新增证据。未从受限网页绕过验证码或授权限制。
