# Hermann von Helmholtz 核验记录

核验日期：2026-10-09。范围为听觉科学人物词条，不是完整著作目录或系统综述。

## 检索与访问

- 以 Deutsche Biographie、Helmholtz Association 与 PTB 官方历史材料核对教育、生卒、任职、1883年封爵及PTR成立/任职年份。使用Gerlach的1969年NDB条目，不与同页1906年ADB作者混淆。
- 阅读1895年《音的感觉》数字文本的题名页、版本前言及听觉相关部分；对照 Saltire 原书第3、6、8章转录。现代网页交互内容不作为原著。原文入口分别为 https://www.saltire.com/helmholtz/dev/Chapter3.html 、 https://www.saltire.com/helmholtz/dev/Chapter6.html 、 https://www.saltire.com/helmholtz/dev/Chapter8.html 。
- 阅读Kursell（2018）的翻译史相关段落，及Schmidgen的六页神经时间历史研究；原书直接用于器具、版本和实验描述，现代历史研究用于背景补充。
- 以UNSW大学文档核对腔体共振公式及边界条件；以Smithsonian馆藏说明核对Koenig制造的装置，未使用其带限制的馆藏照片。
- 重用百科已核验的Robles与Ruggero（2001）耳蜗力学来源，阅读Caclin等（2005）PDF摘要与音色变量相关内容；McDermott等（2010）只读取PubMed摘要，不声称全文访问。
- 核对Commons两张文件的原来源、尺寸、授权及器具制造信息，并通过浏览器“Original file”链接下载。直接HTTP访问失败后使用普通浏览器下载；没有降低TLS验证或绕过访问检查。

## 关键修正

- 初版德文出版1863，序言署于1862；首英语译本1875，第二英语版1885，1895为重印。
- PTR于1887年创办，1888年Helmholtz任首任院长；机构成立与任职分开。
- 肖像的2022年是上传年份，不能作为摄影日期；AIP原记录未成功打开，不重述“最后疾病前三天”等细节。
- 共振器照片是约1890—1900年Max Kohl制造的同类仪器，不是已证实的亲手原件。
- 440与444 Hz线性叠加的拍频为4 Hz，慢因子的带符号频率为2 Hz；声谱并不因此多出4 Hz纯音。
- 音叉合成、相位比较和历史耳蜗假说均保留条件，未写成现代听觉机制的完整结论。
