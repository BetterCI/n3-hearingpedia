## 实际读取与关键修正

- Lee 等：Europe PMC XML 正式版本全文，核对 Results、Click detection task、Two-photon calcium imaging、Population decoding 和 Discussion。0.5 ms click、反应窗及声级控制来自方法；区分短时抑制与永久损伤。作者明确指出光抑制还缺少不表达有效视蛋白的光照对照，正文保留这一限制。群体解码不能替代下丘的因果干预。2024 正式版本与 2023 预印本分开。
- van der Heijden 等：核对书目、原始摘要和公开全文的结果／讨论／实验方法片段；沙鼠 MSO 的兴奋输入整合与放电概率不同。PMC 全文 XML 接口未返回可用正文，不把 API 失败记作全文成功；相关公开片段来自 PMC 索引及机构书目入口。
- Antunes 与 Malmierca：本次实际取得摘要，保留冷却后丘脑适应与增益调节的结论，不加入具体温度、样本量或效应值。卷期核对为 31(47)，不是 31(48)。
- Moerel 等：核对人类自然声音 fMRI 原始摘要，明确血氧响应与细胞记录不同，不从影像类别偏好推出专属语言中心。
- Bajo 等：核对出版社摘要和图题。雪貂选择性去除皮层下丘投射后，原有定位与堵耳后的学习适应分开；数据库 2009 为在线年，正式卷期为 2010。
- Sharma 等：核对原始摘要与 PubMed／Europe PMC 元数据；采用 PMID 12476090 所登记 DOI 10.1097/00003446-200212000-00004，避免直接复制检索中冲突的旧式 DOI。P1 成熟不是言语结局，观察性年龄分组不是统一临床界线。
- Park 等：核对蝙蝠 LSO 与下丘中央核的原始摘要。记录单位、固定兴奋耳声级及单元／群体比较都有明确条件。
- Lopez-Poveda：重新取得全文，检查橄榄耳蜗内侧／外侧系统的靶点及外周测量限制。
- Lohse 等 2026：核对正式出版元数据与摘要，作为网络认识的综述背景，不当作新的行为因果实验。

## 配图与计算

解剖原图为 OpenStax《Introduction to Behavioral Neuroscience》图 7.12，CC BY-NC-SA 4.0，原图未修改；正文写明只突出部分对侧上行线路，补充中文释义、原页与许可链接。

四张原创图由 `scripts/generate-auditory-pathway.py` 生成 SVG 与 PNG：双耳回路、高斯重叠计算、反馈网络、证据设计。蓝色／橙色结合箭头／横挡及实线／虚线区分含义，白底中文，均支持点击放大。网络图没有画出皮层直达耳蜗的虚假投射。

高斯模型所有时间参数用 ms，读出无量纲；解析结果为 exp[-(τ-d)²/(4σ²)]，半高全宽为 4σ√ln2。输入宽度 0.08、0.20 ms 及内部延迟均为教学参数。数值积分、峰值位置断言及结果见 figure-verification.json；不是生理数据，不输出行为阈值，也未运行完整 Verhulst 模型。
