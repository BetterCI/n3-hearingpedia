# 言语可懂度配图说明

五张图用于本地审阅稿。SVG供网页及出版排版使用，PNG供预览；图注保存在词条正文中。均为原创示意图，没有使用实验被试数据或外部图片。

1. **聆听场景**：安静对话、多人交谈和混响房间。声源位置和传播路径是概念示意，不代表实际声场计算或可懂度测量。
2. **声学线索**：同一段0.9秒合成信号的波形、声谱图、频带时域包络和局部带内振荡。采样率16千赫，基频130赫兹；三个类元音片段使用不同的谐波幅度权重。声谱图采用512点汉宁窗，步长64点。三个频带为250—550、1200—1800和2400—3200赫兹，经四阶巴特沃思带通滤波；包络由解析信号幅度经20赫兹低通获得。局部振荡图采用未平滑的解析信号幅度，橙色虚线是其负值，便于显示包络边界。
3. **背景干扰**：目标及三个背景先匹配整段均方根值，再共同除以四个信号的最大绝对峰值，使所有波形均处于−1至1之间，总体信噪比保持0分贝，目标停顿也计入整段时长。稳态噪声按目标的平滑功率谱着色；起伏噪声施加4赫兹幅度调制；类言语干扰使用基频205赫兹、共振峰参数偏移130赫兹的合成片段，再循环移动85毫秒。短时相对级采用20毫秒均方根窗口，以共同的整段均方根值为参考。这些条件说明时间结构差异，不能据此推断真实竞争言语的信息掩蔽或识别成绩。显示下限为−40分贝，停顿的真实数值可低于该显示下限。
4. **心理测量函数**：逻辑函数的假设曲线。图(a)阈值−6及−3分贝、尺度1.2分贝；图(b)共同中点−4分贝、尺度0.8及1.8分贝；图(c)机会水平10%、上限98%、中点−4分贝、尺度1.2分贝，因此曲线中点为54%；图(d)中点−5及−3分贝、尺度0.8分贝。灰色区只帮助解释地板与天花板效应。
5. **评分单位**：每组10句、每句5词。两组均正确40词，词正确率80%；错误集中组有8句全部正确，整句正确率80%；错误分散组每句错一词，整句正确率0%。圆点表示正确，叉号表示错误。这是构造的回答模式，不依赖词识别独立性的假设。

图中的信号幅度为相对单位，不是声压或设备输出电平。附带的synthetic-teaching-signal.wav与图2目标波形使用同一幅度尺度；其没有可识别的词义。所有背景采用共同缩放系数，不能各自独立按峰值归一化，否则会改变信噪比。

## 复现

在项目根目录运行：

```powershell
python -X utf8 docs/drafts/assets/speech-intelligibility/build-figures.py
node docs/drafts/assets/speech-intelligibility/integrate-figures.mjs
node docs/drafts/assets/speech-intelligibility/render-preview.mjs
node docs/drafts/assets/speech-intelligibility/verify-preview.mjs
```

绘图依赖NumPy、SciPy、Matplotlib和Pillow，中文字体使用Windows微软雅黑。随机种子固定为20261005。figure-verification.json记录数值参数及峰值检查；生成的SVG和PNG保存在本目录。网站使用public/figures/speech-intelligibility中的SVG副本；替换网站副本后运行pnpm check、pnpm build和pnpm verify。试听WAV仅用于本地验证，没有加入网页。
