# 来源范围与核查路径

本篇为《信号与系统》《数字信号处理》的配套基础课程，连接概率、相关、谱与估计；不是随机分析完整教材、统计平稳检验综述或实测神经模型评估。18份来源包括10份MIT作者章节/课程讲义、3份作者在线教材页面、5份SciPy官方接口文档，原文件、提取与SHA256见source-index.json。

- sp-processes/basic/stationary：过程与实现、有限维分布、WSS/严格平稳、联合高斯和指定平均的遍历性。交替边缘分布与共享随机尺度反例另行构造，未作为源文实测结果。均值遍历限定均方定义，不能代替全部统计量的遍历。
- sp-psd/spectral/wkt：相关与谱、谱测度/谱线、整形与白噪声。本文固定实过程、每Hz双侧谱、输入物理单位；普通密度公式的充分条件与一般谱测度分开。未把连续理想白噪声当有限方差点值序列。
- sp-wss/filtering：LTI映射和相关；输入全历史与程序零初态分别说明，跨谱采用R_YX[k]=E[Y[n+k]X[n]]。本文AR初始化与8点平均方差另核对。
- sp-mmse/wiener：条件期望与线性投影、正交与因果/非因果信息范围。本文三抽头权重与全时域总体风险另用线性方程、独立闭式积分核对，不声称用模拟真值拟合参数或公平比较同一实时条件。
- sp-poisson/markov：Gallager课程章节的事件计数、独立平稳增量、等待时间、条件Markov、有限链平稳分布与收敛条件。未将这些理想模型直接当真实神经不应期或因果证据。
- sp-brownian：Pishro-Nik的11.4.2定义与性质，按可见next链接找到；原页面相对路径可能重复chapter11，使用其明示根路径修正，完整发现链保留。标准连续版本与网格高斯增量模拟分别说明，不教授或声称实现Itô微积分。
- sp-periodogram/welch：density、窗平方和、单侧端点、去均值与重叠。本文例子明确detrend=False，实际运行SciPy1.17.1；未用重叠段数机械推自由度或置信区间。
- sp-csd/coherence：明确conj(X)Y对应本文S_YX。循环移位的API方向检查与实际因果流系统不同；单段相干退化为1的例子不作生理或因果发现。
- sp-lfilter：因果差分与初态。AR使用显式平稳抽样，有限因果FIR最前历史不完整的点从显示片段中排除。

十幅图与全部随机数、矩阵和信号由原创代码生成。Monte Carlo只作已知模型的固定种子交叉核对，不证明定理，也不当独立实验数据。文档URL为核查日期的stable快照；运行库版本与源文件身份分别记录。专业审阅待完成。
