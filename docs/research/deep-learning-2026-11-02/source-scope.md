# 来源用途与范围

本篇为《机器学习》的配套基础课程，深入多层表示、梯度、稳定训练及架构；不是系统综述、软件全版本兼容指南或当前性能排行榜。

- dl-mlp/backprop/init：基本计算、形状、链式法则与初始化边界；原创XOR、九参数梯度和矩递推不冒充教材/论文实测。
- dl-sgd/adam/adamw：训练更新、随机估计、自适应尺度与解耦衰减；固定D反例不是完整Adam状态。
- dl-dropout/batchnorm/ln-api/grad-api：随机激活、统计轴、运行状态与梯度记录；明确图中简化公式和实际接口检查的范围。
- dl-conv/rnn/lstm/resnet/he-init：局部共享、状态、门控、残差与矩尺度；索引、感受野与时延另作推导，不由架构名保证实时。
- dl-attention/transformer/transformer-paper：缩放点积、掩码、位置与完整结构；非未来依赖与纯算子置换等变例子独立核对。
- dl-ctc：blank、折叠、路径概率及动态规划；短序列穷举和反例为另行计算，不报识别性能。
- dl-wav2vec/hubert：原始语音预训练目标与微调定位；不将无转写预训练说成全流程无标注或当前最优。
- dl-vae/gan/diffusion：潜变量、对抗与前向扩散的定位；只模拟前向高斯链，未训练或交付音频生成系统。
- dl-generalization/calibration：容量、选择和概率校准；已知总体的精确/求积风险不当作另采集测试数据或实际听觉效果。
- dl-ce-api：类索引CE输入logits、忽略位置和归约；未加权硬标签特例才使用本文有效位置均值公式。

27份原始文件均已缓存并计算哈希。D2L页面为1.0.3在线教材，PyTorch链接固定2.15文档；文章短程序使用本地NumPy/SciPy，版本与核查结果记录于发布检查文件。原始PDF字体编码异常的wav2vec2使用Poppler文本提取；没有以二手概括代替方法核对。
