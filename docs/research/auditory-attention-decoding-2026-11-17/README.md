## 原创计算与图

- generate.py用numpy、matplotlib生成全部SVG/PNG。SVG字体转路径、稳定哈希、删除行尾空格；不使用第三方论文图。
- 固定种子20261117；20个独立试次，每试次960点、32 Hz、6个通道。目标和竞争特征由平滑随机序列生成，再以已知延迟和强弱比例混入通道并添加噪声。它不是生理EEG模拟或真实语料。
- 试次0–7训练、8–11验证、12–19测试；集合不交叉。时延0–8点采用未来EEG，保留952点，逐试次构造避免越界。固定训练均值/标准差用于后续输入。
- 目标函数为均方误差加lambda乘权重平方，数值解与增广最小二乘在1e-10内一致。给定网格内选择lambda=0.001；不是对所有参数的全局最优证明。
- 首个测试试次相关0.8654517548/0.2201568654，8个测试试次全选对。正文醒目标注生成条件有意简化，高分不能当成人体准确率或应用证据。
- reconstruction.csv为试次12完整有效片段；results.json保存参数、数据划分、验证分数和所有测试相关，生成代码可复算。
- 图1为信息依赖框图，图2为实际脚本输出，图3为分组概念示意。逐张检查PNG；图2增加图例上方空间，避免覆盖曲线。没有虚构泄漏导致的准确率增量。
