# 语音增强与降噪：证据与发布核查

核查日期：2026-11-06。近期范围：2024-01-01 至 2026-11-06。正文为 AI 辅助编写的待专业审阅深度词条；工程发布检查不构成具名专业审阅。

## 检索方法与限制

- 使用 deep-research 技能的 OpenAlex 客户端，进行主题检索20条、Wang与Chen（2018）综述种子解析、一层后向20条及前向20条追踪，另做按日期排序的近期检索20条。按DOI优先、其次作品ID去重，得到81条发现记录，见 `candidates-deduplicated.json`。
- 语义判定使用 `screening-prompt.txt` 的四级规则，由本次编写过程检查题名和可用摘要。`candidate-triage.json` 明确记录证据层级；相关性不代表已全文阅读或必须引用。
- 按日期排序的宽泛近期查询混入大量仅有词语交集的结果；这些结果不用于支撑正文。另通过官方会议库、作者论文、出版记录定向核查 Close（2024）、FUSE（2025）、PASE（2026）。并不声称穷尽近期论文。
- Crossref核验11篇新增DOI文献。Ephraim条目首次请求429，随后单独重试成功；最终记录全部为200。DeepFilterNet演示论文按ISCA档案与原PDF登记，不猜测会议DOI；8项来源复用现有注册ID。
- 原论文只放在被Git忽略的 `artifacts/enhancement-sources/` 供核验，不随站点再分发。正文图均为原创解析算例。

## 公式与图文检查

1. $X=S+V$ 来自同一STFT的线性性；瞬时功率保留交叉项，统计功率相加需要不相关条件。
2. 维纳幅度增益为 $\xi/(1+\xi)$；IRM平方根形式另行定义，输出功率增益需再平方。
3. 功率谱减的底限为 $\beta\widehat P_v$；明确是教学变体，不归作Boll原文公式。
4. 固定增益、零均值不相关条件下展开MSE；不把该分解直接套用到输入自适应非线性系统。
5. 复数理想比值排除 $X=0$；两个例子分别为5、0.5−0.5j。
6. MVDR采用共轭转置；正定协方差条件下满足目标约束；求解线性方程，未显式求逆。
7. 图4噪声协方差为 $10aa^H+I$，a为50°干扰传递向量；4传感器、2.5 cm、343 m/s。前半平面曲线不证明前后辨别。
8. 四图由 `public/code/speech-enhancement-and-noise-reduction/demo.py` 生成，断言与数值记录见同目录 `validation.json`。图中文字缺字问题已通过字体回退修正，并重新生成SVG与PNG。
