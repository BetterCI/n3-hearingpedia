# 《听觉老化》本地稿资料记录

核对日期：2026-10-10。词条为 AI 辅助撰写的深度草稿，尚未具名专业审阅；本轮没有提交或推送。

范围包括外周结构、中枢响应、频谱/时域/双耳任务、复杂言语、测量控制、认知与生活影响，以及助听和训练证据。年龄相关性听力损失是其中一部分，未将 presbycusis 注册为整个听觉老化的别名。

## 检索与筛选

使用 deep-research 技能的 OpenAlex 查询、种子与前后向引文工具。`search.json` 保存初次宽检索的八个候选；`seed.json` 为 Füllgrabe 等（2015）；`backward.json` 与 `forward.json` 各保存第一层的八个候选。本轮是为百科组织证据的有界检索，不是系统综述，也不主张穷尽文献。

`relevance-prompt.txt` 保存统一的语义判断要求；人工按“实际研究什么→相关等级→保留理由→阅读范围”筛选，未声称批量模型已自动评分。`relevance-screening.md` 记录取舍、重复与索引错误。对阴性结果、方法控制和干预结局定向补充原始研究；人体神经退变与小鼠突触论文复用百科已有核实条目。

`verified-metadata.json` 保存 19 项 DOI 的 Crossref 与 Europe PMC 原始记录，`abstracts-read.jsonl` 为最终保留记录的原始摘要归档。新注册 18 项来源（17 项论文/综述及一项官方说明），另复用五项来源，共 23 项。正文只在已读范围内陈述结果：多数来源为摘要，部分阅读相关原文段；完整访问范围写在 `selected-sources.json` 与参考注册表。元数据匹配本身不等于全文阅读。

## 来源核查的修正与限制

- 初始 Humes DOI 候选实际指向无关的面孔分类研究，已剔除；`excluded-mismatched-record.json` 留作核查痕迹。最终为 10.1044/2017_AJA-16-0111。
- Carcagno 与 Plack：在线 2020，正式卷期 2021，正文与书目保留区分。其结果约束简单的高声级突触病变预测，没有否认人体神经退变。
- Füllgrabe 与 Schoof 的年龄效应不一致，正文保留不同掩蔽、任务与样本条件；没有把所有时域指标合并为一种普遍下降。
- Cochrane 官方公众页混有旧版摘要；本轮使用 DOI pub3 对应的 2026 原始更新摘要（16 项试验、2261 人），没有混用旧版五项试验数字。原文全文获取未完成，按摘要记录。
- ACHIEVE 两个参考条目沿用既有全文核实记录；本轮重读原始摘要，主要试验的预设 ARIC 人群差异另经原文 Discussion 检索可见内容复核。“48%”不是所有人痴呆发病风险下降。
- PMC 部分网页或全文接口失败，记录在 `fulltext-first-pass.json`，没有据此声明全文获取成功。2025 社会结局原文 XML 及相关段单独保存。
- 健康英语志愿者或某一动物模型的结论，不扩写为中文、所有老年人或个体诊断；认知筛查、组间认知变化和痴呆发病为不同终点。

## 图与可重复性

`scripts/generate-auditory-aging.py` 输出 SVG 和 PNG，使用确定性解析计算，无参与者数据模拟。

1. 功能框架：概念框图，不是解剖图或必然因果链。
2. 言语心理测量函数：教学参数 k=0.6 dB⁻¹、两个 SRT −4/0 dB；不是年龄常模。
3. 声级控制：假设阈值 20/50 dB SPL，固定 65 dB SPL 与固定 30 dB SL；采用相同声压参考，不混减 dB HL 与 dB SPL。
4. ACHIEVE 结局：独立重绘已发表的两组估计及真实置信区间，分别使用认知与 HHIE-S 的尺度，没有生成个体数据或重新拟合模型。

`figure-verification.json` 保存参数、结果及数值断言。`draft-verification.json` 保存引用编号、已存在交叉链接、图像尺寸、关系与路径检查；构建、链接和桌面/手机视觉检查见 `qa-report.json`。
