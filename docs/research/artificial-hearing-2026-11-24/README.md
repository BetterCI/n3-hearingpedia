# 人工听觉：研究与交稿记录

日期：2026-11-24。交付为 n³ Hearingpedia 深度词条，状态 Draft；AI 起草、资料核验与工程检查不构成专业审阅。

## 问题与范围

本条解释从植入式听觉假体到装置助听、生物修复与机器听觉的概念扩展，主要对象为学生与研究者。四层范围是响应本次写作要求建立的编辑框架，不声称为国际统一定义。以机制、接口和评价终点为主线；不作产品排名、个人适应证判断或所有地区的监管清单。

历史研究不设年份下限。近期补充范围为 2024-01-01 至 2026-11-24，重点核对 OTOF 人体研究及 FDA 官方状态。本次是定向叙述性证据核查，不是系统综述，也不声称检索穷尽。

## 检索与引文扩展

采用 deep-research 技能。先阅读词库写作规范与人工耳蜗、助听器、基因治疗及听觉计算模型的已有来源，再在公开网页、Europe PMC、OpenAlex 与研究机构原始页面复核。

主要检索组：

- cochlear implants / auditory prostheses / continuous interleaved sampling；
- auditory brainstem implant / nontumor / auditory midbrain implant；
- hearing aids / noise reduction / real-world outcomes；
- OTOF gene therapy / 2025 / 2026 / FDA Otarmeni；
- AudioSet / machine hearing / task-optimized auditory models；
- cochlear optogenetics / spectral selectivity。

OpenAlex 主题检索 `auditory prosthesis cochlear brainstem implants` 初次返回 HTTP 429，因此改用 DOI 定位 Wilson 1991（W2058319502）。随后成功获取种子、8 条后向候选与 12 条前向候选，原始结果保存在 `openalex-*.json`。这只是限量一层扩展，不是完整网络。前向结果确认 Shannon 1995、Friesen 2001 与 Zeng 2008 处于相连的编码与评价谱系；其他支路按具体问题检索。由于已覆盖接口、线索、行为、修复及机器任务，且新候选多重复主题或进入过细分支，未继续第二层扩展。

OpenAlex 后向列表混入一项 2011 年记录，晚于 1991 年种子；将其作为索引异常排除，没有据此建立历史论证。前向的生物材料综述、音乐综述与语言学习论文分别属外围或已有论证的补充，未以引文数量为理由纳入。宽泛检索中的新闻仅用于发现线索，不作为临床结论来源。一条错误 PMID 导向舞蹈康复研究，核对标题后排除；混合植入系统通过正式 DOI 10.1002/lary.25451 重新确认。

Europe PMC 的摘要与元数据下载脚本为 `collect_evidence.py`。首轮输出遇到 Windows GBK 字符编码异常，已经保存的 UTF-8 JSON 不受影响；后续改为 UTF-8 输出并从保存记录核对。PubMed 网页和 Nature 页面部分访问受限，正文据 Europe PMC 正式摘要限制结论。全文可获得与本次实际阅读全文是不同情况。
