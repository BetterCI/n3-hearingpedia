# 《听觉皮层》检索与证据记录

核验日期：2026-10-09。用途：深度词条草稿；2026-10-09获用户明确授权提交推送，尚未完成具名专业审阅。

## 问题与范围

解释人类听觉皮层在哪里、如何划分、怎样表征声音，以及不同测量和因果操作能回答什么问题。以人类成像、颅内记录和自然声音研究为主；小鼠、大鼠、雪貂和猫研究用于解释局部回路、状态调节、学习及干预，不转写为人类临床效果。

与《听觉通路》的区别：通路词条介绍耳蜗到皮层的多层级网络；本文深入皮层区域、局部回路、声谱时间模型、上下文范式及因果证据。临床疾病分类、完整语言理论与植入时机指南不在本稿范围。

## 检索和筛选

使用 deep-research 技能的 OpenAlex 脚本进行主题检索，以 2022 年时间整合研究 `10.1038/s41562-021-01261-y` 为种子，展开一层后向参考与前向引用。记录分别保存于 `openalex-discovery.json`、`openalex-backward.json` 和 `openalex-forward.json`。前向结果用于发现后续工作，不按引用数评价质量。早期输出因 Windows 默认编码中断，设置 UTF-8 后重新生成有效 JSON。

补充检索包括：人类 auditory cortex / core / belt / parabelt / Heschl / tonotopy；STRF、phonetic feature、model-matched sounds；temporal integration / TCI；attention / motor corollary discharge / prediction error；cortical inactivation / lesion；deafness / cross-modal plasticity。近期核验范围为 2024-01-01 至 2026-10-09，同时保留直接支持定义和方法的经典研究。

按“实际研究对象—实验操作—测量结果—与本词条关系—推广限制”筛选。优先选择有明确对照、独立方法价值或与相邻证据形成对比的原始研究。排除会议摘要、只重复已保留结论的材料、与完整临床指南有关但超出本文的问题。停止在主要主题及方法分支已覆盖、种子一层扩展主要重复这些主题时；本记录不是系统综述，不声称穷尽全部最新论文。

## 证据组织

| 主题 | 关键来源 | 证据用途及边界 |
| --- | --- | --- |
| 区域及个体定位 | Moerel 2014；Dick 2012；Leaver 2016 | 结构与功能联合定位、多个梯度、不同刺激线索；不用单一坐标定义所有人的 A1 |
| 局部回路 | Li 2015（在线2014）；Kato 2017 | 小鼠细胞类型及网络抑制；保留清醒／麻醉、刺激时长与记录条件差别 |
| 自然声音表征 | Mesgarani 2014；Norman-Haignere 2015、2018 | 人类声学语音特征、类别成分和模型匹配；区分体素成分、电极群体与单细胞 |
| 时间整合 | Norman-Haignere 等 2022、2025 | TCI、输入窗口与潜伏期的区别、伸缩语音的后续检验；范围是方法和样本结果 |
| 注意及状态 | Mesgarani 与 Chang 2012；Fritz 2003；Schneider 2014 | 同一混合声中的目标选择、快速任务调节、运动输入；不混同长期学习 |
| 偏差检测 | Parras 等 2017 | 多标准／级联控制区分重复抑制与额外偏差成分；不等同主观惊讶 |
| 因果与任务 | Hamilton 等 2021；Lee 等 2024 | 人类局部刺激／病例与小鼠短点击检测；解码、干预、短时和永久操作分别解释 |
| 学习及剥夺 | Bajo 等 2010；Sharma 等 2002；Lomber 等 2010 | 回路对重校准的作用、P1成熟、聋猫视觉补偿；不制定临床时机或否定视觉交流支持 |
| 近期进展 | Leonard 等 2024（在线2023）；Bhaya-Grossman 等 2026（在线2025）；Lohse 等 2026 | 深度记录、语言经验及整合网络视角；最后一项仅使用已核对摘要 |

逐项书目、DOI、访问范围、支持用途和证据定位见 `selected-evidence.json` 及网站参考注册表。16 项新登记来源（含一项图源）、7 项复用已有来源；没有为同一 DOI 再建重复 ID。已有 Moerel、Dick、Mesgarani 与 Chang 的参考 ID 保留，追加实际核读范围。

## 书目与访问限制

OpenAlex 仅用于发现和书目初核；作者顺序、卷期年份和科学结论回到 PMC、出版社或 PubMed核对。Li、Leonard、Bhaya-Grossman 三篇的在线年份与正式卷期年份不同，参考表分别说明；不按 DOI 中的年份替代出版年份。

部分 PMC 直接打开触发验证页，Europe PMC XML 服务返回 503；没有把下载尝试视为阅读成功。实际核读使用网页工具返回的原始文献摘要、可访问正文相关段落及公开作者稿。摘要范围来源包括 Li、Fritz、Schneider、Lomber、Bajo、Sharma 和 Lohse；正文不新增超出摘要的样本数、统计量或方法参数。Hamilton 使用公开作者稿的 SUMMARY 和 STAR Methods 刺激段，病例推广限制保留在正文。

2025 年时间整合引用正式发表版本 `PMC12586173`，不使用 2024 年预印本 `PMC11463558` 作为另一项独立研究。Lee 使用 2024 年正式版本，保留其光遗传操作缺少不表达光敏蛋白对照的限制。Lohse 2026 仅支持摘要中的网络组织视角。

## 配图与可复现计算

六张图包含五张原创教学图及一张可靠来源的医学插图。五张原创图采用白底、中文标注、SVG 路径字体及 PNG 预览，未转载实验数据、误差线、样本量或显著性标记。生成脚本是 `scripts/generate-auditory-cortex.py`，参数与数学核验为 `figure-verification.json`。

STRF 图保存全部矩阵与无量纲归一化特征，延迟为 0、20、40 ms，基线 2 spikes/s，增益 10 spikes/s 每单位加权输入，预测为 12、7 spikes/s。它是离散计算示例，未拟合真实神经数据，也未生成真实声波。TCI 图只演示 200 ms 共享片段与 50、300 ms 矩形窗口的几何；偏差控制图只展示事件角色，不用八个事件宣称实验概率。

新增图1采用 Blausen Medical 的 Blausen 0102 Brain Motor&Sensory 原始PNG（1600×1493）。Wikimedia Commons 文件页记载作者 BruceBlaus、2014年创建、Blausen捐赠及经VRT核实的CC BY 3.0授权。原图及英文标签未修改；网页列出作者、来源页、许可链接和中文标签对照。原图仅说明功能区域的大致位置，图注明确赫施尔回藏于外侧裂内、彩色区域不是严格脑叶或个体A1边界、经典语言区标签并非完整语言网络。下载URL、尺寸、哈希及授权记录见 image-sources.json；原有五张图的生成记录继续保存于 figure-verification.json。

## 尚待解决的问题

科学研究问题包括：任务和状态是否改变输入整合窗口；语言经验与声学特征如何交互；短时与永久干预在何种网络条件下出现不同任务结果；群体指标是否能在独立人群中预测功能。正文将它们作为问题提出，未写成确定结论。
