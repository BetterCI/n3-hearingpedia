## 检索策略与停止条件

采用 deep-research 技能，2026-10-09 定向检索；这不是穷尽性的系统综述。核心种子为 Caclin 2005（受控线索、相异性与模型）和 Patil 2012（联合表征、分类与行为预测）。通过 OpenAlex 取得两篇种子的向后、向前各一层候选，每层最多 30 条，再以音色感知及 2024–2025 年表述补充发现检索（25 条）。另用主出版方、作者公开论文、PubMed／Europe PMC 核对关键原始研究及 2026 年临床进展。

`openalex-*.json` 保存候选书目及摘要是否可得。OpenAlex 年份与类型可能与正式出版物不一致，引用年份以出版方及对应期刊卷期为准；没有用搜索排名当作证据强度。`screening.json` 记录选定候选的人工语义判断，依据实际摘要或已读正文的方法、对象与结论；其余检索结果标为“仅检出，未完成评估”，不冒充全部筛选。重复 DOI 合并，不同检索层不计作独立证据。

停止扩展的理由是定义、频谱／动态线索、MDS、神经与模型、个体任务、跨类别、CI 和助听处理等论断均有直接支持，新增候选多在已有主题内重复或转向应用。近期声音生成及嵌入预印本未用于建立听觉机制共识。优先保留直接行为研究与适用边界，没有用新论文数量代替覆盖。

所有图和声音原创，无第三方录音或转载图。代码 `scripts/generate-timbre-perception.py`；输出目录 `public/figures/timbre-perception/`、`public/audio/timbre-perception/`。SVG 的视框为 1440 × 720，PNG 预览为 2000 × 1000；字体为 Microsoft YaHei，SVG 将文字转为轮廓。白底、中文、蓝橙与线型／纹理共同区分条件。

`figure-and-audio-verification.json` 记录每段 WAV 的参数、RMS、峰值、持续段重心与 SHA-256；四段 24 位 PCM WAV 均有 57,600 个样本、整段 RMS 约 0.06，无削波。频谱检验针对 0.4–0.8 s 的整数周期持续段及已知谐波频点，而非宣称所有 FFT 算法重心相同。代码运行时直接断言这些关系。

图注及正文均说明：等 RMS 不等于等响；同物理时长不等于同感知时长；同基频未做知觉等音高；全事件归一化改变持续段幅度。试听只能展示操作，没有收集或推算能力。MDS 项目 P/Q/R/S 与音频 A/B 快慢条件没有映射；轴可以旋转，不能自动称为真实音色维度。图和音频供本站展示，脚本与参数可复算；对外复用的开放许可证尚待项目维护者确定，与仓库 README 的现状一致。
