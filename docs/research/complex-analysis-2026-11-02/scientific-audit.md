## 结论与范围

在正文明确的单频稳态、线性固定滤波、一极点与两共轭极点、简单闭曲线和给定收敛域条件下，未发现阻碍作为待审阅课程材料发布的实质数学或声学错误。解释范围包括复数与相量、复导数/解析性、分支、复积分、级数、奇点与留数，再连接s/z平面、衰减振荡与响应面积；不以复数基础代替整个复分析课程。

所有图、数值、音频均为原创合成或解析计算，没有听者实测、器件验证或临床推断。数学推导成立不等于人耳对相位变化的可闻性或实际降噪效果已经证实。

| 核对主题 | 结论与关键条件 |
| --- | --- |
| 复数与声压相量 | 实/虚部、模、幅角和Euler公式一致；采用峰值相量、正时间指数。相位单位、Hz与rad/s区分，RMS与峰值因子明确。 |
| 同频叠加 | 两分量各0.2，相位差0/120/180度，合成幅值0.4/0.2/0；非相干均方叠加和多位置实际消声另有条件。 |
| 阻抗与能流 | 比声阻抗P/V单位Pa s/m，声阻抗P/Q单位Pa s/m³；本例100+j173.205，平均声强5e−7 W/m²。用完整周期实声压×实速度平均独立复算共轭及1/2因子。 |
| 复导数与CR | 差商全路径定义明确；平方函数全路径极限，共轭函数方向反例，模平方仅原点可导。连续偏导加CR作为充分条件，单点可导与邻域解析区分。 |
| CR单点反例 | 审查脚本另取F(z)=共轭(z)²/z、F(0)=0，实/虚轴差商均1，斜向为−1；说明没有相应实可微条件时，仅CR等式不足。 |
| 调和与声波方程 | 解析函数实/虚部满足二维Laplace方程，不将此“调和”混同音频谐波，也不将非零频率Helmholtz声压视为空间解析函数。 |
| 复对数与相位 | 解析主支限定避开非正实轴；主值乘法可差2πj。纯延迟采用负频率相位，主值与展开相位区分；采样歧义明确限定f_k=kΔf网格，零点处相位未定义。 |
| 复积分与Cauchy公式 | 参数积分包含路径导数、方向；Cauchy定理保留单连通与域内全纯，公式保留简单闭曲线及内部邻域全纯条件。单位圆1/z积分2πj，z积分0，z²/(z−0.5)积分πj/2。 |
| Taylor/Laurent与ROC | a=0.8的内外级数对应不同序列，因果/反因果及稳定性不由有理式独立决定。8项和4.1611392，尾项0.8388608。外部级数在z=0.6发散。 |
| 奇点与留数 | 零点重数、可去、极点、本性奇点及对数分支点分开；留数是负一次系数，不是频响峰高。约分后传函与隐藏内部动态区分。 |
| 逆Z | H(z)z^(n−1)为被积函数。负时间时原点新增极点不可漏算；两条不同ROC圆周提取n=−3至6的系数均吻合。 |
| 连续s与离散z | s具每秒量纲，z为无量纲采样步乘子；模态关系z=exp(sTs)不冒充通用离散化代换。连续/离散稳定判据保留因果、有理、ROC和外部/内部边界。 |
| 两极点谐振器 | 衰减、脉冲响应与手写递推一致；角度1000 Hz不等于精确峰频。r=0.95/0.995时峰991.87959/999.92276 Hz，时间常数1.21848/12.46872 ms，已修正文中舍入至991.88。 |
| 响应面积 | 留数与大圆弧界共同推出实积分；单边角频率积分πωc/2，转换Hz后为πfc/2；直流增益1的例子面积1570.7963 Hz，不称为录音声能或未经输入PSD规定的噪声方差。 |
