# 宽动态范围压缩：证据与核验记录

日期：2026-11-06（Asia/Shanghai）。基线提交：`1c3b31ae52d1fdccab39ca485a4acf55e0cc36cf`。

## 范围

面向听觉研究教学，解释声学助听器WDRC的静态与动态机制、多通道及混合声作用、处方验证和实际结局。既纳入经典工作，也检索2024-01-01至2026-11-06的相关进展。不提供个体验配参数；不把人工耳蜗声电映射、数据编码压缩、频率压缩或音乐母带处理混作WDRC。

正文保持Draft、reviewer=null；本轮核验不是具名专业审阅。

## 检索与筛选

使用deep-research技能的`openalex_research.py`，主题检索`wide dynamic range compression hearing aids`返回20项；以May等2018（OpenAlex W2886069922）为种子，向后20项、向前20项。另按日期排序搜索`hearing aid compression`15项，用于检验新近检索覆盖；该查询精度低，返回大量非WDRC条目，不能把它当作近期研究的完整清单。来源原始记录分别保存在本目录的search、seed、backward、forward、recent JSON中。

初始引用扩展误把DOI传入需要OpenAlex ID的citations命令，返回400；随后先解析种子ID再运行，最终保存的是成功结果。初次Windows输出编码错误也已改为UTF-8后重新生成。筛选提示由`judge_relevance.py`针对种子生成，见`screening-prompt.txt`。

进一步通过PubMed、PMC、出版社和作者机构查找：Kates数字压缩机制、Jenstad恢复时间、Bor元音谱对比、Gatehouse交叉试验、Windle快慢压缩试验、Ellis复杂声场、Neural-WDRC、空间线索和验配来源。按研究问题与实际方法选文，不按引用量排序。重复DOI只计一次；同一文章的在线与卷期版本不当作两个研究。

停止于一层引用扩展：静态机制、动态语音、多通道、混合声、行为结局、验配及空间处理已有对应来源，后续发现主要是相同主题的延伸。此为定向百科证据整理，非系统综述，不声称穷尽2026年研究。低精度近期结果中急救团队、可可产业、植入异物反应等与WDRC问题无关，排除；音乐设备、声增强硬件等相邻主题不因关键词相同自动纳入。

## 书目、访问与可核查性

`bibliographic-check.json`保存19个DOI的Crossref身份、作者、卷期页码与日期字段，最终全部HTTP 200。首次5项429经顺序重试解决，记录保留previous_error。Crossref在线日期与卷期日期不完全一致；Windle最终按PubMed及出版社确认为2026年47(1):107–119、2025-09-12在线。其内部ID后缀2025用于稳定标识，不代替页面出版年。

原始来源链接、全文／摘要／书目访问范围及具体用途在参考注册表中逐项展示。既有参考条目不因本轮复用而自动升级访问标签。访问故障不算科学反证，也不把仅见元数据写成读过全文。原文PDF与XML仅在本地排除目录`artifacts/wdrc/`用于核对，未把全文打包进公开网站。

## 原创计算与图表

运行`python public/code/wide-dynamic-range-compression/demo.py`。依赖Python、NumPy和Matplotlib；实际版本与字体记录在`public/figures/wide-dynamic-range-compression/numerical-checks.json`。代码与图为本词条原创教学材料，按仓库许可发布；未转载论文图片。四图SVG为网页主文件，PNG用于审阅。

1. 单拐点输出和增益：K=50 dB SPL、G0=30 dB，CR为1/2/3；无输出限制。
2. 已知输入声级50→80→50 dB SPL；dB增益域指数平滑，时间步长0.1 ms，启动常数5 ms、恢复常数50/500 ms。未模拟声级检测、真实波形和输出限幅。恢复50 ms后输出74.48/66.43 dB SPL。
3. 两理想不重叠频带输入70/50 dB SPL；共同增益保持20 dB差，逐带同规则压缩变为10 dB差。不是元音仿真。
4. 两等时长稳态片段，目标相对功率100/1、噪声1/1，源间不相关。单位功率对应50 dB SPL。各段SNR为20/0 dB，共同压缩后仍不变；能量合计SNR由17.0329变为11.2099 dB。不能用两个dB值的算术平均计算全程SNR。

断言覆盖连续性、单调性、差分斜率、压缩比、增益／输出恒等式、一阶响应解析解、谱对比、固定增益SNR不变及跨片段权重改变。没有随机数据、临床常模或受试者实验；也没有执行openMHA。
