# 《语音感知》本地深度稿交付记录

日期：2026-10-10。状态：本地Draft，未提交或推送，专业审阅待完成。

## 范围与写作定位

回答人类听者如何从变化的声学线索形成语音类别及词语判断。面向学生、研究者和专业读者，按协作规范的深度词条要求组织。与《语音学》《言语可懂度》《言语测听》衔接，分别保留物理描述、识别过程、成绩与临床任务的区别。

主线：研究对象 → 声学线索与整合 → 类别及连续信息 → 协同发音与适应 → 连续语流与词语候选 → 语境及视听 → 普通话 → 神经与模型 → 实验设计 → 听力技术 → 研究沿革与开放问题。

## 检索、筛选与核验

采用 deep-research 技能的OpenAlex主题检索，查询speech perception acoustic phonetic cue integration；从Norris等2003年学习研究W2096162685做一层后向与前向扩展，后向12项、前向8项。原始结果保存在openalex.json、backward.json、forward.json。前向结果引出Shortlist B及理想适应者两条解释路线。检索不是系统综述，不据本轮检索数量作覆盖率或质量排名。

筛选依据是论文是否解释线索到类别、在线词语识别或学习，而非仅凭词频和引次数。OpenAlex六项发现候选中：2010年线索权重学习和2014年特征编码为Core；1981年语音／非语音线索等效、1989年声学一致性及2021年声学／词汇线索个体差异为Important；2012年语用线索研究为Background，未单独展开。保留语音神经研究、普通话模拟与真实植入者对照，排除仅有工程转写成绩而不检验人类机制的来源。筛选提示保存为relevance-prompt.txt。

经典来源范围1957—2008年，后续核心证据包括2012—2015年研究及2021年模型比较；近期窗口按2025-01-01至2026-10-10定义。补充Bhaya-Grossman等的语言经验皮层研究，其在线日期2025-11-19，正式刊载2026年，不作为两个独立研究。

书目和部分原始摘要用Crossref与Europe PMC交叉核对，保存verified-metadata.json；重要原文段落通过作者存档或出版页面阅读。24项选用来源包含复用的站点条目，去重后按ID登记在selected-sources.json。全文相关段落、摘要及仅书目访问逐项注明；访问失败不记作成功。OpenAlex条目不是独立科学证据。
