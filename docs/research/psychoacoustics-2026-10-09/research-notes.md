## 主要论断边界

- 强迫选择减小是／否报告标准的自由度，仍可能有时段、顺序与记忆偏向。
- 位置参数不普遍等于 75% 阈值，斜率依赖刺激坐标，失误参数不自动等于走神发生率。
- 正态等方差的 d′ 与 c 有明确条件；绝对判据 k 与以分布中点为参照的 c 分开。
- 二降一升、三降一升的目标概率描述经典长期条件，有限轨迹不证明无偏或收敛。
- Wilson 区间描述固定水平下二项比例的不确定性；它不是曲线阈值或跨人群的区间。
- 实验功能模型、正常听力声学模拟、真实植入者与临床测听保持解释层次。
- 耳机筛查不校准入耳声压、不确证正常听力；在线结果限于实际任务与筛选样本。

2. 心理测量函数：γ = 0.5、λ = 0.02、α = 0 dB，β = 2 或 4 dB；函数中点 0.74，β = 2 时 75% 位置约 0.167 dB。
3. 信号检测：N(0, 1) 与 N(1.5, 1)，k = 0.2 或 1.2；以独立的正态尾概率计算 H/F，再由分位数反算 d′，均为 1.5。
4. 采样：七个固定水平各八次，二降一升模拟 56 次；种子 20261009、初始相对声级 8 dB、步长 1 dB；70.71% 的模型位置约 −0.552 dB。不是人群实测或推荐流程。
