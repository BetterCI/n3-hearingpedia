# 《耳鸣》检索与编写记录

日期：2026-10-09。目标为百科深度词条，非穷尽性系统综述。参照 `docs/contributor-kit/README.md` 和 deep-research 技能，保留不同证据对象及实际阅读范围。

## 范围与问题

覆盖定义及负担、外周与中枢候选机制、躯体调制、心理声学与功能结局、动物及人体研究范式、临床管理和代表性试验。近期窗口为 2023-01-01 至 2026-10-09，经典定义、方法与原始研究不受此窗口限制。

## 发现与核验

1. OpenAlex 主题检索 `tinnitus mechanisms assessment treatment`，上限18项；书目发现不作为效果证据。
2. 以 Shore、Roberts、Langguth 2016 综述（DOI `10.1038/nrneurol.2016.12`，OpenAlex `W2252713678`）为种子，分别进行有界后向、前向检索，各上限12项。
3. 按 DOI、题名和版本去重；选择能够覆盖机制、阴性结果、功能量表与试验设计的研究，而非按引用次数机械取前若干项。保留 Guest 2017 生理阴性结果、TRT 2019 对照结果和 UNITI 的敏感性边界。
4. Europe PMC core 核对作者、年份、期刊、DOI和摘要；开放全文采用 PMC XML 或 NCBI BioC，并阅读论断对应方法、结果或讨论段落。Auerbach 2014 复用并重读既有可核对全文缓存，不重复注册来源。
5. NICE NG155（2020）和 VA/DoD（2024）使用官方 PDF，提取并核对推荐正文。不把 NICE 文件版权年份当作新版指南。
6. 2026-10-05 声音试验尚未在本次 Europe PMC 查询中索引；使用 Crossref 元数据与 Scientific Reports 出版者摘要核对。它是已同行评审的提前在线版本，未阅读完整方法，不写未经核对的样本数、盲法实现或偏倚结论。

种子扩展的 OpenAlex 摘要有缺失；语义筛选提示用于组织问题，最终纳入依据是后续摘要与相关全文核验。Cima 2012 的 DOI 查询未直接返回结果，改以 PMID 22633033 核实，不将初次检索失败记作不存在。

## 筛选与停止

纳入24项，包括23项新增参考注册和1项既有来源。完整阅读范围见 `source-ledger.json`，不能把摘要访问记为全文。发现池见 `discovery-pool.json`；它是搜索痕迹，并非所有候选均进入正文。模型、动物、个案、随机试验、单臂自身对照和指南分别解释。正文需要的主要证据链及反例已有覆盖后停止扩展，未声称覆盖全部疗法或全部最新论文。

## 图片与教学计算

四张图均为项目原创，使用 `scripts/generate-tinnitus.py` 生成 SVG 和 PNG，未转载外部解剖图或论文图。参数见 `figure-manifest.json`。框图不提供解剖定位或因果强度；结局对照数据为教学设定。生成脚本断言三个情形的变化量及感觉级示例，页面检查另核对尺寸和移动端布局。
