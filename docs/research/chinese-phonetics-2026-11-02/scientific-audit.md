## 语言学论断与适用边界

| 主题 | 核对与处理 |
| --- | --- |
| 范围 | 汉语不等于普通话；正文明确以普通话入门，比较仅限指定调查点与文献，不给出所有方言的统一音表或声调数。 |
| 类别与实现 | 音素、音位、变体、字母和语音信号分开；词汇对立不自动意味着只有一个声学线索改变。字数不总等于音节数，花儿与女儿的例子按常见普通话读法限定。 |
| 拼音与IPA | b/p常见为[p]/[pʰ]，不送气不等于浊；拼音y不同于IPA[y]。j/q/x后的ü省点、n/l后保留、iou/uei/uen省写和jun的ün均按方案原文核对。 |
| 音节结构 | 声母、韵母、声调与音素不混层；guang按传统教学结构分解，ng作为字母组合不拆成n+g；介音、成音节近音保留理论表示差异。 |
| 声母数量 | 21项属于常规拼音声母表，不称为唯一音位总数；y/w不额外计入，ng不作为普通话常规声母。7组计数3+1+4+3+3+4+3=21。 |
| 部位与方式 | 使用传统部位组；“舌根”“舌尖后”不规定唯一解剖位置。近音、鼻音、塞擦音保留气流与时序区别；r可有近音或带摩擦实现。 |
| 翘舌记音 | [ʈʂ、ʈʂʰ、ʂ]为常见教学宽式，不冒充Lee与Zee青年北京样本的原始窄式表；保留样本不具有严格卷舌形态的范围。 |
| 韵母与元音 | 韵母、元音音位与字母数不等同。i/y/u的高低前后圆唇用于入门，e与介音等不裁决唯一音系分析。舌尖元音与成音节近音并列说明传统术语与分析差别。 |
| 舌尖元音符号 | [ɿ、ʅ]不称为现行官方IPA元音符号，依据Lee与Zee Notes及IPA表；不从提取失真的PDF字形重造符号。 |
| 鼻化与鼻尾 | 鼻腔耦合不等于鼻韵尾；不将an/ang或en/eng都简化为完全相同元音+n/ng，相关研究仅据ISCA摘要使用，不引用未核验数值。 |
| 声源与共振 | 准周期F0与共振峰、谐波谱峰分开；短时线性模型有条件。数字共振器的设定频率不等于组合响应精确峰位；F1/F2不是舌头坐标。 |
| 四声 | 调类、五度相对值、Hz轨迹和知觉音高分开。55/35/214/51为常见教学记值，独立指定的合成Hz曲线不声称是其等间隔物理换算。 |
| 上声连读 | 3+3在适当同域条件下首音节升调；非上声前常保留低段；不把所有上声都要求为完整214，不将表面升调每个细节等同词汇阳平。不把多音节序列简化成机械左到右替换。 |
| 一与不 | 常见去声前及非去声前条件、单念/序数例外与本调拼写分开。不采用课程资源中“夹在任意三音节词中都读轻声”的泛化；用数字箭头示实际变调，避免伪装成正词法拼写。 |
| 轻声 | 不固定成第五条F0线或最低音；语境、弱读、时长和音段变化分开。Chen与Xu仅用出版方摘要的弱目标解释，不引用具体人群数值或宣布唯一音系理论。 |
| 儿化 | 花儿的常见单音节儿化不同于女儿的独立ér，不等于附加r声母。F3或F2/F3为声学入口，不据此唯一反演舌形；2024超声研究只按其北方样本解释。 |
| 韵律 | 不把重音只定义为强度，不将疑问句每个音节都改上升调；焦点、语调和词汇声调共同组织。所谓音节等时不表述为每音节物理时长相等。 |
| 方言比较 | 香港粤语p/t/k末尾不释放只按指定描写；昆山吴语气声超过首音节的结果保留F0与韵律词条件，不泛化所有粤语、吴语。地方变体不直接判为病理。 |
| VOT | 定义为周期起点−释放时刻，有正负。12/65ms为人工事件不是b/p的群体均值或诊断界；塞擦音须交代摩擦阶段的计量约定。 |
| 自动测量 | 无周期区F0记缺失而非0；倍频跳跃不自动等于音系变调。窗长、窗形、网格、带宽分开，Burg模型不当直接解剖测量。 |
| 感知与应用 | 检测、辨别、识别和分类分开；机会水平与混淆表保留。合成谐波调形不冒充自然ma，元音样共振合成不当标准读音。 |
