## 研究问题与范围

面向本科高年级、研究生与听觉研究读者，解释相位延迟和群延迟的数学区别、局部窄带含义、测量及常见误读，并连接耳蜗/OAE、电声与助听器、双耳同步和神经记录。一般理论以线性时不变系统为前提；非线性耳蜗、DPOAE和时变算法的应用另注明条件。排除光学超光速讨论、完整群延迟均衡算法综述和商业产品排名，不给临床通用阈值。

经典定义不限年份。近期检索关注2023-01-01至2026-10-27；正文纳入与问题直接相关的2024年耳蜗模型、2024年助听器模拟及2026年原型设备自声研究。这个日期表示本次检查范围，不表示已覆盖该时段全部文献。

## 已核实的关键边界

1. 相位延迟依赖相位分支；恒定2π平移保留群延迟但改变相位延迟。相对时间参照改变则会同时改变两者。
2. 恒定群延迟与相位延迟相同还涉及截距条件；不宣称所有FIR天然线性相位。
3. SciPy `group_delay` 的频率轴可用Hz，返回延迟仍为样本。在线文档版本与本地数值执行版本分别记录。
4. 前后向处理的幅度平方关系限定为实系数滤波器的理想内部响应，有限记录需另处理边界。单次线性相位FIR延迟补偿与前后向两次滤波分开说明。
5. OAE固有源干涉不等于随机测量噪声；DPOAE扫频轴不能直接当作一般LTI系统输出频率轴。
6. Roth摘要把−18.1到−14.7 dB SNR称作decrease，数值方向与该词不符；正文只用全文支持的表现受损/单侧与双侧条件差异，不沿用该措辞或制造额外定量结论。
7. 2026研究Table 2的两两比较在多重校正后不显著；Figure 6的额外问卷偏好评分则支持0.5 ms相对10 ms。Table 5中部分属性显著，不能写成全部自声质量项目均显著。研究SRD预测不显著，与2024模拟研究不同。

## 同日补强：工程意义、“群”与窄带条件

根据用户阅读反馈，导言补充频带间相对时间关系的工程动机；“群”增加相邻双音形成慢变因子的恒等式，再从相位差/频率差的差商连接群延迟导数。持续双音只用于解释拍音，明确不把它当作孤立音包。生成脚本用两频率复响应直接计算的输出，交叉核对三角恒等式，并检查频率间隔缩小时差商趋近解析群延迟。

窄带部分明确区分数学定义和包络平移解释：定义本身不限制输入带宽；用单个中心频率值表示整个包络移动，才需要带内幅度近似平坦、相位近似线性。宽带信号仍可用整条群延迟曲线分析，理想纯延迟可完整平移宽带信号。

工程部分新增四类任务对照：瞬态保真、滤波器组/多路合成、双耳/多声路同步及实时等待。区分延迟大小、频带内起伏和通道匹配，并说明斜率相同仍可保留常数相位差。此次未增加或改变图示内容，来源仍为17项，审阅状态维持Draft。
