- 北京语言大学2011年报道取得完整网页；中科院学部《马大猷传》网页取得前言、目录及作者介绍。2017年声学所报道阅读官方已索引全文，URL中的2021是迁移路径，事件与发稿按正文2017年处理。

- 1974年、2005年论文及2024年研究只读到相关原文的官方索引段落，不声称逐页通读。1974年PDF识别为6页，截图获取超时，未完成其扫描页的视觉核对，因此未抄录原图、完整公式或统计曲线。

## 接入与验收范围

新增人物词条、独立参考注册模块、6项关系及证据映射记录。现有人物页面按`kind: person`自动收录；主导航补充人物入口。初次运行`pnpm check`发现既有人物稿被内容schema拒绝，因此补充`person`枚举、标签及既有`researches`关系类型。初次失败发生在新增词条之前，错误对象为`albert-bregman`。

旧工作区的关系还引用了10个缺失节点（包括`phonetics`、`psychoacoustics`等），属于本次前已有的接入问题。本次新增关系的端点全部存在，不补造无关条目、不删除其他人物稿的关系。原工作区的检查、构建与页面核验结果见 [draft-validation.json](draft-validation.json)。

词条为`depth: in-depth`、`status: draft`；没有真实具名专业审阅，不填写审阅人和审阅日期。
