# 原始来源与核查范围

本篇为《微分方程与动力系统》的配套深度课程，关注局部与全局结构、振荡及混沌证据；不是系统综述、一般分岔定理的完整证明集或听觉临床应用评估。来源共18份：15份MIT作者课程讲义、1份原始听觉建模论文作者稿、1份原作者方法综述及1份官方求解器文档。原文件、文本提取与SHA256见source-index.json。

- nd-scalar/phase/normalforms：局部平衡、势函数、正规形、非退化和结构约束。本文立方偏置、折点、两参数折线、瓶颈时间及吸引域另行推导，不声称全部来自某张源图。
- nd-hopf/hopf-proof：超/亚临界、Hopf额外条件与环的折叠。Rothman讲义鞍结小节把mu>0处误写为mu<0，本文按方程独立推导，不沿用该符号笔误。五次饱和是显式选择的全局教学扩展，不由一般局部Hopf定理推出。
- nd-cycles/weak：Van der Pol能量、平均、慢快形式、Duffing弱非线性方法；示意图或软件输出不替代理论。本文谐波平衡的根不标作真实稳定解，强迫相位和弱扰动条件单独说明。
- nd-poincare：截面、返回和周期稳定性。Hopf二维单周期矩阵另与解析横向乘子exp(-2muT)核对；图中没有把暂态拿来作为已知周期轨道。
- nd-cochlea：Camalet等2000年原始临界振荡听觉模型作者稿。本文仅推导指定共振Hopf正规形的立方根响应，未复现其分子马达、钙反馈或自调谐模型，也未将图3视为实测听阈。
- nd-maps/intermittency：Logistic周期乘子、倍周期、窗口、间歇与准周期。典型r=4指数与特殊初值、有限精度的区别保留。
- nd-strange/dissipation/lorenz/lyapunov：吸引集合、相体积、Lorenz、变分和重归一化。有限QR结果不冒充混沌定理；指数求和一致只核对体积增长。
- nd-spectral/surrogates：谱与时间序列的证据边界、观测与替代数据零假设。图10不是替代检验结果；未训练状态重构器或从实测数据估计混沌维数。
- nd-ivp：官方stable文档在2026-11-02的接口语义快照，运行SciPy1.17.1。t_eval不等于内部步长，局部误差容差不等于真实全局误差界。

相位锁定一节的Adler型方程为独立指定、解析可解的教学约化模型，锁定范围及滑移率直接验算；不声称所有弱耦合系统都精确服从同一正弦方程。Rosales资料按MIT2004课程归档引用，文件内部未标明年份的部分不另猜出版时间。图形全部从自身程序生成，没有复制源文图形或转述源文实测性能。
