# 来源范围与复核路径

本篇是基础课程深度词条，不是系统综述、所有小波算法的实现手册或当前性能排名。原始来源与官方文档共17份，原文件缓存与SHA256见source-index.json；下载失败或不完整的文件未作为成功记录保留。

- wa-daubechies：原论文导言的连续/离散小波、可容许性、框架与正交基，以及后文紧支撑构造和消失矩。本文正尺度、实母小波、角频率的CWT因子另外解析推导，并以Mexican hat和Gaussian输入独立核对；不混用论文的全尺度或其他傅里叶归一化。
- wa-mallat：多分辨近似、嵌套空间、细节正交分解和金字塔滤波。理论分辨率j与软件层号J的方向区别明确写出；有限Haar矩阵与二通道相位约定另行构造验证。
- wa-torrence：尺度与周期、Morlet、有限记录影响区和噪声背景。本文采用精确零均值修正Morlet、物理dt求积和特定相对功率；不冒充重现其气候数据、显著性或完全相同归一化。
- wa-donoho：斯坦福官方仓库1992扫描报告，39页PDF；视觉核对PDF第3–8页（正文第1–6页），覆盖高斯模型、软阈值、阈值尺度及结果条件。无可用OCR文本，不将pypdf空输出声称为全文阅读。本文用有限向量能量约定，说明报告函数估计归一化中的1/√n与离散噪声系数阈值不同。仅引用报告版本，未声称读取1995期刊版。
- wa-coherence：原论文公式8–10、时间与尺度平滑、相干定义及Monte Carlo显著性。本文未实现一套完整相干估计器，也未用地球物理数据作为听觉证据。
- wa-pitfalls：交叉谱解释、背景过程、显著性陷阱。独立检验概率只是另行指定的概率算例，不替代相关小波系数的自由度和簇检验。
- wa-scattering：固定小波、模与平均构造的定位；不报告识别性能，不声称对任何变形都完全不变。
- 十份PyWavelets官方文档：母小波属性、CWT、DWT/IDWT、延拓、SWT/ISWT、小波包、阈值及系数排列。stable链接为2026-11-02快照；实际运行PyWavelets1.8.0，未使用较新接口中的precision参数。

原始代码、图形与信号均另行编写。物理CWT使用直接卷积求积；PyWavelets CWT另用于核对sampling_period语义，两种离散化不被声称逐点完全一致。这里只作定义、来源与可复算性核查，外部专业审阅待完成。
