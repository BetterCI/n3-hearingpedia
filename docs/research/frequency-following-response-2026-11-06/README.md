## 证据如何进入正文

| 问题 | 主要来源 | 编辑结论 |
| --- | --- | --- |
| FFR是否“纯脑干” | Coffey 2016/2019；Bidelman 2018；Gnanateja 2021 | 保留皮层下优势的条件性证据，同时说明皮层发生源；不设普适频率分界 |
| 极性加减测到什么 | Aiken与Picton 2008；Krizman与Kraus 2019 | 操作性分量不等同纯来源；相减也可保留线性伪迹 |
| 小幅度如何解释 | Tichko与Skoe 2017 | 多源相位相消可产生低谷；图1为独立两源解析例子 |
| 平均和抖动 | 2019方法教程；独立数学推导 | 列出独立等方差与高斯抖动假设、单位及可计算端点 |
| 相位统计偏差 | Vinck等2010 | 区分平方PLV的期望、PPC和单神经元向量强度；不把试次当受试者 |
| 肌源混杂 | Bidelman等2024 | 说明眼位、参考电极和刺激条件；不据此否定全部既往经验效应 |
| 经验／注意 | Krishnan 2005；Song 2008；Varghese 2015；Whiteford 2025 | 群体关联、前后变化、因果训练效果和行为中介分开；纳入阴性证据 |
| 重复性 | Song等2011 | 条件限定的两次记录研究；均值无差异与个体一致性分开 |
| 连续语音 | Schüller等2024 | 4–11 ms与20–58 ms窗口属于该分析，非普适解剖分界 |
| 快速采集 | Huber等2025 | 所核查版本为预印本；年轻成人128 Hz锯齿波不直接推广到婴儿或动态语音 |
| 发育比较 | Danielou等2026 | 17名足月新生儿、21名成人；基频／共振峰指标分别解释，不制造诊断常模 |

2025年Whiteford等多中心预注册研究由前向引用发现，再核查正式Nature Communications版本；其阴性结果加入正文，避免只介绍历史阳性研究。Rapid FFR通过PMC、PubMed及作者机构目录交叉确认所见版本仍是预印本。

## 原创图与复算

四张图均为本站原创教学计算，无人体数据、无转载论文原图，不是论文结果复现或临床常模。图为SVG主文件加1400×630 PNG预览；点击可查看原图。中文字体优先Microsoft YaHei，跨平台可用Noto Sans CJK SC。

1. 两等幅来源，延迟差2 ms；核验250 Hz相消、500 Hz幅度2。
2. E为100 Hz、幅度1；T与A为500 Hz、幅度0.5与0.6，延迟8 ms与0 ms。两种极性按理想代数构造；相加恢复E，相减保留T+A。8 ms恰为500 Hz的四周期，说明延迟不同仍可在该频率同相。
3. 噪声独立等方差下标准差按1/√N下降；高斯抖动的相干幅度按特征函数计算，0.2 ms在100/1000 Hz分别保留0.992135/0.454041。
4. 独立均匀随机相位，种子20261106，每个试次数5000次模拟；验证平方PLV均值与1/N在5个蒙特卡洛标准误内一致。这里标准误用于数值核验，不是人体实验误差线。

复算：`python public/code/frequency-following-response/demo.py`。参数、断言及结果保存在 `public/code/frequency-following-response/validation.json`。公式中的秒／毫秒、Hz、弧度、电位、幅度比／功率比及维度逐项核查。
