# 《线性代数》：从听觉与声学例子学习数学

## 深度升级

正文按六个问题组织：录音为何是向量；两种纯音的线性组合、基与坐标；用内积与投影提取频率分量；两支麦克风的矩阵方程、逆与秩；直达声与延迟副本的最小二乘估计；双通道共同／差异模式的特征分解。PCA 与 SVD 从相同声学模型延伸，不另堆抽象矩阵例子。在此主线中展开非正交频率的 Gram 矩阵与联合估计、正规方程与薄 QR、65 抽头反射模型的独立验证、PCA 坐标重建，以及小奇异值与正则化强弱对照。现版约 10,500 汉字、10 节、25 个小节；练习置于文末。

现版共六张教学图与四个试听音频；音频、图片和公式均嵌入自包含预览 `docs/drafts/linear-algebra-preview.html`。离线可读、可播放；完整实验脚本也嵌入离线下载链接，交叉词条链接指向正式网站。

## 深度实验参数与数值范围

非正交对照：8000 Hz，1000／1100 Hz，N=8 或 80，合成系数 0.6／0.3；无噪声。八点分别投影约为 0.89785／0.84454，联合拟合返回设定系数；八十点的整周期条件仅适用于本设定。

噪声对照：对称矩阵对角为 1，交叉增益为 0.5／0.95／0.995；真实瞬时声源 [1,0.2]，误差为 [0.001,−0.001]，另比较共同方向误差 [0.001,0.001]。条件数为 3／39／399。对 rho=0.995，预设 lambda=1e-5 和 1e-3 展示抑制与过度缩小，不将教学真值用于实际调参。

长反射对照：种子 20261101，输入 2048 点、标准差 0.25；噪声标准差 0.02；65 抽头；丢弃前 64 点。训练设计 1984×65、秩65，QR与lstsq一致。独立验证观测残差 RMS 约0.02019、已知无噪声输出预测误差 RMS 约0.00298。固定常量激励的稳态设计秩为1，单频激励在绝对阈值1e-9下秩为2。软件版本、阈值和全部数值见实验结果文件。
