## 论断核对

- PRO定义以FDA通用定义为依据，仅采用本人报告、不替代解释的概念，不搬用肿瘤试验规程。
- APHAB为24项、四分量表；global采用EC/RV/BN，AV单列。原始开发摘要与原开发实验室手册相互核对。
- SSQ12与49项版不同；约0.6分是开发研究资料的平均差，不是个体校正值或统一换算。
- RHHI18项与RHHI-S10项，不沿用未经支持的双维度解释；各种满分与分数方向分开写。
- COSI的变化程度与最终能力不同。IOI-HA七项1—5、总分7—35；是多维轮廓。SADL15项四领域；费用项目、缺失与反向题按原版说明。
- 相关不等于一致：图2只作代数示例，无随机误差，不输出临床一致性限。
- MDC公式明确独立、等误差、近似正态等前提；SEM不是均值标准误。SEM=3仅为教学假设，MDC约8.32不用于任何真实量表。
- 中文版本与香港常模分开；不宣称简繁转换完成跨文化验证。
- 核心结局集为共同最低集合，保留个体目标及本地验证边界；未照搬网页中简化百分比判据。
