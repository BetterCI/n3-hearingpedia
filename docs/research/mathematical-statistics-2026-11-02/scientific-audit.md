## 主要科学论断与核对边界

| 项目 | 核对与处理 |
| --- | --- |
| 总体与目标参数 | 人群、任务、刺激与差值方向明确；平均差、个体差异和正确概率不混同，阈值dB平均不称能量平均。所有听者数据均虚构。 |
| 模型与样本 | 模型为分布族，独立与同分布分开，说明可识别性及随机变量与观察值区别。随机抽样与随机分配不混为一谈。 |
| 统计量与抽样分布 | 统计量为不含未知参数的可测样本函数；估计量与估计值分开。SE为估计量抽样SD，样本SD不直接变成置信区间或均值SE。 |
| 均值与样本方差 | iid有限二阶矩条件下推导无偏性与均值方差。n−1的推导不要求正态；正态的枢轴分布另加条件。 |
| 估计性质 | 无偏、逐参数一致、MSE与偏差平方加方差的定义清楚；不把无偏宣布为所有损失下最优。 |
| 矩与最大似然 | 正态方差矩估计/MLE分母n，对比无偏估计n−1。似然固定数据而改变参数；不把密度或似然直接当后验概率。MLE有限样本和边界情形保留。 |
| 充分性 | 条件分布定义和非负因子分解按共同控制测度限定；伯努利总数只在固定n、iid同p模型下充分，不据此删除学习或疲劳的时序。 |
| Fisher信息与CRLB | 得分均值为零、积分求导交换、参数内点、支持集条件与有限正信息写明；标量无偏方差下界不推广到所有有偏估计量，不称Fisher信息为bit熵。 |
| t与卡方 | 解释独立标准正态平方和、样本均值与方差独立及t比值，精确t区间限iid正态差值，自由度n−1。CLT不设统一n=30保证。 |
| 区间解释 | 置信程序覆盖、贝叶斯后验概率、个体预测三者分开。有限40批模拟39次覆盖不冒充定理证明或要求恰好95%。 |
| 比例区间 | Wilson由得分方程反演，非任意p下恰好95%覆盖；不把不同听者/难度或自适应试次直接并为同p二项样本。 |
| 检验与p值 | H0/H1、拒绝域、第一/第二类错误与功效按参数定义。t例双侧尾部明确，不称p为H0后验概率、随机原因概率或效应大小。 |
| 效应与等效 | 原单位效应与配对dz分母明确；TOST预设有意义等效界，两个5%单侧对应90%双侧区间，未拒绝不推断等效。 |
| 配对与Welch | 配对差的方差保留协方差，跨听者独立与正态差值是精确条件。Welch自由度为近似，不当所有小样本异方差分布的精确t。 |
| 层级与伪重复 | 研究目标、实验单位与观察单位分开。零均值随机截距的方差、ICC与设计效应按等簇等相关模型推导，27.9只为均值方差等效量，不当听者数或自由度。 |
| Bootstrap | 重抽听者差值或共同配对索引；百分位区间为教学选择，无小样本覆盖保证，更多重抽不等于更多听者。 |
| 符号翻转 | 需每对独立等概率交换及相应尖锐零假设，或零对称分布；仅零均值不足。完整4096配置按绝对均值尾部计16种，重复配置按概率权重保留，随机子集与穷举区分。 |
| 功效与样本量 | 另设总体SD=3 dB，不与虚构样本SD混用。非中心t参数与双侧功效核对，已知方差正态近似32对与未知方差t的34对分别说明，不给真实研究统一招募数。 |
| 回归与F | 满秩、条件零均值、同方差及精确t/F需要的正态误差分层写明；嵌套模型pR<pF<n、残差自由度、总体F不等于每对显著。QR/SVD用于实际求解。 |
| 预测与诊断 | 均值区间与独立新观测的额外残差项分开，图带是点态，不是同时覆盖。残差、异方差、相关、外推、选模与听者间验证边界保留，不把年龄回归说成因果证据。 |
| 二分类与心理测量 | logit为对数优势，不是百分点；强迫选择另设机会下限、失误上限、位置/尺度，参数条件写明，有限MLE分离问题保留。 |
| 多重比较 | 独立20零假设的0.642只限指定条件。FWER与FDR定义不同；Holm仍需有效p值，BH需独立/PRDS，任意正相关不自动满足，BY的一般依赖条件保留。 |
| 贝叶斯 | a,b>0，Beta(1,1)为演示先验，后验Beta(61,21)、均值及等尾区间核对。不称均匀先验跨参数化无信息，不把FDR当单个后验概率。 |
| 设计与报告 | 纳入、缺失、排除、停止、校准、分析选择与敏感性须报告；缺失非零，不把软件忽略NaN当缺失机制论证。 |
