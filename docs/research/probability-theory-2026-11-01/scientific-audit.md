## 科学结论

在已明确的独立伯努利、等方差高斯、平稳AR(1)、共享噪声及Beta-Binomial等教学模型内，未发现阻碍作为待审阅课程材料发布的实质数学或声学错误。所有听觉/声学数值都是原创合成与设定，不是人体、设备或临床结果。

| 关键知识 | 定义与解释核对 | 独立计算或反例 |
| --- | --- | --- |
| 概率空间与事件 | 样本空间、sigma代数、概率三公理、补集/交并；四格有无实验先限定有效反应空间 | 有目标与报告有声不是同一事件；四格并非等可能 |
| 随机变量、PMF与二项 | 可测映射、随机变量与实现值；相互独立同概率是二项前提 | 组合计数枚举，概率和1，均值30，方差7.5；图1模拟恰为32次正确，不冒充推断例30/40 |
| 泊松计数 | 固定时长、齐次速率与独立增量假设；lambda为期望计数 | lambda=2的零计数概率与归一化；不把神经不应期忽略为普遍事实 |
| 密度与CDF | 密度是面积而非点概率，有单位；CDF也适用无普通密度的分布 | 正态声压密度峰19.9471/Pa，±0.01 Pa面积0.3829249；独立数值积分 |
| 条件概率、贝叶斯 | 条件方向、正分母、全概率分解、先验与后验 | 160/200为命中率，160/240为后验；先验0.02时后验0.1403509 |
| 独立、互斥与条件独立 | 事件独立、随机变量独立、相互独立与两两独立；不将条件独立推广总体独立 | 两种潜在听者p=0.6/0.9；枚举联合反应得总体均值0.75、跨试次协方差0.0225 |
| 期望、方差、全方差 | 一阶绝对可积、有限二阶矩；线性期望不要求独立；样本与总体区别 | 总方差0.165+0.0225=0.1875；平方幅值平均不等于RMS直接平均 |
| 协方差与平均 | 标准差非零才定义相关；不相关一般不推出独立，联合高斯例外 | X取−1/0/1，Y=X²的反例；用完整16×16协方差矩阵核验平均方差公式 |
| 录音平均与SNR | 固定同相目标、同方差、同一时刻不同记录之间的rho；明确功率比 | 独立标准差0.05，rho=0.5时0.1457738；增益12.0412和2.7470 dB |
| 大数定律与CLT | 充分条件、依概率/依分布、有限方差、非单调、CDF收敛 | 二项精确PMF/网格宽与正态作形状比较，不把离散变量称连续密度 |
| 随机过程 | 实现/总体，宽平稳/严格平稳，自协方差/自相关；白与高斯分别定义 | 平稳AR(1)方差递推与相关phi的绝对滞后次幂；随机常量过程反例说明宽平稳不保证遍历 |
| 检测与ROC | 证据单位不等于Pa，等方差高斯与判据；敏感度和倾向分开 | 独立积分得F=0.1586553、H=0.6914625；两间隔证据差方差2，正确率0.8555778 |
| 心理测量函数 | logistic、机会水平、渐近上限、位置与尺度；lambda是上限差，不直接等于走神率 | alpha=0对应0.74；75%反解0.2501448 dB，并正向代回 |
| 似然与推断 | 固定数据比较参数，非参数概率；MLE边界不表示确定；CI/可信区间/p值分开 | Wilson端点满足score等式；Beta后验直接多项式积分验证归一化、均值与等尾质量；二项尾概率由组合数直接求和 |

## 资料与访问范围

完整书目在 `src/data/probability-theory-references.ts` 及复用的参考注册表中，正文共17项引用。所有借用内容为概念对照与解释，没有转载图或长篇摘录。

- MIT 6.041/6.431，2006年Dahleh讲义：L1概率空间主题，L2条件概率与贝叶斯，L3独立性，L5离散变量，L8连续变量，L13条件矩，L14协方差，L15弱大数，L22中心极限。通过MIT官方PDF读取可检索相关段落；部分幻灯片的公式文本提取不完整，正文公式由自主推导、官方分布定义和独立数值核对，不冒称全部扫描公式已经OCR核对。
- Oppenheim与Verghese的MIT 6.011完整讲义：第9章9.1/9.3/9.6的过程实现、联合高斯、WSS、遍历性；第10章10.2.3白与有色过程的整形滤波。未声称读完250页。
- David Heeger的NYU作者讲义：内部证据、判据、命中/虚报与ROC；具体d′=1.5教学例为自主计算。
- Wichmann与Hill，2001，原文第1293—1296页：反应模型、心理测量函数、渐近线及拟合框架。复用 `speech-reception-threshold-wichmann`，不重复注册同一论文。logistic参数与反解为原创。
- NIST Wilson区间页面：实际读取公式与术语说明，复用 `psychoacoustics-nist-wilson`。强调名义覆盖率并非离散有限样本处处恰为95%。
- SciPy官方binom、poisson、norm、beta文档：支持参数、分布、CDF/SF/PPF接口。在线文档显示1.18.0，本地实际执行版本1.17.1；不使用新版本才有的接口。
