## 结论

主要定义、给定模型内的公式与原有数值算例正确，但发现若干条件表述过强，以及任务/测量对象可能混淆之处。已按下表修正。新版本继续保留Draft与空专业审阅者；本轮属于AI辅助数学、声学和来源复核，未替代具名专业审阅。

| 发现的问题 | 判断与修正 |
| --- | --- |
| “只有互斥事件才可直接相加”把充分条件说成必要条件 | 加法成立的确切条件是交集概率为0；互斥可保证这一点，但不是唯一情况。改为同时说明两者。 |
| “独立同概率才满足二项分布”逻辑过强 | 独立同概率是标准推导的充分条件，不能由总数的二项分布反推各次独立。正文去掉必要性暗示，独立枚举构造了反例。 |
| “联合高斯……才足以”容易被读成独立所必需的分布 | 改为“若联合高斯，零协方差足以推出独立”，并明确这不是所有独立变量的分布要求。非高斯伯努利对也可满足该方向的等价关系。 |
| 高斯噪声滤波的条件不够明确 | 明确输入为联合高斯、滤波为固定线性处理；不把逐点边缘高斯或非线性平滑视为同一条件。 |
| 平均噪声的理论SNR与实测比值未充分区分 | 明确同一窗口内的确定信号均方值与噪声均方值的期望之比；12.04 dB是理论增益，不是随机比值的期望，也不是每段有限音频的精确增益。 |
| 有／无检测与两间隔正确计分之间的样本空间切换 | 在首次切换处明确目标间隔与选择间隔的样本空间，避免沿用前一任务的结果含义。 |
| 心理测量函数的正确概率与“报有声”概率 | 明确本例函数采用两间隔正确率；有／无任务的阳性反应率、虚报率与总正确率不能混用，后者还取决于目标呈现比例。 |

## 用反例审查充分条件与必要条件

1. **不互斥但概率可直接相加。** 令U在[0,1]上均匀，A=[0,1/2]，B=[1/2,1]。交集是单点{1/2}，不是空集，但其概率为0。因此P(A并B)=1=P(A)+P(B)。
2. **总数二项但各次依赖。** 按000、001、010、011、100、101、110、111排序，对三次二值结果指定概率[2,2,1,3,3,1,2,2]/16。各次成功概率均为1/2，总数K=0、1、2、3的概率为[1,3,3,1]/8，恰为Binomial(3,1/2)；但P(X1=1,X3=1)=3/16，不等于1/4，故不独立。已用脚本枚举核验。
3. **独立无需高斯分布。** 两个伯努利变量在协方差为0时，P11=pX·pY，其余三格由边缘概率确定，也分别等于乘积。因此在伯努利对这一特定族中，零协方差也推出独立。它不推翻一般分布下“不相关不等于独立”，而是否定“必须高斯”的误读。
4. **边缘高斯还不够。** 令X为标准正态，独立符号B以等概率取±1，Y=BX。X与Y的边缘均标准正态，Cov(X,Y)=E[B]E[X²]=0，却总有Y²=X²，故不独立、也不联合高斯。这是对正文条件区别的解析检查，没有把它当作听者实测现象。
