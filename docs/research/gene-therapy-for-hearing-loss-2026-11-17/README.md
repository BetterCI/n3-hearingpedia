## 范围与交付

目标是解释听力损失基因治疗的机制、递送与证据评价，以 OTOF 人体研究为主线；其他基因的动物研究用于说明补充、失活与编辑的区别。不是全基因目录、诊疗指南或全地区监管综述。

- 正文：`src/content/concepts/gene-therapy-for-hearing-loss.md`，约 6,600 个中文汉字，10 个一级章节。
- 16 项来源：14 项原始研究摘要与书目，2 项美国官方监管材料。具体用途见 `source-map.json`。
- 三张原创教学图：双载体递送、疗效层级、假设阈值计算；SVG 与 PNG 位于 `public/figures/gene-therapy-for-hearing-loss/`。
- 绘图源码：`scripts/generate-gene-therapy.py`。图 3 的四频数据为教学假设，平均值 97.5 与 50 dB HL，差值 47.5 dB。
- 接入现有参考注册表、6 条知识关系、耳蜗与内毛细胞的正文链接及证据映射。

## 检索与选择

使用 deep-research 技能的 OpenAlex 脚本进行主题发现（OTOF gene therapy，12 条），以 Wang 2024 双耳试验 DOI 10.1038/s41591-024-03023-5 为种子，向前与向后各扩展 20 条。原始结果分别保存为 `openalex-search.json`、`seed.json`、`backward.json`、`forward.json`。扩展用于发现相关机制、较新人体报告和不同技术路线，不代表穷尽全部文献。

结合已有词条中的 Roux、Lv 和 OTOF 研究，使用 Europe PMC 按 DOI 或题名获取正式元数据与摘要。采集脚本为 `collect.py`；单篇 JSON 保留完整 API 返回。追加 Lv 精确题名及 Anc80L65 DOI 检索的结果也保存在对应 JSON。部分 DOI 检索无结果后改用精确题名；不得将空结果解释为论文不存在。

核验时间截至 2026-11-17；历史机制研究从 2006 年起，近期重点为 2024—2026 年人体研究。按研究对象与问题作内容筛选：Roux 支持突触机制，两项 2019 双 AAV 研究支持表达及功能恢复，Tmc 补充、显性失活和隐性碱基编辑支持策略差异；成年人毛细胞再生的论断未纳入，采用成年小鼠原始研究说明边界。2025 Anc80L65、DB-OTO 及 2026 长随访和对侧耳再次给药报告回答不同临床问题。

`screening.json` 记录最终纳入来源的相关性与用途，不冒充对全部发现池的系统筛选。综述、评论和新闻用于定位原始材料，未纳入疗效证据；新生小鼠前庭椭圆囊重编程不作为成年耳蜗功能恢复证据。没有计算跨研究合并疗效或做正式偏倚风险评分。

## 来源访问与证据边界

原始论文实际读取范围为 Europe PMC / PubMed 摘要与正式书目信息；出版方网页搜索结果用于交叉核对题名、日期和研究范围。没有声称逐篇阅读全文或补充材料。FDA 公告与官方说明书的适应证、操作风险和加速批准条件通过官方页面核对。美国批准不代表其他地区批准、供应或报销。

Lv、Wang、Jiang、Fan 报告同一注册号 ChiCTR2200063181，按同一试验计划的相关报告处理，不相加参与人数。DB-OTO 在线发表于 2025 年，正式卷期为 2026 年，正文明确区分；数据库参考条目采用正式卷期年份。最长 2.5 年随访不能写成全体 42 人均观察 2.5 年。

保留有限或不完全恢复：Al-Moyed 的胞吐与囊泡补充恢复并不一致；Yeh 的听觉改善为暂时性；DB-OTO 预设阈值达标人数与平均正常敏感性人数不同。Fan 是对侧耳再次给药，不能外推同耳补打。
