## 原创图与计算

运行 `python scripts/generate-audiology.py` 可生成四组 SVG 与 PNG。脚本需要 numpy、matplotlib 和中文字体；Windows 使用微软雅黑，其他系统可安装 Noto Sans CJK SC。SVG 字体转为路径，方便独立查看。

筛查算例的 10000 人、1%／10%、灵敏度 90%、特异度 95% 都是教学设定，不是实际人群或设备数据。脚本分别用四格人数和贝叶斯公式核验 PPV，并检查人数守恒及设定的灵敏度、特异度。`figure-verification.json` 保存结果；其余三图为概念整理，没有病变定位或诊断判读规则。

`article-summary.json` 保存章节、引文和链接统计；`validation.json` 保存构建与页面检查结果。正文、引文登记、学习路径、知识关系及证据索引一起保留在本地 `codex/audiology` 分支，等待维护者确认。
