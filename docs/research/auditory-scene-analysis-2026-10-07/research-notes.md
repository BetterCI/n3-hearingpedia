# 听觉场景分析：本地稿研究与核查记录

研究日期：2026-10-07。目标是为通用专业百科新增核心词条；本轮只写本地审阅稿，不改线上内容。

## 范围与方法

纳入同时分组、序列分组、交替音声流、连续性错觉、时域相干、随机图形—背景、注意、听力损失和计算模型。基础文献不限制起始年代；近期补充检索范围为 2024-01-01 至 2026-10-07，选择与知觉组织直接相关且能够核查的方法或结果，不追求穷尽。

先进行主题及作者检索，再以 Elhilali 等 2009 年 Neuron 论文为种子，使用 deep-research 的 OpenAlex 脚本解析论文，并向前、向后各扩展一层，每方向取回 14 条。该数量为发现窗口，不代表完整引文网络，也未依靠引用数决定质量。检索原始记录存于 openalex-seed.json、openalex-backward.json、openalex-forward.json。

对候选进行人工语义筛选，依据研究问题、刺激、任务与实际结论决定是否纳入。摘要和书目信息通过 Europe PMC、PubMed、出版社或作者页面核查；模型与工具链接核查官方 README。重要结论区分人类行为、动物神经记录、神经表征、理论框架与工程模型。

## 写作边界

- 声学输入叠加式属于教学模型；不是生理实现假设。
- 分组、注意、理解、努力分别解释。声流分离可帮助或妨碍不同任务。
- 时域相干模型是一种重要框架；相关系数只是教学量化，不能代替完整模型。
- 未把宽带任务的无显著组间差异解释为所有听力损失者正常，也未把部分人工耳蜗结果解释为统一缺陷。
- 2026 年论文的四人闭环使用颅内信号；听力损失群体评价别人的解码输出，不是用自身脑信号控制。
- BASS README 明确指出不是完整可直接执行软件包；本轮未运行 BASS、AMT、STSstep 或 Asteroid。

## 配图与验证

5 张原创矢量图及 PNG 使用 NumPy/Matplotlib 生成，中文字体及白底学术插图风格。每张图与题注明确物理刺激、候选分组和知觉推断的区别。没有实际音频波形；连续性图纵轴是存在状态，不是幅度。所有参数和随机种子见 generate-figures.py、figure-verification.json。

图形—背景两条件每帧均为 8 个成分，避免凭成分总数增加识别图形；固定重复索引为 5、11、17，1 s 后出现。未合成音频或验证听者知觉。交替音连接线不是扫频。图 1 两组共享 600 Hz 但时间不同，方框只围蓝色事件。

本地预览采用现有 Astro Markdown 处理器和 KaTeX，核对引文编号、锚点、图片数量及公式渲染。概念交叉链接在预览中指向线上已有词条；原始 Markdown 保持发布使用的相对路径。当前无浏览器交互检查工具，因此不声称浏览器布局已逐屏验证；图片 PNG 已逐张目视检查。
