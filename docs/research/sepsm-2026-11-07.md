# sEPSM 与 mr-sEPSM 词条核验

## 取证范围

以 2011 年原模型和 2013 年多分辨率扩展为主线。按方法、输入、实验操纵和所测人群筛选。2026-11-06 以 `speech based envelope power spectrum model fluctuating maskers` 检索 OpenAlex（取 15 条），从 [2013 年论文](https://openalex.org/W2082668798) 回溯 30 条、前向取 40 条，按 DOI、其次按 OpenAlex ID 去重得到 81 条候选。定向补查相位失真、周期性和截至 2026-11-06 的人体资料。候选集合用于发现文献，未对 81 项逐篇进行全文评审。

- 两篇 JASA 原始研究确认模型对象和验证条件。作者 2014 年学位论文第 2、4 章用来交叉检查归一化、窗长、理想观察者及图 4.3–4.5，对应同一研究系列。
- AMT 1.6.0 两个主函数及官方演示核对实现。2016 年相关型变体和 2019 年周期性研究用于界定功率后端的局限，2026 年德语矩阵句测量仅用于说明时间与空间操纵需分开。
- 书目条目分别标注摘要、全文相关段落或实现文档的访问层次；词条保留 Draft，未登记专业审稿人。

## 数值复核

使用 MATLAB R2024a 和 AMT 1.6.0。当地安装的两个模型入口及官方 demo 与 AMT 官网相应的版本化源码页逐文件比对（忽略行尾编码与首尾空白）。模型文件和样音的原始 SHA-256 为

| 文件 | SHA-256 |
| --- | --- |
| joergensen2011.m | 35fdb124068edbbfde8a273b4788efa6bf6913eda62203b6980a4755b1bc2b7f |
| joergensen2013.m | 000fd6120a4e6d1e56b0deabeb4994bce2c49da5e97836ca7fd5ab29c1cce93e |
| Counting-16-44p1-mono-15secs.wav | 7494cb83029e6f579a786106c5689092ebbe2ae0358216e47d719cbbd90c3e7c |

在已启动 AMT 的 MATLAB 环境中，将 [示例目录](../../public/code/sepsm) 加入路径。运行 `compare_sepsm()` 和 `compare_sepsm('white')`。每种载体含平稳及 4 Hz 起伏条件，各有五档声学信噪比。读出两版本的线性 SNRenv，省略理想观察者参数。图 3 仅展示匹配载体。没有复用 CLUE 的拟合参数，也没有做听者实验。已发布的 CSV 不包含录音样本。

绘图使用 Python 3.11、NumPy 1.26.4 和 Matplotlib 3.8.0。从仓库根目录可执行 `python public/code/sepsm/plot_sepsm.py public/code/sepsm/results.csv public/figures/sepsm`。图 1 为解析调幅波，图 2 为名义时间窗，两者独立于 MATLAB 实验。
