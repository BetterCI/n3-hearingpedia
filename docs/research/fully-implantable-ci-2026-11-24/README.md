# 全植入人工耳蜗：证据核验记录

核验日期：2026-11-24。对象为成人全植入人工耳蜗的系统原理、声音传感、供能、临床证据与地区上市状态。正文保留 draft 与 reviewer: null；资料核验不等同于独立临床专家审阅。

## 检索与筛选

以 MED-EL 六人临床研究（DOI 10.1038/s43856-024-00719-0；OpenAlex W4406165538）为种子，保存 seed.json、backward.json、forward.json 与 screening-prompt.txt。反向网络返回10项，正向网络截取12项；网络用于发现资料，不将引用量当作证据质量。近期文献范围为2023-01-01至2026-11-24，另保留2008年早期整机研究和2022年中耳传感研究。

语义筛选：2008年 TIKI 为核心整机历史证据；HUI、SSQ12、HISQUI19和 Nijmegen 量表文献为结局测量背景；助听器使用、污名、植入决策及一般植入装置综述作为背景。正向网络中的压电传感、腔内声压传感、UmboMic固定和双向换能器研究列为相关传感候选，但未经逐项原文核验的结果不进入正文。一般脑机接口、瘫痪神经接口、双模式延迟及材料细胞毒性论文不回答本文核心问题，未纳入证据结论。

补充直接检索三条整机路线、DrumMic、注册记录和监管解释。核心文献由出版社、PubMed/PMC或作者机构摘要交叉核对；部分PMC访问遇到验证页面时，使用可检索的原始摘要和方法结果段，不据此声称阅读全文。正式发表、在线发表及产品发布日期分别记录。相关题目与 DOI 见 src/data/fully-implantable-ci-references.ts。
