**信号与系统**（signals and systems）研究随时间或其他自变量变化的量怎样表示，以及一个过程如何把输入变成输出。信号可以是声压、电压、位移或数字序列；系统可以是电路、房间、换能器、算法或某一层次的生理模型。课程的核心任务是给这些对象建立可计算、可检验的关系，而不是把所有系统预先假定为线性。[1](#ref-ss-intro)

听一段录音时，声源、传播、麦克风、采样和播放已经构成一条系统链。本篇用回声、低通、频谱和混叠解释基本知识，连接[电路原理](../circuit-theory/)、[复变函数](../complex-analysis/)、[线性代数](../linear-algebra/)和[计算神经科学](../computational-neuroscience/)。滤波器设计细节可继续读[FIR与IIR滤波器](../fir-and-iir-filters/)，声学传播的场与边界可读[数学物理方法](../mathematical-physics-methods/)。

配套课程[数字信号处理](../digital-signal-processing/)进一步把这些关系落实为谱估计、滤波器设计、流式分块、STFT重建、多速率与有限精度实现；可在理解原理时同步查阅并复算。

变化率、累积和初值所需的连续数学工具，可配合[微积分](../calculus/)按具体问题补读。

正文从信号图像、单位和小数组建立定义，再讨论变换与实现；复数、微积分、微分方程和矩阵工具可按下方读法逐步补充。十幅图和代码均为独立设定的教学计算，没有录制听者、动物、实际房间或器件，也不把电压或声压模型输出直接解释成感知改善。

反馈如何改变动态、稳定与性能怎样分别判断，以及观测器、最优控制和数字实现的条件，可配合[控制理论](../control-theory/)按需阅读；时延、噪声与执行器限制应进入具体模型。

多尺度局部表示、连续与离散小波、完全重建滤波器组、阈值去噪及小波包，可配合[小波分析](../wavelet-analysis/)进一步阅读；该篇另核查尺度频率换算、边界与相干解释。

随机信号的联合统计、平稳与遍历、相关和功率谱、LTI输出、混叠及Wiener估计，可配合基础课程[随机过程](../stochastic-processes/)阅读；该篇以可复算反例区分总体模型、单条记录和有限估计。

## 阅读准备与独立阅读

**起步知识。** 从函数图像、比例、简单方程和周期波形开始。复数、求和、变化率与累积先作简短解释；微分方程、变换积分和矩阵用于进一步核对推导，可按章节逐步补充。

**随用随补。** x[n]表示第n个样值，Σ表示把指定项相加；例如1、2、3三个样值的和为6。导数表示瞬时变化率，积分表示累积；令j²=−1，复数a+jb的两坐标(a,b)可换算出幅度与相位。冲激响应先看系统对单位样本或理想冲激的响应，连续冲激的严格含义在正文另行说明。

**分层阅读。** 第一遍读信号与单位、系统性质、回声卷积、初始状态和频响图，再看混叠与反馈例子。第二遍核对Fourier、Laplace、Z变换和收敛域；矩阵只是同一关系的一种表示，正文提供标量与小数组计算。相关课程供具体知识点查阅。

## 先确定信号的自变量 数值与单位

### 连续时间和离散时间描述不同对象

连续时间信号x(t)在连续的t上定义，t通常以s计；离散时间信号x[n]只在整数n上定义。若由均匀采样得到，才有 $x[n]=x_c(nT_s)$，其中Ts为采样间隔、fs=1/Ts为采样率。n没有秒的单位，n=80在8 kHz采样下对应10 ms，换成16 kHz就对应5 ms。[2](#ref-ss-dt)[16](#ref-ss-basic-signals)

**离散时间不等于幅度离散。** 一个数学序列可取任意实数或复数；数字设备通常还进行有限精度量化。连续时间也不意味着波形必须光滑，阶跃信号就是反例。画图时把样本用直线连接，只是选择了显示方式，不能据此声称已完成某种物理重建。

若声压以Pa计，那么图的纵轴就应为Pa；音频文件中的归一化幅度则通常不直接等于Pa。须通过校准和声学传递关系连接，详见[测听校准](../audiometric-calibration/)。同一数字幅度不保证耳道内声压相同。

### 平移 缩放与反转要看自变量

x(t−t0)表示延迟t0，x(at)在a>1时压缩时间；x(−t)为反转。这里时间缩放不自动改变幅度。对离散序列，x[2n]只取原序列偶数索引的值；x[n/2]在奇数n处尚未定义，必须说明插零、插值或其他规则，不能把连续公式原样照搬。[1](#ref-ss-intro)

正弦的连续角频率ω以rad/s计，离散角频率Ω以rad/sample计，两者在采样联系下满足Ω=ωTs。离散复指数在Ω与Ω+2πk处给出相同序列。连续正弦只要频率非零就有周期，离散正弦是否存在整数周期还取决于Ω/(2π)是否为有理数。

### 能量与平均功率是数学分类

连续信号的平方积分 $E_x=\int_{-\infty}^{\infty}|x(t)|^2dt$，离散版本为 $\sum_n|x[n]|^2$。有限且非零时称为能量信号。平均功率则用长时间的平方平均，例如
$P_x=\lim_{T\to\infty}(2T)^{-1}\int_{-T}^{T}|x(t)|^2dt$，前提是相应极限存在；平均功率有限且非零时称为功率信号。离散平均功率相应取$(2N+1)^{-1}\sum_{n=-N}^{N}|x[n]|^2$在N趋于无穷时的极限。有限能量信号的该平均功率为0；无限持续的非零正弦有非零平均功率但无限能量。[1](#ref-ss-intro)

这些名称不自动代表焦耳或瓦。若x是声压，平方积分单位为Pa²·s，平方平均为Pa²；换成真实能量或功率还需介质、面积、阻抗和传播条件。用序列近似连续平方积分时，还需采样间隔权重，不能漏掉Ts。并非所有信号都属于这两类，例如持续增长或平方平均极限不存在的信号还需另外分析。

## 系统性质必须分别检验

### 线性指叠加关系 不是曲线看起来直

令系统算子为T。**线性**要求对允许的输入和标量满足
$T\{ax_1+bx_2\}=aT\{x_1\}+bT\{x_2\}$，即齐次性与可加性共同成立。y=2x是线性无记忆系统；y=x+1有直线图像，却因固定偏置不满足零输入产生零输出；限幅、平方和一般压缩器也通常非线性。[17](#ref-ss-properties)

线性可以在有限工作范围内近似成立。例如围绕工作点写增量输出δy≈gδx，是局部小信号模型，不能据此宣布整个器件、耳蜗或神经元对任意幅度都线性。检验应说明刺激范围和误差容许程度。

### 时不变与线性是两个独立条件

**时不变**表示输入延迟后，输出只发生同样延迟。若y(t)=t x(t)，系统仍线性，但绝对时间进入增益，因而时变；y(t)=x²(t)虽非线性，却时不变。固定参数的纯延迟系统为线性时不变，简称LTI。[2](#ref-ss-dt)[3](#ref-ss-ct)

还可以把输入乘以已知载波cos(ωct)。这对输入是线性的，却通常时变；乘法调制会搬移频谱，不能用一个固定H(jω)乘每个原频率而不产生新频率。由此也能看出“线性”不等于“没有频率搬移”，后者还涉及时不变条件。

### 记忆 因果 稳定和可逆各回答一个问题

无记忆系统只用当前输入；纯延迟有记忆。**因果**要求某一时刻的输出不依赖未来输入，允许依赖过去状态。离线文件可以用未来样本处理，实时设备则需考虑缓存和延迟；不能把已知整段录音与实时可实现性混为一谈。

**有界输入有界输出稳定性**（BIBO稳定）要求每个有界输入都产生有界输出。可逆则要求允许输入能由输出唯一恢复。因果不保证稳定，稳定也不保证逆系统稳定或因果。例如纯延迟的信息可保留，但精确抵消延迟需要时间超前；低通的数学逆还可能强烈放大高频噪声。[17](#ref-ss-properties)[18](#ref-ss-lti)

## 冲激响应与卷积怎样描述LTI系统

### 把输入拆成平移的单位样本

离散单位样本δ[n]在n=0时为1，其余为0，因此
$x[n]=\sum_k x[k]\delta[n-k]$。若T线性且时不变，并能在所考虑的信号空间内合法交换求和与算子，令h[n]=T{δ[n]}，得到
$y[n]=\sum_k x[k]h[n-k]$。这叫**卷积**，写作y=x*h。[4](#ref-ss-convolution)

推导中线性允许按输入幅度加权，时不变允许把同一h平移使用。一般线性时变系统则需要依赖两个时刻的核h[n,k]，一个固定冲激响应不够。只有在模型、状态与收敛条件合适时，才可以用“测到一次脉冲响应”预测全部输入。

### 连续冲激是分布 不是无限高的普通数

连续Dirac冲激δ(t)通过对测试函数积分的作用定义，满足抽样性质；它不是某个时刻取“无穷大”的普通函数。若输入输出量纲相同，δ(t)具有1/s量纲，普通冲激响应h(t)也常具有1/s量纲，卷积积分中的dt才会补回正确单位。

连续零状态LTI系统在适当条件下满足

$$
y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau.
$$

τ是积分变量，不是额外物理延迟参数。短声脉冲只是理想冲激的近似；其宽度、面积、频带与设备响应必须一起考虑。单位面积窄矩形的极限与单位高度窄矩形的极限不同，不能只画“越来越尖”而忽略面积。[4](#ref-ss-convolution)

### 回声就是延迟副本的加权和

指定一个离散教学通路h[0]=1、h[40]=0.55、h[96]=−0.25，其余为0。在8 kHz采样下，后两项对应5 ms和12 ms延迟，输出为
$y[n]=x[n]+0.55x[n-40]-0.25x[n-96]$。负系数表示模型中的极性反转，不等于负的声能，也不是所有房间反射都如此简单。

有限序列长度N与M的线性卷积至多占N+M−1个样本。裁剪成与输入相同长度会丢掉部分尾部；频域相乘若没有足够补零，则会产生循环卷积和回绕。互相关用于比较相对位移或共同结构，含共轭及索引约定，与卷积也不能仅凭名称混用。

### 从冲激响应判断因果与稳定

对离散LTI系统，因果等价于h[n]=0对所有n<0成立；BIBO稳定等价于 $\sum_n|h[n]|<\infty$。充分性来自卷积界
$|y[n]|\leq\|x\|_\infty\sum_k|h[k]|$。连续情形在h为普通函数时，对应绝对可积条件；若含直接馈通δ项，应按有限总变差的冲激响应测度处理，不能对δ作普通绝对值积分。[4](#ref-ss-convolution)

阶跃响应是系统对u的零状态输出。离散取u[0]=1时，s[n]=Σ从k=−∞到n的h[k]，故h[n]=s[n]−s[n−1]；连续情况下可在相应分布意义下求导。阶跃响应与冲激响应描述不同输入，实验中差分或求导还可能放大噪声。

## 微分 差分 状态与初始条件

### 同一个方程还需要说明初态

考虑 $\tau_0\dot y+y=x$，其中τ0>0为时间常数，x与y单位相同。取零初态时，它是因果低通模型，h(t)=e^(−t/τ0)u(t)/τ0。阶跃输入x=u的响应为1−e^(−t/τ0)。但若y(0)=y0非零，在t≥0还应加y0e^(−t/τ0)。[3](#ref-ss-ct)

**零输入响应**来自储存的初始状态，**零状态响应**来自输入。二者之和才是全响应。固定非零初态后，只把外部输入映到全输出的算子通常是仿射的，不能再不加说明地使用叠加。看到方程系数恒定，也不足以忽略初始电荷、机械位移或神经膜状态。

取τ0=5 ms，单位阶跃、y0=0.5，则5 ms时零状态部分约0.6321，零输入部分约0.1839，全响应约0.8161。这里τ0不是输入延迟，也不是系统等待5 ms才开始变化。

### 差分递推与模态增长

离散模型y[n]=a y[n−1]+b x[n]在零初态下有h[n]=b aⁿu[n]。a可以是负数或复数；|a|决定增长衰减，辐角决定振荡。a=−0.5产生符号交替的衰减，不能只因波形振荡就判断不稳定。[2](#ref-ss-dt)

当|a|<1时该一阶因果系统BIBO稳定；a=b=1对应累加器，恒定有界输入可使输出增长。数值递推也可能只是某个连续方程的离散近似，参数需要由采样间隔及离散化方式导出，不能随意把连续衰减率当作离散a。

### 状态空间把内部记忆显式写出

连续线性状态模型可写 $\dot{\mathbf q}=A\mathbf q+B\mathbf x$、$\mathbf y=C\mathbf q+D\mathbf x$，q为内部状态，A等为相容维度的矩阵。状态是预测未来所需的内部变量，不必等于直接可见的输出；多个不同状态实现也可能具有相同零状态输入输出关系。[3](#ref-ss-ct)

从电路电容电压、振子位移速度到[生物物理学](../biophysics/)的膜变量，都可建立相应状态描述。线性化、状态可观测性及内部稳定性要单独判断；只拟合外部传递函数，并不保证内部每个自由度都已得到正确解释。

## 傅里叶表示把时间结构展开为频率成分

### 周期信号用傅里叶级数

周期T0的连续信号在适当意义下可展开为
$x(t)=\sum_{k=-\infty}^{\infty}c_ke^{jk\omega_0t}$，
其中ω0=2π/T0，j²=−1，$c_k=T_0^{-1}\int_{t_0}^{t_0+T_0}x(t)e^{-jk\omega_0t}dt$。积分取任一完整周期，t0为任意起点。复系数同时保存幅度与相位；实信号满足$c_{-k}=c_k^*$，正负频率不是两个独立的实声源。[6](#ref-ss-fs)

有限谐波截断会改变波形。以±1方波为例，跳变附近出现Gibbs过冲，增加项数会缩小受影响区域，却不让最大过冲简单消失。按相应收敛条件，跳变处趋于左右极限的平均，而不是保证每一点都恢复原先人为指定的端点值。

级数Parseval关系把一个周期的平方平均与Σ|c_k|²连接。它说明正交展开怎样分配平方量，不允许忽略相位后仍声称保留了全部波形。两个具有相同幅度谱的信号可以有不同的瞬态形状。

### 非周期信号的变换与约定

本篇采用角频率形式：

$$
\begin{aligned}
X(\omega)&=\int_{-\infty}^{\infty}x(t)e^{-j\omega t}dt,\\
x(t)&=\frac{1}{2\pi}\int_{-\infty}^{\infty}X(\omega)e^{j\omega t}d\omega.
\end{aligned}
$$

正反变换的2π因子随约定改变。对足够好的可积信号可按通常积分理解；L²信号需按平方可积意义扩展；无限持续正弦和常数则通常借助分布解释，不能假装它们都绝对可积。[7](#ref-ss-ft)

若x单位为Pa，以上X单位为Pa·s。使用频率f（Hz）时应写e^(−j2πft)并同步改变逆变换约定。不能把横轴ω直接贴成Hz，也不能把两套公式中的2π随意混搭。

### 频谱 平方能量与功率谱要分开

在L²约定下，
$\int|x(t)|^2dt=(2\pi)^{-1}\int|X(\omega)|^2d\omega$。
这连接有限能量信号的时域与频域平方积分。功率信号或随机过程的功率谱密度需要另外定义，并说明平均、平稳性与估计条件，详见[频谱与功率谱密度](../spectrum-and-power-spectral-density/)。[7](#ref-ss-ft)

把时域信号乘以cos(ωct)，在适当条件下得到两个移位频谱各乘1/2；频率搬移的依据是指数乘法，而不是听觉系统凭空制造信息。有限时窗相乘也会在频域卷积，因此一段短录音的频谱不能简单当成无限长声源的精确谱线。

## 频率响应连接幅度 相位与时间变化

### 为什么复指数是LTI系统的特征输入

把x(t)=e^(jωt)代入卷积，若相关积分存在，得到y(t)=H(jω)e^(jωt)，其中H(jω)为h(t)的傅里叶变换。对稳定LTI系统，每个输入复指数保持频率，只乘一个复数；一般信号则在满足条件时按各频率叠加。[5](#ref-ss-frequency)

H的模给增益，辐角给相移。对从某一时刻才开始的正弦，通常还存在启动暂态；“输出是输入乘H”的单频稳态关系不能代替完整初值问题。多输入多输出系统的H还可为矩阵，不必只有一条增益曲线。

### 一阶低通既改变幅度也改变相位

对前述一阶模型，$H(j\omega)=1/(1+j\omega\tau_0)$。截止角频率1/τ0处，幅度为1/√2，幅度分贝约−3.01 dB，相位−π/4。τ0=5 ms时，截止频率约31.83 Hz；图6另取τ0=1/(2π·200) s，明确展示不同参数下200 Hz的截止。

幅度比使用20log10|H|；在相同阻抗等条件下，相应功率比才为|H|²。不能把幅度直接放进10log10，也不能忽略输入输出采用不同物理量时H本身的单位。声压相同也未自动等于响度相同。

### 延迟与相位不能只用一个数字概括

纯延迟d的响应为H=e^(−jωd)，幅度恒为1，相位随ω线性下降。**群延迟**定义为 $-d\phi/d\omega$，φ须采用适当展开并避开零点等相位不可定义处；以Ω为自变量时导数给样本数，以ω为自变量时给秒，详见[相位与群延迟](../phase-and-group-delay/)。[5](#ref-ss-frequency)

一阶低通的群延迟为τ0/[1+(ωτ0)²]，随频率变化。窄带包络在适当缓变与低失真条件下可用群延迟近似描述；它不保证任意宽带脉冲整体平移，也不能不加条件解释成因果信息传播速度。

回声通路的响应则是各延迟复指数的和，可产生梳状起伏。低谷是分量叠加结果，不等于那里完全没有输入，也不保证能靠无界增益安全恢复。逆滤波的噪声敏感性与[最小相位系统](../minimum-phase-system/)有关。

## DTFT DFT与FFT各自是什么

### 离散时间频率仍然可以连续

DTFT定义为 $X(e^{j\Omega})=\sum_{n=-\infty}^{\infty}x[n]e^{-j\Omega n}$，逆变换在任一完整2π区间积分并乘1/(2π)。Ω连续，频谱以2π为周期；离散时间并不自动意味着只剩有限个频点。存在条件及广义解释仍需另行说明。[8](#ref-ss-dtft)

实际序列可来自无穷过程的有限截取。截窗后的DTFT与原过程的谱并不相同，窗函数及记录时长属于观测模型的一部分。不能因为软件画出了平滑曲线，就认为每个细节都由数据独立确定。

### DFT是有限数据的可逆变换

N点DFT在本篇采用
$X[k]=\sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}$，
逆变换乘1/N。它可看成长度N有限序列DTFT的等间隔取样，也可用于其周期延拓的频率表示，具体归一化要分清。FFT是快速计算DFT的一类算法，不是另一种物理变换。[9](#ref-ss-relations)

第k格对应kfs/N（按常用正负频率映射解释），这叫频率格点间隔。用零填充到更长DFT，可更密地观察同一有限序列的DTFT，却没有增加实际记录时长，也不自动改善分开相近成分的能力。频率分辨还取决于窗、信噪比、模型和任务，不能只看图上格点数量。

### 循环边界与显示尺度会改变解释

DFT中的频域乘法对应周期长度下的循环卷积。要用DFT计算两个有限序列的完整线性卷积，变换长度至少N+M−1；不足时尾部绕回前端。对于无限流，需要另行安排分块、重叠和状态，不能逐块随意清零。[9](#ref-ss-relations)

FFT库通常不替你完成“幅度、能量还是PSD”的选择。单边实信号谱除直流和偶数长度时的Nyquist格外，常需按所选幅度定义处理正负频率贡献；窗增益、归一化与相位参考也要说明。一个未经校准的FFT峰值不是声压级。

## Laplace与Z变换还必须给收敛域

### 把增长衰减纳入复频率

双边Laplace变换为 $X(s)=\int_{-\infty}^{\infty}x(t)e^{-st}dt$，s=σ+jω；双边Z变换为 $X(z)=\sum_{n=-\infty}^{\infty}x[n]z^{-n}$，z为复变量。σ或|z|提供指数权重，扩展了可表示的增长与衰减信号，但积分或级数只在某些复数上收敛，形成**收敛域**（ROC）。本篇ROC按绝对收敛定义。[10](#ref-ss-z)[11](#ref-ss-laplace)

傅里叶变换可在相应收敛条件满足时视为σ=0或|z|=1上的取值。若该轴或圆不在ROC中，不能仅把s=jω或z=e^(jΩ)代进去，就宣布得到了通常意义下的频率响应。

### 相同代数式可以代表不同时间信号

例如 $X(z)=1/(1-az^{-1})$，取实数0<a<1。ROC为|z|>a时，对应aⁿu[n]；ROC为|z|<a时，对应−aⁿu[−n−1]。前者因果且绝对可和，后者向过去增长、非因果且不绝对可和。代数式相同，信号与稳定性却不同。[10](#ref-ss-z)

连续例子1/(s+a)、a>0，右半平面Re(s)>−a对应e^(−at)u(t)，左半平面Re(s)<−a对应−e^(−at)u(−t)。极点位置不能单独选出因果方向；必须结合ROC和系统约定。

### 极点 稳定与内部实现要一起判断

对因果、适当的有理连续系统，其普通冲激响应部分衰减的常用条件是传递函数极点严格在左半平面；离散因果有理系统对应严格在单位圆内。一般LTI系统的BIBO判断仍应回到冲激响应或包含傅里叶轴/单位圆的相应ROC，不把有理因果结论无条件推广到所有系统。

传递函数主要描述零状态输入输出。若实现中存在不被输入激发或不被输出观察的不稳定内部模态，代数极零相消可能将其隐藏；外部传递函数稳定不自动保证所有初始状态下的内部稳定。模型约简和实验拟合时尤其需要保留这一层次。[11](#ref-ss-laplace)

### 单边变换保留初始条件

求初值问题常用单边Laplace变换。在合适约定下，导数项为sY(s)−y(0⁻)，因此前述一阶方程产生
$(1+\tau_0s)Y=X+\tau_0y(0^-)$。只写Y=HX相当于取相应零初态，不能把额外项悄悄丢掉。若输入含冲激，还应核对0⁻、0⁺与状态跳变的约定。

离散单边变换同样会出现初始样本项。双边移位定理与单边初值处理不是同一操作。[复变函数](../complex-analysis/)中的留数、极点和积分帮助计算逆变换，本课还要求把它们解释回时间方向、状态和稳定条件。

## 采样 重建与量化分别改变什么

### 采样定理要连着信号条件阅读

对严格带限到|f|≤B、满足相应条件的信号，均匀采样率fs>2B时，可用理想低通或sinc插值唯一重建。采用sinc(v)=sin(πv)/(πv)，可写

$$
x_c(t)=\sum_{n=-\infty}^{\infty}
x[n]\,\operatorname{sinc}\!\left(\frac{t-nT_s}{T_s}\right).
$$

这是理想模型，涉及无穷样本与相应收敛方式。等号fs=2B需要额外的边界谱条件，不能作为任意相位信号的普遍保证；例如频率fs/2的正弦可在全部采样点上为0。实际设备还需要抗混叠滤波的过渡带。[12](#ref-ss-sampling)

采样冲激串x_s(t)=Σx[n]δ(t−nTs)与序列x[n]是不同对象。若X_c采用角频率傅里叶变换，则
$X_s(\omega)=T_s^{-1}\sum_kX_c(\omega-k\omega_s)$，ωs=2π/Ts。这个1/Ts来自冲激串约定；理想重建滤波器相应通带增益为Ts，不能将比例因子任意漏掉。

### 混叠发生后 仅靠已有样本一般不能恢复

采样率8 kHz时，6 kHz与2 kHz的单位幅度余弦在采样点上相同，这是频率周期性和实余弦对称性共同造成的混叠。除非加入可靠的额外先验或测量，后续数字滤波无法仅凭这一组样本判断原来是哪一种。[12](#ref-ss-sampling)

Nyquist频率fs/2是采样率的一半；Nyquist采样率则针对某信号带宽谈所需采样率，两者不要互换。带通采样还有额外频带位置条件，不能用一个最高频率口号覆盖所有情形。本篇采用最基本的低通带限框架。

### 幅度量化和保持电路是另外两步

均匀量化的步长Δ决定幅度格点。在无过载、相应舍入约定下，误差大小可界为Δ/2；误差方差Δ²/12还需误差近似均匀等条件，白噪声和与信号独立也不是量化器自动保证的性质。小幅正弦或周期输入可能产生相关误差与杂散。[13](#ref-ss-quantization)

理想B位量化在固定满量程下提供2ᴮ个码字，但“位数更多”不是整个测量链动态范围必然等比例改善的证明；模拟噪声、增益和饱和同样重要，详见[动态范围](../dynamic-range/)。量化不会修复已经发生的时间混叠。

数模转换的零阶保持把样值保持一段时间，产生相应频率包络与频谱镜像；它不是理想sinc重建。重建滤波器、设备幅相和负载仍属于实际输出链，需要测量验证。

## 反馈与互联系统不能只看局部增益

### 串联 并联与反馈有不同关系

零状态LTI系统串联时，总冲激响应为卷积，频域为乘积；并联输出相加，对应冲激响应相加。数学上的理想级联假定接口关系已正确建模，实际电路可能互相加载，不能只把各自独立测得的电压增益机械相乘。[14](#ref-ss-feedback)

对前向G、反馈F的标准负反馈，写e=x−Fy、y=Ge，消去e得到闭环G/(1+GF)。符号由连接方式决定，分母零点、延迟和内部状态共同影响稳定性；“负反馈”这个名字不保证闭环稳定。代数消元还要求互联良定，即当前输出能唯一确定。

### 一个延迟就能改变闭环极点

离散例子 $y[n]=x[n]-k\,y[n-1]$，零初态下闭环
$H(z)=1/(1+kz^{-1})$，极点在−k。k=0.5时冲激响应(−0.5)ⁿ衰减；k=1.05时交替增长。两者都是带延迟的负反馈结构，差别由闭环动力学决定。[14](#ref-ss-feedback)

耳机啸叫、助听器反馈抑制和主动降噪都需要考虑实际传播延迟、频率依赖、耦合与算法自适应；本例不是其中任何产品的稳定裕度测量，也不能用这一个标量阈值替代完整分析。

### 保持系统模型与听觉机制的解释层次

系统框图可以组织物理、算法与生理模型，但箭头不自动代表已证实的神经机制。耳蜗在特定工作范围内可以近似为滤波通路，其主动、非线性和时变特征仍需对应模型与实验；神经元脉冲、适应和学习也不能只由一条固定频率响应解释。

同样，声学输出更接近目标不自动意味着言语识别或主观音质改善。系统分析先核对物理和数值关系，再与[听觉计算模型](../auditory-computational-models/)及行为评价相接。

## 从理论关系走向可靠测量和计算

### 系统辨识要同时观察激励与噪声

用已知输入估计h或H叫系统辨识。有限数据下，可把卷积写成设计矩阵并作最小二乘；输入是否充分激励目标频带、记录是否同步、截窗是否丢失尾部、模型是否可识别，都会影响结果。没有激励的频率不能凭空获得可靠响应。

若写稳定LTI模型y=h*x+v，令输入与输出为零均值、联合宽平稳过程，按$R_{yx}[\ell]=E\{y[n+\ell]x^*[n]\}$的DTFT定义互谱S_yx，并满足相关与谱存在等条件。若加性输出噪声与输入在所有时差上不相关，可由相关关系推出S_yx=H S_xx，在S_xx非零处估计H。实际使用有限窗的谱估计，还需平均与不确定性评估，详见[频谱与功率谱密度](../spectrum-and-power-spectral-density/)。

输入测量本身有噪声、噪声与激励相关或过程明显时变时，该谱比值可能有偏差；弱激励区也可能极不稳定。[线性代数](../linear-algebra/)和[数理统计](../mathematical-statistics/)提供相应估计工具。

相干性可辅助检查输入输出的线性关联，却不能独自证明因果机制或排除所有非线性。校准、独立重复、不同强度的叠加检验和保留验证刺激，都比只展示一条拟合曲线更有解释力。本文提出这些检查作为方法应用，不把教学合成数据冒充辨识实测。

### 连续模型的离散实现需要误差检查

对τ0ẏ+y=x，若一个采样区间内x保持为x[n]，精确零阶保持离散化为
$y[n+1]=a y[n]+(1-a)x[n]$，a=e^(−Ts/τ0)。它是带明确输入保持假设的离散模型，不是“把t换成n”就得到的结果。[15](#ref-ss-numerics)

前向Euler则取a_E=1−Ts/τ0；输入为0时，数值稳定要求|a_E|<1，即0<Ts<2τ0。真实连续低通始终衰减，但过大步长会让近似振荡甚至发散。数值发散未必是物理系统不稳定，步长减小也应伴随收敛与单位检查。

### 一条完整链应报告哪些条件

至少说明输入输出物理量、采样率、时间原点、系统状态、延迟、窗长、边界处理、幅度与频率归一化。对耳机或麦克风还要报告声学负载和校准；对生理或行为解释，还需相应刺激、观测和人群条件。

建议用三类证据交叉核对：解析特例提供已知结果，独立数值方法检查实现，实际测量检查模型能否解释对象。它们解决不同问题，不能用代码内部一致性替代真实系统验证。

## 可复算的例子与学习自检

### 用矩阵与直接求和核对回声卷积

以下用同一有限序列比较卷积和设计矩阵，保留完整尾部。数组按离散样本解释，不额外乘Ts；若用它近似连续卷积，则需另行处理核、单位和积分权重。

```python
import numpy as np
n = np.arange(160)
x = np.exp(-.5*((n-24)/6)**2)
h = np.zeros(97)
h[[0, 40, 96]] = [1., .55, -.25]
y = np.convolve(x, h)
A = np.zeros((len(x)+len(h)-1, len(x)))
for k in range(len(x)):
    A[k:k+len(h), k] = h
assert np.max(abs(y-A@x)) < 1e-12
print(len(y), np.sum(h), np.sum(y)-np.sum(x)*np.sum(h))
```

矩阵的一列是一个移位通路响应，这就是卷积推导的有限维版本。长度应为256，通路系数和为1.30；总和检查依赖保留完整线性卷积，不能在裁掉尾部后沿用。

### 用ODE与频率响应核对一阶低通

以下输入从t=0开始，初态为0。解析稳态外还要加入衰减暂态，不能在启动时立即套用纯稳态曲线。

```python
import numpy as np
from scipy.integrate import solve_ivp
tau, f = .005, 100.
w = 2*np.pi*f
H = 1/(1+1j*w*tau)
t = np.linspace(0, .08, 1601)
sol = solve_ivp(lambda tt, y: [(np.cos(w*tt)-y[0])/tau],
                [0, t[-1]], [0.], t_eval=t,
                rtol=1e-10, atol=1e-12)
steady = np.real(H*np.exp(1j*w*t))
exact = steady-np.real(H)*np.exp(-t/tau)
assert sol.success and np.max(abs(sol.y[0]-exact)) < 1e-8
print(abs(H), np.angle(H), np.max(abs(sol.y[0]-exact)))
```

该式在t=0满足初值0，长时间才接近稳态；输入输出幅度、相位和启动条件因此得到同一模型内的交叉解释。实际低通器件还应考虑额外极点、饱和及噪声。

### 用相同样本检查混叠与循环回绕

下例先比较两种连续余弦在相同采样点上的值，再展示短DFT的循环卷积与足够补零的线性卷积。混叠检查和卷积检查是两个独立问题。

```python
import numpy as np
fs = 8000.
t = np.arange(64)/fs
assert np.max(abs(np.cos(2*np.pi*6000*t)
                  -np.cos(2*np.pi*2000*t))) < 1e-11
x, h = np.array([1., 2., 3.]), np.array([1., -.5, .25])
linear = np.convolve(x, h)
circular = np.fft.ifft(np.fft.fft(x, 3)*np.fft.fft(h, 3)).real
padded = np.fft.ifft(np.fft.fft(x, 5)*np.fft.fft(h, 5)).real
folded = np.array([linear[i::3].sum() for i in range(3)])
assert np.allclose(circular, folded)
assert np.allclose(padded, linear)
print(linear, circular)
```

### 六个问题检查理解

1. 连续/离散时间与连续/量化幅度分别描述什么？为什么n不直接以秒计？
2. 推导固定冲激响应卷积时，线性、时不变和初始状态分别起什么作用？
3. 为什么无限正弦、有限录音和随机噪声不能不加区别地使用同一种“谱”定义？
4. 为什么DFT补零能让曲线更密，却不能凭空增加录音时长？循环卷积怎样回绕？
5. 为什么同一个Z变换分式还必须给ROC？外部稳定和内部稳定有什么区别？
6. 为什么负反馈、较小仿真误差或较高位数，都不能各自单独保证整个听觉系统有效？

建议按信号与单位、系统性质、卷积、状态、傅里叶、复频率、采样与互联的顺序阅读，再进入数字信号处理的设计与实现。学习中反复把“输入是什么、保留哪些状态、条件在哪里、输出测到什么”说清楚，比只记变换表更能支持研究。
