**汉语语音学**（Chinese phonetics）研究汉语口语怎样产生、形成怎样的声学信号，以及听者怎样从中辨认语言。它既研究普通话，也研究各汉语方言和不同说话人的实际实现；普通话的声韵调系统是重要入门对象，却不是全部汉语的共同音表。语音学的任务是描述和解释声音，发音规范、拼写规范与对语言变异的科学描写需要分别理解。

本篇以普通话为主要教学对象，逐步连接拼音、国际音标、声母韵母、声调与声学测量，并用香港粤语、昆山吴语等具体材料说明不能把普通话的规则直接推广。Lee与Zee的北京语音描写是一个原始材料入口，但该文的示例与记音有明确说话人和风格范围，并不规定所有人的唯一舌形或基频数值。[1](#ref-lee-zee-standard-chinese-2003)

本篇从熟悉的汉语字音与拼音对照开始，发音、音标和时间频率术语随例子说明。一般学科框架见[语音学](../phonetics/)，完整辅音对照见[普通话辅音](../mandarin-consonants/)。本篇的八幅图、三段音频与计算均为原创教学示意或合成信号，不是说话人实测，也不作为标准读音录音。

## 阅读准备与独立阅读

**起步知识。** 能留意自己熟悉的汉语字音、比较两个读音，就可以开始。熟悉拼音更方便对照；国际音标、发音部位和声学术语由正文逐步引入。

**随用随补。** 拼音是拼写方案，国际音标用来记音；[ ]通常标注具体读音，/ /通常标注音位，即语言中有区别词义作用的抽象声音单位。频率可先理解为每秒重复多少次，时长是声音持续多久；基频与共振峰分别涉及声源周期和声道共振，正文会用图解释其区别。

**分层阅读。** 第一遍从声母、韵母、声调与常见语流现象入手，再对照语谱图、基频和起声时间。先看坐标与例子，即可阅读声学测量章节；合成代码、滤波与自动测量细节适合第二遍进一步学习。

## 从字音进入发音 信号与感知

### 三个层面怎样相互核对

读“趴”时，双唇先形成闭塞、随后释放；声学记录中可以寻找释放瞬态、送气噪声和后续周期振动；听者则可能报告“趴”或“八”。发音动作、记录的线索和行为反应相互联系，但不是同一个量。仅从听者选错，不能立即断言声带或舌头执行了哪种动作。

**发音语音学**观察气流、声带、舌、唇、软腭等怎样协调；**声学语音学**分析波形、频谱及时间变化；**感知语音学**通过听辨、分类和反应任务研究线索利用。镜子能观察唇形，不能完整观察舌腭接触；语谱图能显示能量结构，不能直接拍出器官位置。实际研究常需要在多个层面交叉核对。

### 语音实现与语言类别

**音素**用于描写具体语音，**音位**是特定语言中具有区别功能的类别，**音位变体**是同一音位在环境等条件下的实现。方括号通常标语音，如 [pʰ]；斜线通常标音位或音系表示。音位分析还依赖词汇对立与分布，不能只数波形中的谱峰或数拼音字母。[3](#ref-phonetics-phonemes)

“八”bā与“趴”pā可以用来理解普通话不送气与送气的词汇区别；“八”bā与“拔”bá则说明同样的声母韵母可因声调不同而参与词义区分。这是语言类别的比较，不保证自然录音只有一个声学指标发生变化。做线索实验还需要进一步控制时长、基频起点、强度和其他差异。

同一个汉字也未必只有一种读音，汉字个数不总等于实际音节数。例如“花儿”的常见儿化读法通常只有一个音节，而“女儿”中的“儿”是独立音节。字形、词汇、拼写和实际音节应分别标注，不能让自动字数统计代替语音分段。

## 拼音 音标与音节结构

### 拼音是一套拼写规则

《汉语拼音方案》规定怎样书写普通话音节；国际音标提供跨语言的语音描写符号。两者用途不同。拼音 b通常对应清、不送气的 [p]，p通常对应 [pʰ]，不能按英语同名字母的读音，把普通话b直接改写成浊塞音 [b]。上标ʰ是送气标记，不是另一个完整的h音段。[2](#ref-cp-pinyin-scheme)[4](#ref-ipa-chart-official)

拼音y也不等于国际音标 [y]：前者参与零声母音节拼写，后者是前高圆唇元音的符号。读“衣”yī与“迂”yū，可以把主要比较放在不圆唇与圆唇上；但精细声学比较仍须考虑舌位协同与说话人差异。读资料时，先确认括号、字母系统和记音精细程度，再比较所谓“相同符号”。

### 声母 韵母与声调不是三个音素

传统分析把普通话音节分为**声母**、**韵母**和**声调**：声母是音节开头的辅音部分，韵母是声母之后的部分，声调是参与词汇区别的音高模式及其相关实现。声调不是接在韵母末尾的一个独立辅音或元音。

韵母还可按教学分析分为**韵头**、**韵腹**、**韵尾**。韵腹是主要成音节部分，韵头是前面的介音部分，韵尾是后续收尾部分。以“光”guāng为例，声母写g，韵母写uang；在这套分析中，u、a、ng分别对应韵头、韵腹、韵尾。ng是一个字母组合，通常表示一个鼻辅音 [ŋ]，不能拆成先n后g的两个收尾动作。

这是一套结构分解，不要求真实语音逐段停下来拼接。介音究竟归入声母、韵母还是更细的音节组织，音系理论可能采用不同方案；成音节近音等材料也使“韵腹永远是一种普通元音”过于简单。结构、音值和理论表示需要说明各自的约定。[1](#ref-lee-zee-standard-chinese-2003)

### 容易读错的省写

| 拼写例子 | 应核对的规则 | 不能据此推断什么 |
| --- | --- | --- |
| jū、qū、xū | j、q、x后ü省略两点 | u在这里不是通常的后高圆唇 [u] |
| nǚ、lǜ | n、l后仍写ü | 不能把lü与lu合为同一个韵母 |
| niú、guī、lùn | 加声母时iou、uei、uen分别省写为iu、ui、un | 字母少不表示语音仅有相应几个静止位置 |
| jūn | 来自ü行的ün，拼式省点 | 不能把所有un都还原成uen |
| zhī、chī、shī、rì、zī、cí、sī | 方案用i拼写这七类音节的韵母 | 不表示它们都以“衣”的 [i] 收尾 |
| yī、wū、yú | y、w参与无常规辅音声母时的拼写 | 不能据首字母另加两个固定声母音位 |

这些规则有助于解释实际材料，也提醒研究者别让拼音直接充当精细声学标注。[2](#ref-cp-pinyin-scheme) 自动切分时，必须先按完整音节和合法拼写解析，再核对实际录音；仅以字母个数估计音段时长会出错。

## 普通话辅音的部位 方式与喉部协调

### 二十一个常规声母怎样组织

按《汉语拼音方案》的常规声母表，可整理为以下21项；y、w不在此表中。这里的数量属于声母与拼写教学体系，不是对所有音位分析的最终裁决。鼻音ng通常作普通话韵尾，也不加入这21个声母。[1](#ref-lee-zee-standard-chinese-2003)[2](#ref-cp-pinyin-scheme)

| 传统部位组 | 拼音声母 | 主要方式对照 |
| --- | --- | --- |
| 双唇 | b、p、m | 塞音与鼻音 |
| 唇齿 | f | 擦音 |
| 舌尖中 | d、t、n、l | 塞音、鼻音、边近音 |
| 舌根 | g、k、h | 塞音与擦音 |
| 舌面前 | j、q、x | 塞擦音与擦音 |
| 舌尖后 | zh、ch、sh、r | 塞擦音、擦音与r的不同实现 |
| 舌尖前 | z、c、s | 塞擦音与擦音 |

**发音部位**描述哪里形成关键狭窄，**发音方式**描述闭塞、摩擦和气流通路怎样组织。塞音形成口腔闭塞后释放，擦音在狭窄处形成湍流；鼻音有口腔阻碍，同时通过软腭的协调开放鼻腔通路；边近音允许气流从舌的侧边通过。鼻音并不是“完全没有阻碍的元音”。[5](#ref-essentials-consonant-place-phonation)[6](#ref-essentials-consonant-manner)

塞擦音有闭塞和紧接的摩擦阶段，但不是看到两个阶段就自动判为两个独立声母。词汇分布、时序和语言类别仍参与分析。j、q、x常用 [tɕ、tɕʰ、ɕ] 记写；教学宽式常把zh、ch、sh写为 [ʈʂ、ʈʂʰ、ʂ]。符号提示主要类别，并不规定每个人必须把舌尖卷成同一个形状。

### 送气不等于清浊

**清浊**主要涉及声带振动及其与其他动作的协调，**送气**涉及闭塞释放后等阶段的气流与发声时序。普通话b/p、d/t、g/k等常见配对，主要表现为清不送气与清送气的对立；不能把“不送气”直接等同于“浊”。鼻音、l与r常有发声，清阻碍音在弱读位置也可能出现浊化等变化，实际语流并非一张清浊表的机械播放。

起声时间VOT是重要指标，但不是全部线索。Xu与Xu研究普通话送气对后续声调的影响，表明声母条件还可能关联后续元音的F0起点；不能为了做“纯声调比较”，只保证拼音声调相同就忽略声母。[18](#ref-cp-aspiration-2003) 线索相关不意味着每个语音差异都必须由一个单独的声学数值解释。

### 材料表面的相同不等于发音完全匹配

比较“知”zhī与“诗”shī，重点可以放在塞擦与摩擦；比较“苏”sū与“书”shū，重点可以放在部位。但即使拼音韵母相同，声母也会影响后续过渡。尤其“资”zī与“知”zhī的i不等于“衣”的i，而且两种舌尖性韵腹也未必相同。把它们直接当成“只换声母、元音完全不变”的物理刺激并不严谨。

平翘舌、n/l等合流或不同实现，需要先说明所描述的语言变体、说话人及任务。研究者可以对规范读音评分，也可以描写当地系统；这两种问题不应混为“有差异就证明发音器官异常”。

## 韵母 元音与鼻韵尾

### 韵母大于元音字母表

**元音**按舌位高低、前后和唇形等维度描述；**韵母**是音节结构单位，可能包含元音、介音、鼻韵尾及动态过渡。因此“有几个韵母”“有几个元音音位”“用了几个拼音字母”是三个问题，不能直接相等。

常见的普通话示例中，[i] 是前高不圆唇元音，[y] 是前高圆唇元音，[u] 是后高圆唇元音。可以分别用“衣、迂、乌”帮助定位，再观察唇形变化和声学差异。圆唇不仅影响嘴唇外观，还会改变声道的有效形状；同一舌形配不同唇形，也可能改变共振结构。普通话元音的精确音位数、某些拼音e的表示和介音归属，存在不同分析，本文不把一种教学清单宣布为唯一理论。

### 单元音与复韵母是动态问题

单元音的主要音质相对稳定，但自然发音仍有起止过渡；复韵母常涉及连续的构形与音质变化，如ai、ao、ou等。观察“爱”ài时，不宜只在中点取一个F1、F2后便用这个点概括整个韵母。比较动态轨迹还要对齐取样位置、保留实际时长，并说明是否经过时间归一化。

“知、蚩、诗、日、资、雌、思”一组的韵腹传统上常称“舌尖元音”。一些研究将其分析为成音节近音；记音体系也不完全相同。传统符号 [ɿ、ʅ] 不是现行官方IPA元音符号，不能因为汉语教材常见就称为官方国际音标的两个标准元音。[1](#ref-lee-zee-standard-chinese-2003)[4](#ref-ipa-chart-official) 入门时先弄清实际舌位与声学连续性，再讨论音位归属。

### 鼻化与鼻韵尾

元音鼻化涉及鼻腔耦合，鼻韵尾则涉及音节末端的鼻辅音动作，两者可以相伴，却不是同一个概念。普通话n与ng韵尾的部位通常不同；an与ang、en与eng中的前段元音，也可能随韵尾改变。Zee与Lee对北京元音的声学分析专门比较了不同鼻韵尾条件，提示不能把所有差异压缩成最后一个鼻音。[7](#ref-cp-vowels-2001)

分析鼻韵母时，可同时观察元音的共振变化、鼻化线索、末段能量及过渡。只凭一处低频能量或一个自动标注的字母n/ng，不能充分证明发音部位。鼻化还可影响谱峰和共振峰估计；测量困难不等于说话人没有相应语言类别。

## 声源与声道怎样形成可测线索

### 基频与共振峰各描述什么

在短时、近似线性的声源—滤波器模型中，可写为

$$
s(t)=e(t)*h(t),\qquad S(f)=E(f)H(f).
$$

声源 $e(t)$ 可以包含声带准周期振动或狭窄处噪声，声道的作用用滤波器 $h(t)$ 近似，输出为 $s(t)$。这个分解帮助理解频谱，但不意味着真实发声系统永远线性、不变或只有一个声源。[8](#ref-formant-sourcefilter)

**基频** $F_0$ 是准周期声源的重复速率，**共振峰**F1、F2、F3等反映声道共振形成的谱包络结构。谐波间距主要与 $F_0$ 有关；共振结构影响各谐波的相对强弱。最强谱峰不必是基频，某个谐波峰也不必恰好位于共振峰的中心。声源周期为 $T_0$ 时，$F_0=1/T_0$；130 Hz的周期约7.69 ms。

F1与元音开口或舌位高低、F2与前后及唇形常有相关关系，但不是一一对应的器官尺读数。声道长度、圆唇、咽腔形状及协同发音都会影响数值。比较不同年龄或不同说话人时，不能把统一Hz阈值当作普遍发音标准。

### 两段共振合成音

## 声调 调值与实际基频轨迹

### 四声是类别 五度值是相对记法

普通话主要词汇声调通常分为阴平、阳平、上声、去声。教学中常用55、35、214、51等五度记值，1代表相对低、5代表相对高；它们不是Hz，也不是固定的五个钢琴音。声调类别、相对调值、测得的 $F_0(t)$ 与听到的音高，应分别描述。

“妈mā、麻má、马mǎ、骂mà”展示声调可参与词义区分。高平、上升、低或降升、下降是入门概括；实际声学轨迹受说话人、位置、语速、焦点与相邻声调影响。尤其上声不应被要求在每个语境中都完整降到最低后再升高。[1](#ref-lee-zee-standard-chinese-2003)[9](#ref-cp-xu-1997)

### 基频归一化保留什么 又丢失什么

若希望用相对音高比较同一说话人的轮廓，可规定正的参考频率 $F_{\mathrm{ref}}$，转换为

$$
p(t)=12\log_2\frac{F_0(t)}{F_{\mathrm{ref}}}\quad\text{半音}.
$$

130 Hz变成260 Hz会相差12半音。这个表示仍依赖参考选择；它不会自动解决说话人的全部差异。若将时间归一化为 $u=(t-t_{\mathrm{start}})/(t_{\mathrm{end}}-t_{\mathrm{start}})$，还会移除绝对时长。因此可以同时保存原始秒、Hz和归一化轨迹，而不是只保留一条看似重合的平均曲线。

无周期区间的 $F_0$ 通常应记为缺失或未定义，不是0 Hz。低调的喉化、不规则周期可能让算法出现倍频或半频错误；一条突然跳高12半音的线首先需要核对周期和算法条件，不能直接宣布发生了声调类别改变。

## 连读变调 轻声与儿化

### 上声的连读形式

在同一适当变调域内，两个上声相连时，前一个通常呈升调，教学上常以“3＋3→2＋3”提示，如“你好”。这里的2描述类别或教学上的对应，不保证其每个声学细节都与词汇阳平完全一致。上声在非上声前，常出现低段而不完成孤立式末尾上升，如“老师”中的“老”。

超过两个音节时，词语结构、韵律分组和语速会参与组织，不能用“从左到右，把所有3都改成2”的程序处理每个句子。Xu的上下文声调研究区分了相邻声调影响，也说明真实F0包含前后文的连续作用，不能把每个细小弯折都分析为音系变调。[9](#ref-cp-xu-1997)

<figure><img src="/n3-hearingpedia/figures/chinese-phonetics/connected-tone-patterns.svg" alt="你好和老师的概念性连读图分别展示上声加上声时首音节的升调、上声加阴平时首音节的常见低段。" loading="lazy" /><figcaption>图6　两组曲线只示意连读模式，相对高低没有物理单位，也不是某位说话人的录音结果。停顿、强调或不同分组下，需要重新观察实际实现。</figcaption></figure>

### 一与不的变调及拼写

“一”在常见连续读法中，去声前常变为阳平样，如“一辆”；阴平、阳平、上声前常变为去声样，如“一天、一年、一本”。单念、计数、序数等位置还要检查本调读法。“不”在去声前常呈阳平样，如“不去”，在“不能”等非去声前一般保持去声；弱读结构又可能不同。[19](#ref-cp-yi-bu)

学习时可用调类箭头记录本调与表面读法，例如“一辆：1＋4→2＋4”“不去：4＋4→2＋4”。书面拼音通常保留“一、不”的本调；实验记音为了显示实际读法，也可以另列读音层。不要把拼写规范与实际发音混成一列，或仅凭文本调号就当作已经测过的F0。

### 轻声不是固定第五条音高曲线

轻声涉及词汇、语法和韵律弱读条件，常有较短时长、音段弱化和依赖上下文的音高实现。并非把某个完整声调一律降低固定Hz就得到轻声，也不是所有轻声都等于“最低调”。“妈妈”第二音节、语法助词等可作为入口，但具体词的读法及地域、语体变化需要核对。

Chen与Xu通过轻声音节、语速与焦点条件研究其F0实现，提出弱目标及实现强度的解释；这提示“没有固定完整调形”不等于“完全没有任何实现约束”。本文不以一种理论取代所有轻声音系分析，也不从摘要推算人群统一的时长或基频阈值。[10](#ref-cp-neutral-2006)

### 儿化不能只在词尾添一个r声母

普通话常见儿化会改变韵母的音质、收尾和共振结构；“花儿huār”的儿化不等于先把花发完，再发一个声母r，也不同于“女儿”中独立的ér音节。鼻韵尾、韵腹和介音怎样变化，取决于原韵母与具体实现，不能用统一的文字拼接替代分析。

F3降低或F2、F3靠近常是观察卷舌化、r音色的入口，但同一声学结果未必对应唯一舌形。Chen、Whalen与Mok结合超声和声学记录研究北方说话人的普通话r类音，发现成音节和元音后的r可有不同舌形实现。[12](#ref-cp-rhotics-2024) 测得F3差异不等于直接测得“舌尖卷了多少度”。

## 声调以外的韵律与汉语内部差异

### 重音 焦点与语调

**重音或突显**涉及音节、词在语流中相对突出，**焦点**涉及话语中被突出传达的信息，**语调**涉及更大范围的音高与韵律组织。它们可通过F0范围、时长、强度和其他线索共同实现，不能把重音只定义为“声音更大”。

普通话疑问句也不意味着每个字都改成阳平或上升调。词汇声调与句子语调共同约束实际轨迹；焦点位置还可能改变局部音高范围和后续部分。Liu与Xu比较不同问句、陈述及焦点条件，为区分这些功能提供了原始研究入口。[11](#ref-cp-focus-2005) 单个句末升降不能自动推断全部语用意图。

将汉语概括为“音节等时”，也不应理解为各音节持续时间必须相等。轻声、停顿、重读、语速和边界都会影响节奏。在研究里，报告所测的具体时长、边界和条件，比给整种语言贴一个绝对等时标签更有解释力。

### 香港粤语与昆山吴语的对照

Zee的香港粤语描写包含普通话没有的常规塞音韵尾 [p、t、k]，并说明这些末尾塞音不释放。不能因为看不到明显爆破就自动认为没有闭塞韵尾；所谓入声也不宜当成普通话四声之外一条固定的F0曲线，需同时考虑音节收尾结构与当地的调类分析。[13](#ref-cp-cantonese-1991)

昆山吴语的研究则提醒我们注意发声态与韵律域。Xu与Mok分析双音节词中的气声，发现其持续范围可能超过首音节，并受F0条件影响。这是具体方言、材料和分析条件下的结果，不能简化成“所有吴语的浊声母就是普通话b、d、g的另一种读法”。[14](#ref-cp-wu-2023)

比较汉语方言时，先选定调查点、说话人背景、音节位置和记音体系，再比较词汇对立及声学实现。相同汉字、相同调名或相同拼音样字，不保证对应同一个声音；当地读音与普通话不同，也不自动构成听觉或发音病理。这些例子只说明汉语内部差异，不替代完整方言分类或历史音韵课程。

## 怎样从录音得到可解释的测量

### 先规定问题与标注层次

一个可执行的小实验可以问：“同一说话人在相同元音、声调和句子位置下，b与p的释放至周期发声间隔如何不同？”先记录说话人、方言背景、材料、重复次数、麦克风和采样设置，再分别标注词、音节、闭塞、释放、送气与周期起点。用人工核对校准自动分段，并保存不能确定的边界。

若换成“声调比较”，就应匹配或建模声母类型、韵母、语速、重读与位置；若换成“鼻韵尾比较”，应同时检查前段元音。控制一个文字条件，不等于所有声学干扰都已控制。训练集与测试集还需区分说话人和材料，防止相同录音片段进入两边。

### VOT的定义与边界不确定性

对塞音，常把**起声时间**定义为释放时刻与周期发声开始时刻之间的有符号时间差：

$$
\mathrm{VOT}=t_{\mathrm{voice}}-t_{\mathrm{release}}.
$$

正值表示发声在释放之后开始，负值表示释放前已有发声。普通话清不送气与清送气塞音常表现为不同的正VOT范围，但部位、元音、声调、语速及说话人都会影响结果，不能在所有材料中共用一个固定分界值。塞擦音还包含摩擦阶段，应说明所采用的时间边界是否包含该阶段。

图7的释放时刻均为50 ms，周期起点分别为62与115 ms，因此VOT为12与65 ms。它们是合成事件标记，不是普通话b、p的标准值。实际录音中，爆破可能不明显、发声可能逐渐出现，必须明确边界准则，并检查重标注误差。[18](#ref-cp-aspiration-2003)

<figure><img src="/n3-hearingpedia/figures/chinese-phonetics/vot-landmarks.svg" alt="两条人工波形均在50毫秒标记释放，在62或115毫秒开始周期振动，分别给出12和65毫秒的起声时间。" loading="lazy" /><figcaption>图7　VOT由两个明确事件的时间差定义。纵轴幅度是合成数值，不是气流量；图中没有测量真人的声带运动或行为分类边界。</figcaption></figure>

### 窗长与语谱图的可见结构

语谱图将短时频谱随时间排列，颜色常表示某种对数幅度或功率。短窗有利于定位较快的时变结构，长窗能更细地分辨邻近谐波；具体带宽还依赖窗形。给同一记录画两张窗长不同的图，外观差异不等于说话人产生了两套发音。[15](#ref-phonetics-praat-spectrogram)

本篇用周期Hann窗，采样率16000 Hz。5 ms窗有80个样本，40 ms窗有640个样本；二者都用2048点FFT，频率网格均为7.8125 Hz。但等效噪声带宽分别为300与37.5 Hz。这个带宽定义与Praat高斯窗的−3 dB带宽不同，不能直接混用数值。补零加密频率网格，也不会凭空获得更长的观测时间。

<figure><img src="/n3-hearingpedia/figures/chinese-phonetics/spectrogram-windows.svg" alt="同一共振合成信号的5毫秒与40毫秒Hann窗语谱图，短窗能量带较宽，长窗较清楚显示谐波条纹。" loading="lazy" /><figcaption>图8　两图输入完全相同，均显示各自相对最大值以下55 dB的幅度范围。图中的条纹、分析窗和FFT网格应与信号本身的共振结构分开解释。</figcaption></figure>

### 自动F0和共振峰轨迹需要人工核对

F0提取应根据声音特征选择方法和合理范围，并查看周期性、候选路径、无声区间和倍频错误。低调喉化、气声及高基频都可能使估计困难；曲线断裂不一定代表声调类别断裂。[16](#ref-phonetics-praat-pitch)

共振峰提取还受预加重、模型阶数、窗长、上限频率和声源谐波间距影响。Praat的Burg方法是短时谱模型估计，不是直接测量声道解剖；默认参数也不是适合所有年龄、声道或发声条件的统一标准。[17](#ref-formant-burg) 需要同时查看频谱、语谱图和轨迹，保留无法可靠估计的帧，而不是为了得到平滑曲线填入虚构数值。

## 用于听觉研究与学习时怎样设计比较

### 从听辨到机制的证据

研究普通话声母、韵母或声调感知时，应区分检测、辨别、开放识别和有限选项分类。四选一正确率与二选一成绩的机会水平不同；完整[混淆矩阵](../confusion-matrix/)比一个总正确率更能显示错误去了哪里。听者报错“马”与听者检测不到声音，是不同的现象。

使用合成或重合成材料可操纵特定线索，但必须核对是否同时改变了音质、自然度、时长、幅度和其他线索。只保留F0轮廓的谐波音不是完整声调语音；“仍能听出升降”也不等于能够识别原词。若把[声码器](../vocoder/)、助听器或人工耳蜗模型接入比较，还应明确频带、包络、可听性与任务，不能用设备参数直接替代语音学分析。

### 三步学习练习

先选同一个说话人的少量完整音节，记录字词、拼音、本调、预计连读形式与宽式记音，把不确定项单列。其次在录音上标注边界和测量区间，分别检查F0、共振峰或VOT，不追求每个项目都能得到数值。最后重新听辨并比较：哪些文字上相同的部分实际上不同，哪些声学不同没有产生稳定的类别判断。

可以用“八／趴”观察送气时序，用“衣／迂／乌”观察唇形与共振，用“马／老师／你好”观察同一调类在不同条件下的实现。它们是学习材料的选择思路，不是已经控制好所有变量的标准化测试。正式研究还需设置材料平衡、重复、说话人差异和有效的独立验证。

## 小计算与自测

### 按采样点核对VOT

代码使用图7的已知事件位置，演示样本、秒与毫秒的换算；它不自动识别真实录音中的释放。

```python
fs = 16000
release = 800
for periodic_onset in [992, 1840]:
    vot_ms = (periodic_onset - release) / fs * 1000
    print('release ms:', release/fs*1000, 'onset ms:', periodic_onset/fs*1000, 'VOT ms:', vot_ms)
```

### 将Hz与时间转成相对坐标

无周期区用NaN保留，不把它变成0 Hz；时间归一化只用于同一明确区间，原始时长仍应保存。

```python
import numpy as np
f0 = np.array([130., 195., np.nan, 260.])
reference_hz = 130.
semitones = np.full_like(f0, np.nan)
valid = np.isfinite(f0) & (f0 > 0)
semitones[valid] = 12 * np.log2(f0[valid] / reference_hz)
t = np.array([.20, .25, .30, .35])
normalized_time = (t-t[0])/(t[-1]-t[0])
print('semitones:', semitones, 'normalized time:', normalized_time)
```

### 由F0轨迹生成谐波声源

改变频率必须累计相位。直接把时变频率代入 $\sin(2\pi F_0(t)t)$ 一般不会得到指定的瞬时频率，因为求相位导数时会多出一项。下面输出合成数组与已知轨迹，不将其当作自然语音。

```python
import numpy as np
fs = 16000
n = 7200
u = np.arange(n)/(n-1)
f0 = 140 + 50*u
phase = 2*np.pi*np.cumsum(f0)/fs
sound = sum(np.sin(k*phase)/k for k in range(1,9))
recovered_hz = np.diff(phase)*fs/(2*np.pi)
assert np.allclose(recovered_hz, f0[1:])
print('samples:', len(sound), 'F0 endpoints:', f0[0], f0[-1])
```

完整例子可[下载](../../code/chinese-phonetics/experiments.py)。自然录音中的周期、共振与边界提取还需要相应算法和人工检查，不能把这些已知参数的小计算冒充自动分析器。

### 六个自测问题

1. 拼音b、p与国际音标 [b、p] 能否按同名字母直接对应？
2. jūn的un与lùn的un能否都按uen分析？
3. 一个说话人的两个元音F0相同，它们是否就有相同音质？
4. 上声在“马、老师、你好”中是否必须有同一条完整214曲线？
5. 看到F0从130跳到260 Hz，是否足以证明发生了音系变调？
6. 2048点FFT的网格为7.8125 Hz，能否据此说5 ms与40 ms窗拥有相同的频率分辨能力？

<details><summary>查看答案与推理</summary>
<p>1. 不能。普通话b通常为清不送气[p]，p通常为清送气[pʰ]；拼写系统与语音符号的层次不同。</p>
<p>2. 不能。jūn属于ü行的ün省点，lùn的un对应uen的省写；还要结合完整音节解析。</p>
<p>3. 不一定。相同声源周期可配不同共振结构，谱包络与音色仍可不同。</p>
<p>4. 不必。孤立、非上声前、同域上声前的实现可能不同，句子分组与强调还会影响结果。</p>
<p>5. 不足。应先核对实际周期、算法倍频错误及其他线索，12半音跳变本身不是类别分析。</p>
<p>6. 不能。网格只表示取样位置；窗长与窗形决定分析带宽，补零不会增加观测时间。</p>
</details>
