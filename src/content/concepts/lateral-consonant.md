**边音**（lateral consonant）是气流主要从舌的一侧或两侧通过的辅音。[3](#ref-essentials-consonant-manner)普通话拼音 l 对应的典型音值 [l]，通常描述为浊齿龈边近音：舌尖或舌端在上齿龈区域形成中央阻碍，舌侧仍保留口腔气流通道。普通话 l 与 n 的主要差别不只是舌尖位置，还包括气流由口腔舌侧通过还是由鼻腔通过。[1](#ref-lee-zee-standard-chinese-2003)

## 发音机制

### 中央接触与侧向通道

发普通话 l 时，舌尖或舌端接触上齿龈附近，限制了口腔中央的气流路径。舌的一侧或两侧与口腔侧壁之间仍可保持通道，让气流绕过中央接触区。这就是“边”的含义：它描述气流相对于舌的路径，而不是让声音从嘴角发出，也不要求每个人都以完全对称的方式放开两侧。

因此，不能把 l 描述为“口腔完全堵住后发声”。它虽有中央接触，却仍有口腔侧向气流；完全闭塞并释放是塞音的典型机制。学习时应区分局部接触与整个口腔气流通路的关闭。

### 软腭与声带的作用

普通话 l 的典型发音中，软腭升高，鼻腔通路关闭，气流主要经口腔舌侧排出。声带通常振动，使其具有周期性声源。舌部接触、软腭状态和声带振动分别说明不同发音维度，不能只用“舌尖抬起”概括整个动作。

在[清音与浊音](../voicing/)分类中，普通话 l 通常是浊辅音。浊音的依据是声带振动，不是声音低沉或响亮。实际语流中的振动强弱可以受相邻声音与说话方式影响，宽式类别不应被理解成每个瞬间都具有完全相同的周期性。

## 普通话 l 的分类与分布

### 边音与边近音

“边音”强调侧向气流，是较广的名称；“边近音”还说明通道通常不形成明显摩擦。普通话 [l] 一般以边近音描述。在其他语言中，也存在边擦音等类别，因此不能把全球语言里的全部边音都直接等同于普通话 l。[2](#ref-ipa-chart-official)

在国际音标表中，[l] 位于齿龈栏、边近音行。传统普通话教材常把它列为舌尖中边音。两种术语的分类粒度和习惯有所区别，但都把部位和侧向气流作为重要信息。进一步的方式分类见[发音方式](../consonant-manner-of-articulation/)。

### 声母位置与字例

普通话 l 通常出现在声母位置，例如“拉” lā、“老” lǎo、“路” lù。一个整字还包含韵母和声调，不能把整字的响度或音高都归因于边音。标准普通话常规韵尾没有 l，其他语言或方言中的词尾 l 则需要按相应系统解释。

下表以 l 与容易对照的 n 为例，区分共有的部位特征和不同的气流路径。例字使用相同韵母与声调，帮助突出声母区别。[1](#ref-lee-zee-standard-chinese-2003)

| 项目 | 边音 l [l] | 鼻音 n [n] |
|---|---|---|
| 舌部动作 | 舌尖或舌端在齿龈区域形成中央接触 | 舌尖或舌端在齿龈区域形成口腔闭塞 |
| 主要气流路径 | 经舌的一侧或两侧，从口腔排出 | 经开放的鼻腔通路排出 |
| 典型软腭状态 | 升高，关闭鼻腔通路 | 下降，开放鼻腔通路 |
| 常见声带状态 | 有振动 | 有振动 |
| 字例 | 老 lǎo | 脑 nǎo |

## 与其他辅音的关系

### n/l 的区别如何理解

n 与 l 都可以是浊辅音，也都使用靠近上齿龈的舌部接触。只按清浊或“舌尖顶住上面”判断，无法可靠区分。n 的口腔出口被关闭，气流从鼻腔通过；l 保留侧向口腔通道。关于前者的机制，可参见[鼻音](../nasal-consonant/)。

教学中可以分别体会两种自然发音，再观察其与元音的连接。触觉或简单体感有时帮助理解，但不能仅凭一个练习动作给真实语音作专业诊断。若涉及特定方言的 n/l 合流，应先说明该语言变体的规则，不能默认所有说话人都以标准普通话的对立方式组织这两个声母。

### 边音与 r 不可互换

普通话 r 常涉及舌尖后区域，其实现可以有擦音或近音特征；l 的典型气流则是侧向的。两者都可能带有声带振动，也都可能听起来具有较强共鸣，但相似音色不代表发音方式相同。某些语言把多种相关辅音归入特定类别时，仍需结合其自身音系分析，不能把普通话 l 与 r 简单合成一个类别。

## 语音实现与声学观察

### 部位会受语境影响

[l] 是宽式记音，概括了普通话 l 的典型类别。实际舌尖或舌端的接触范围、舌背姿态和元音连接会受语境及个体影响。同一个声母连接不同韵母时，听感和声谱图不必完全相同。描述这些变化时应记录前后语音，避免把所有差异都解释为 l 的类别改变。

[发音部位](../consonant-place-of-articulation/)的名称帮助定位中央接触区，但不能独自说明侧向通道的形状。研究具体发音动作时，可结合适当的发音观测方法；一张普通录音声谱图并不直接显示舌头两侧的几何形态。

### 声学图形能说明什么

典型 l 具有较明显的周期性与共振结构，但舌部接触及侧向通道也会改变频谱。声学分析可以比较 l 的持续区间、邻接元音的过渡和周期性，不能把“能看到共振峰”直接当作边音的唯一判据，因为元音和其他浊辅音也可以呈现共振结构。

## 记音与学习方法

### 先核对目标类别

学习时可以使用 lǎo/nǎo 等可比字词，先确认声母、韵母和声调，再分别关注侧向口腔通道与鼻腔通道。练习保持自然响度与语速，避免用夸张的舌位或强气流替代正常发音。能够持续发声是有用的体会方式，但持续性本身不能把边音与鼻音区分开。

[普通话辅音的国际音标](../mandarin-consonant-ipa/)说明拼音 l 与 [l] 的对应。整理材料时，应将字母、音标、部位、方式和音节位置分栏记录。这样可以明确讨论的是一个传统声母类别，还是某段录音中的具体音值，并为后续比较保留清楚的语音学依据。
