**普通话辅音的国际音标**是用国际音标（International Phonetic Alphabet，IPA）描述普通话辅音音值的记音方式。汉语拼音服务于汉字注音和规范拼写，IPA 服务于跨语言语音描述；两者不能按字母外形直接互换。本词条提供一套常见的宽式语音对应，并说明可能的记音差异，而不把它规定为唯一的普通话音位分析。[1](#ref-lee-zee-standard-chinese-2003)[2](#ref-ipa-chart-official)

## 方括号、斜线与字母

### 语音与音位的表示

方括号通常表示语音记音，例如 [pʰ] 描述送气的双唇塞音；斜线通常表示音位或音系分析，例如 /p/。同一个符号在不同文献中可能承担不同层次的任务，应先阅读作者的符号约定。本文对照表采用方括号，提供常见类别的宽式音值，不声称每个说话人的每次发音都与符号完全相同。

宽式记音保留主要区别，窄式记音可以用附加符号表达更细的部位、清化或其他变化。宽式 [t] 与加上齿化符号的窄式记音并不必然矛盾，它们可能只是描述精度不同。音位分析还需利用区别意义的对立和分布，不能仅从音标表的格子数量推出普通话有多少音位。[2](#ref-ipa-chart-official)

### 拼音不是音标替换表

拼音 b 通常对应 [p]，p 对应 [pʰ]；拼音 g 对应 [k]，k 对应 [kʰ]。因此把 b 自动写成 [b]、d 写成 [d]、g 写成 [ɡ]，会把普通话清、不送气的类别改成浊塞音。拼音 zh、ch、sh 各记写一个声母，IPA 的符号数量也不按拼音字母数量决定。[1](#ref-lee-zee-standard-chinese-2003)[3](#ref-hanyu-pinyin-scheme)

## 常见辅音对应

### 声母与鼻音韵尾对照

| 拼音 | 常见宽式音标 | 部位与方式 |
| --- | --- | --- |
| b、p | [p]、[pʰ] | 双唇塞音，不送气／送气 |
| m | [m] | 双唇鼻音 |
| f | [f] | 唇齿擦音 |
| d、t | [t]、[tʰ] | 齿龈附近的塞音，不送气／送气 |
| n | [n] | 齿龈附近的鼻音，可作声母或韵尾 |
| l | [l] | 齿龈边音 |
| g、k | [k]、[kʰ] | 软腭塞音，不送气／送气 |
| h | [x] | 常见宽式记音为软腭擦音 |
| j、q、x | [tɕ]、[tɕʰ]、[ɕ] | 龈腭塞擦音与擦音 |
| zh、ch、sh | [ʈʂ]、[ʈʂʰ]、[ʂ] | 卷舌类塞擦音与擦音 |
| r | [ɻ] 或 [ʐ] | 卷舌近音或浊卷舌擦音，须注明采用的描述 |
| z、c、s | [ts]、[tsʰ]、[s] | 齿至齿龈区域的塞擦音与擦音 |
| 韵尾 ng | [ŋ] | 软腭鼻音，通常不作常规声母 |

表格以常用音值概括[普通话辅音](../mandarin-consonants/)系统，部位可随语境出现精细变化。例如 h 的实际摩擦位置可能受相邻元音影响，不能看到拼音 h 就直接套用 IPA 的 [h]。对实际录音做窄式记音时，需要以可观察的语音为依据，而非机械复制此表。表中的卷舌类符号采用常见教学宽式，并非逐项复刻 Lee 与 Zee 的表：该文对青年北京样本采用舌尖后齿龈的较细记音，r 记为后齿龈近音，并指出样本不具有严格的卷舌形态。[1](#ref-lee-zee-standard-chinese-2003)

### 送气符号怎样读取

上标 ʰ 表示送气，例如 [pʰ]、[tʰ]、[kʰ]。它不是让读者在塞音后面额外念一个完整的 h 音节，也不表示声带振动。普通话[送气与不送气](../aspiration/)的区别尤其体现在成对的塞音和塞擦音；[tɕ] 与 [tɕʰ] 都有塞擦结构，送气符号表示另一项区别。

塞擦音可用两个相邻 IPA 符号记录，也可添加连结线，例如 [t͡s]、[t͡ɕ]。是否省去连结线属于记音约定，不应据此把省略形式解释为两个独立的普通话声母。在涉及辅音序列的比较材料中，使用连结线有助于说明它们构成一个紧密结合的发音单元。[2](#ref-ipa-chart-official)

## 需要说明的记音差异

### r 的近音与擦音记法

IPA [ɻ] 表示卷舌近音，[ʐ] 表示浊卷舌擦音，两者对狭窄程度和摩擦的描述不同。普通话 r 的资料中都可以见到有关记法，具体选择涉及说话人的发音、所用宽式方案及作者分析。写作时应注明参考依据，不能把这两个符号当成毫无区别的字体变体，也不能凭一个符号断言所有普通话 r 都有强摩擦。[1](#ref-lee-zee-standard-chinese-2003)[2](#ref-ipa-chart-official)

### 舌尖前、舌尖后与舌面前

传统的平舌组 z、c、s 与翘舌组 zh、ch、sh，常用 [ts tsʰ s] 与 [ʈʂ ʈʂʰ ʂ] 区分。[舌面前音](../mandarin-alveolo-palatal/) j、q、x 常用 [tɕ tɕʰ ɕ]，不应直接写成英语常见的 [dʒ tʃ ʃ]。这些符号概括不同的发音部位和方式，具体舌尖、舌叶姿态仍可能存在个体差异。

普通话“资、词、思”和“知、吃、诗、日”中的拼音 i，不能直接按“衣”的 [i] 处理。资料中可见所谓舌尖元音符号 ɿ、ʅ，它们不属于现行 IPA 主表的正式字母；也有描述采用成音节的近音或其他方案。它们涉及韵母和音节核的分析，本词条不将其加入辅音声母计数。

## 声母范围与 y、w

### 音标不能由拼写位置自动决定

[普通话声母](../mandarin-initials/)的常规 21 类不包括 y、w，ng 则通常只作鼻音韵尾。拼音 yi、wu、yu 等遵循零声母音节的拼写规则，其中的 y、w 不能未经分析就分别转为两个固定的辅音音位。实际语音中的 [j]、[w]、[ɥ] 等滑音与介音如何表示，需要结合完整音节和作者的音系方案。[3](#ref-hanyu-pinyin-scheme)

同样，拼音 ju、qu、xu 中省去两点的 u 对应 ü 系列，并非“乌”的元音。做整音节记音时，除了声母表，还必须检查韵母、声调及具体语音变化；只转换声母而机械保留剩余字母，并不能得到可靠的 IPA 音节。

## 使用与检查

整理词条或语音材料时，宜同时保留汉字、拼音、IPA 和记音说明。先核对声母是否对应正确，再检查送气上标、塞擦音结构和 r 的约定；如果记录的是实际录音，应进一步说明宽式或窄式、说话人及语境。软件字体需要支持 ʰ、ɕ、ʂ、ɻ、ŋ 等字符，形似的拉丁字母或其他字符不应作为替代。

国际音标提供的是可比较的语音描述工具，不能由符号本身推出固定时长、频率或识别难度。需要这些信息时，应另提供测量方法和材料。对入门学习而言，掌握拼音与常见宽式音值的差别，已经能避免把不送气误作浊音、把两字母声母拆开以及把鼻音韵尾计入声母表等常见错误。
