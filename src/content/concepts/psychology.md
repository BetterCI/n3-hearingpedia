**心理学**（psychology）通过系统观察、测量、实验和理论建模，研究心理过程与行为。心理过程包括感知、注意、记忆、思考、情绪和动机；行为包括选择、言语、动作及其与环境的关系。研究者还考察这些现象怎样随发展、个体经历、生物条件和社会文化而变化。心理学既有自然科学的问题，也有社会科学的问题，研究对象并不限于心理障碍或咨询活动。[1](#ref-psych-scope)

在听觉研究中，“听到了”“理解了”“记住了”和“愿意继续听”是不同问题。同样的复述得分可能来自不同策略，同样的声学输入也可能因任务和经验产生不同结果。本篇提供这些问题共用的概念与研究逻辑；[心理声学](../psychoacoustics/)、[听觉注意](../auditory-attention/)、[言语感知](../speech-perception/)和[听觉努力](../listening-effort/)再展开具体任务。

全文以基础课程为定位，覆盖主要领域并深入若干可检验模型，不追求列尽学派、实验和临床技术。十幅图与所有数值均为原创教学示意或明确指定的数学算例，不是参与者、患者或器件实测；文末有三个短程序，并提供[完整计算脚本](/n3-hearingpedia/code/psychology/experiments.py)。

## 阅读准备与独立阅读

**起步知识。** 能理解比例、平均数、两组比较和日常观察即可开始。不要求先学完神经科学、概率论或统计学；需要的概率、测量和因果概念会在例子旁解释。

**随用随补。** 概率是指定条件下事件发生的量化描述；相关描述变量共同变化；随机分派通过随机机制安排实验条件。正文会区分这三者。正态分布先理解为一种钟形模型，参数与公式用于深入复算，不影响先按图理解研究问题。

**分层阅读。** 第一遍读学科地图、构念与测量、各心理过程和综合实验例子；第二遍再读心理测量函数、信号检测、预测误差、证据积累和统计层级。需进一步分析数据时，可按需查阅[概率论](../probability-theory/)与[数理统计](../mathematical-statistics/)，不将它们设置为整篇的阅读门槛。

## 学科地图与解释层次

### 同一行为可以提出不同层次的问题

一个人在多人交谈中没有回答问题，可能没有获得足够清晰的声音，也可能没有选择该声源、未理解语言、暂时未提取信息，或者不准备回应。行为研究要把这些候选解释变成有差别的预测；“没有回答”本身不是任何单一心理状态的直接读数。[2](#ref-psych-science)[8](#ref-psych-attention)

心理学中的**理论**是组织现象并产生可检验预测的解释框架；**假设**是其中较具体、可与观察对照的命题。模型可以是过程图，也可以是数学方程。理论不是随意猜想，但获得支持也不等于永不修正。若某个说法能解释一切结果，却无法指出什么观察会使它受到挑战，其经验检验价值就很有限。[2](#ref-psych-science)

| 方向 | 典型问题 | 主要观察 |
| --- | --- | --- |
| 生物与认知 | 感觉如何转成经验，怎样选择、保持与使用信息 | 行为任务、时间过程、生理记录 |
| 学习与动机 | 经验怎样改变预测、行动与目标追求 | 训练、反馈、迁移和长期保持 |
| 发展与人格 | 随年龄、经历和个体倾向怎样变化 | 纵向追踪、多情境与多来源测量 |
| 社会与文化 | 他人、规范和共同意义怎样参与行为 | 互动、调查、实验与情境观察 |
| 应用与服务 | 怎样支持教育、健康、工作及交流 | 有效性、实际获益、公平与可实施性 |

行为取向强调环境、经验与反应关系，认知取向研究表征与信息加工，生物取向关注实现这些功能的身体和神经机制；发展及社会文化研究提醒我们考察时间与情境。人本和心理动力等传统也影响过理论与实践。评价具体命题时，应分别检查测量与证据，而不是因为它属于某个学派就整体接受或否定。[1](#ref-psych-scope)[20](#ref-psych-social)

## 构念与测量 怎样知道自己测到了什么

### 操作性定义把抽象问题落实为观察

**构念**是为描述和解释现象提出的概念，例如工作记忆、焦虑或外向性。**操作性定义**说明本研究怎样操纵或测量它。研究“注意”时，可以要求跟随一位说话者并报告词语；但复述还依赖可听度、语言知识、记忆和作答。因此，操作性定义限定测量的含义，不把整个构念缩成一项任务。[3](#ref-psych-design)[4](#ref-psych-measurement)

自陈报告直接询问体验与判断；行为指标观察正确率、选择和反应时间；他评反映他人所见；生理指标记录瞳孔、皮肤电或神经活动。各自都有信息与局限。自陈会受题意、回忆和表达影响，行为会受策略与动作影响，生理反应也常由多种过程共同决定。“客观评分”只说明评分规则较固定，不意味着回答完全没有主观影响。[4](#ref-psych-measurement)

### 信度与效度回答不同问题

**信度**关注特定人群和测量条件下，分数相对于随机误差的稳定性或一致性。重测、内部一致性和评分者一致性针对不同误差来源，不可互相替代。真实状态本来会变化时，跨日分数变化也未必都是仪器误差。[4](#ref-psych-measurement)

在简单经典测量模型X=T+E中，T是在规定重复测量条件下的真分数，E为误差；若误差均值为零且与T不相关，信度可写为真分数方差占总方差的比例。这里“真分数”是模型定义，不是完整心理本质。设两方差为100和25，比例为0.8，误差的标准差为5分。增加任务次数只有在相应误差能够平均、测量对象不变等条件下才可能改善精度，不能自动消除系统偏差。

**效度**关注证据和理论是否支持对分数作出的特定解释及用途。内容是否覆盖目标、与相邻构念能否区分、能否预测相关结果、不同语言和人群是否可比，都应提供证据。不能简单说一份量表“有效”，却不交代用于谁、解释什么。[4](#ref-psych-measurement)[25](#ref-psych-ethics)

图2的第二次得分严格等于第一次加12，相关系数为1，但两次绝不相等。相关擅长描述相对排序，不能单独确认绝对一致或校准正确。分数在新场景中稳定地受词汇量支配，也不能据此宣称已经测准了纯粹的注意。

## 研究设计 怎样区分关联与因果

### 观察 实验与定性研究各有用途

观察和调查描述变量怎样在自然条件下共同变化，可以生成、限制或检验理论。**相关**不独自确定因果方向，也不能排除共同原因；多变量观察研究可以使用明确的识别假设作因果分析，但把更多协变量放进回归并不自动满足这些假设。个案、访谈与定性分析能够研究经验、意义和过程，也需要说明材料选择、分析步骤与解释依据。[3](#ref-psych-design)

实验有意操纵自变量、观察因变量，并设置恰当对照。**随机分派**使处理条件不由参与者已有特点决定，在重复随机化意义下平衡潜在差异；一次有限样本仍可能不平衡。它不同于从目标人群随机抽样：前者主要服务因果比较，后者主要服务人群代表性。因果解释还需要检查实施差异、失访、条件串扰和测量偏差。[3](#ref-psych-design)

组内设计让同一个人经历多种条件，能够减少稳定个体差异，却要处理顺序、练习、疲劳与残留效应。随机顺序和顺序平衡解决的是不同问题，不能把“随机”当成一项包办所有控制的措施。准实验在无法随机分派时利用设计与情境信息，但应明确识别依据，不能把任何现成两组都当成等价对照。[3](#ref-psych-design)

### 一个总体优势可以由样本构成造成

图3设A、B为自行选择的两种训练方案。安静条件中A为81/90、B为19/20；噪声条件中A为1/10、B为16/80。在两种条件内，B的成功比例都较高；合并后却是A的82%高于B的35%。原因是A的大多数记录来自更容易的安静条件，而B大多数来自噪声条件。

这称为**Simpson反转**的一种情形，说明总体比例与分层比例可以相反。若将两种情境各按50%重新加权，A为50%，B为57.5%。但分层或标准化本身仍没有证明B训练的因果效应：是否调整某变量，取决于它是共同原因、处理后的中介还是其他角色，以及研究目标和设计。这里仅检验算术与解释逻辑。

## 感觉 知觉与心理物理测量

### 物理刺激不是体验的同名数字

**感觉**通常侧重感受系统对刺激的检测与转导，**知觉**侧重对信息的组织和解释；二者是有用的概念区分，不是两个彼此隔绝、严格串行的盒子。声压、频率和时间结构是物理描述，响度、音高、音色和声源分组是感知问题。经验、语境及多模态线索会参与解释，作用大小需要实验确定。[5](#ref-psych-perception)

**心理物理学**研究可控制的刺激与体验、判断、行为之间的定量关系。检测问有没有，辨别问是否不同，识别问属于什么，匹配问怎样才相等。这些任务不能仅凭“都在听声音”就相互换算。听力阈值、词语识别和日常交谈也分别依赖不同条件。[5](#ref-psych-perception)

### 心理测量函数与阈值依赖规则

**心理测量函数**描述刺激量x与某类反应概率的关系。一种教学形式是

$$
\begin{aligned}
p(x)&=\gamma+(1-\gamma-\lambda)S\!\left(\frac{x-\alpha}{\beta}\right),\\
S(z)&=\frac{1}{1+\exp(-z)},\quad \beta>0.
\end{aligned}
$$

S是逻辑函数，γ为下渐近线，1−λ为上渐近线，α为两渐近线的中点位置，β控制变化尺度。这里λ定义为上限距1的差；若把失误定义为“以一定概率完全随机作答”，其概率需要结合γ换算，不能直接同名代入。[7](#ref-psych-psychometric)

均衡二选一任务中无信息猜测的期望正确率为50%。图4设γ=0.5、λ=0.02、α=5、β=1.2，x是任意教学刺激单位，此时p(α)=0.74，75%准则对应x约5.1001。因此“阈值”必须交代任务、正确率准则和拟合形式；75%也不是所有检测任务的统一定义。拟合还要检查采样、数据量、失误与不确定性。[7](#ref-psych-psychometric)

### 敏感性与回答偏向

在是/否检测任务中，**命中率H**是有目标时回答“有”的比例，**虚警率F**是无目标时回答“有”的比例。漏报为1−H，正确拒绝为1−F。仅看命中率，无法区分更会发现信号与更愿意回答“有”。[6](#ref-psych-sdt)

在等方差高斯证据模型中，设无目标证据为N(0,1)，有目标为N(1.5,1)，证据超过k时答“有”。标准化敏感性d′=Φ⁻¹(H)−Φ⁻¹(F)始终为1.5；偏向指标c=−[Φ⁻¹(H)+Φ⁻¹(F)]/2=k−0.75。Φ是标准正态累积分布。移动k会同时改变H和F，而不改变这两个假定分布间的距离。真实数据不保证满足等方差高斯条件；比例为0或1时，有限样本估计也需适当处理，不能生硬代入无穷值。[6](#ref-psych-sdt)

## 注意 记忆与意识

### 注意选择了什么 任务就能直接测到吗

**注意**指对信息和行动的选择、优先处理、维持与调节。选择性注意、持续注意和分配注意研究的问题不同。“资源有限”是有用的概括，但不意味着所有任务共享一个固定容量的单池，也不意味着无关注的信息完全没有加工。[8](#ref-psych-attention)

在双耳或多说话者任务中，跟随目标并复述可以研究选择；但成绩差也可能源于难度、记忆或语言。双任务增加后某项成绩下降，说明在这些任务组合中存在干扰，还需分析干扰发生在哪个环节。不能从“自己感觉能同时做两件事”或“得分未变”直接断定加工完全并行、没有代价。[8](#ref-psych-attention)

**意识体验**与可报告、任务操作和神经活动有关，却不是这些指标的简单同义词。没报告一个声音，可能涉及未觉察、遗忘、判据或未理解指令；从单一无报告结果不能唯一判断它完全没有进入加工。讨论有意识与无意识加工时，应说明怎样测量觉察和处理替代解释。

### 记忆不是单一仓库

**工作记忆**指在当前活动中暂时保持并使用信息的功能；长期记忆涉及较持久的信息。长期记忆中，可区分个人事件的情景记忆、事实与意义的语义记忆，以及技能、习惯等不必以有意识回忆方式表达的学习。它们不是只凭保存秒数划出的同质容器，容量也不应被压成人人固定的一个数字。[9](#ref-psych-memory)

**编码**是形成可保持信息的过程，**保持**涉及信息随时间的持续，**提取**是在相应线索和任务下使用它。当前提取失败不能直接证明信息已彻底消失；熟悉感、再认和自由回忆也不是同一种指标。回忆会受线索、既有知识和后续信息影响，不能当成逐帧重放。[9](#ref-psych-memory)

图5的衰减曲线只是p(t)=0.15+0.85exp(−t/2)的指定例子，t以天计，时间尺度为2天。它不是统一的“遗忘曲线”，更没有给出应对所有材料的最佳复习日程。真实保持取决于材料、学习和提取条件，不能仅由经过几天推算某个人还记得多少。

### 提取练习不等于不断考试

提取练习让学习者主动尝试回忆，测试因此也可能改变后续学习。Roediger与Karpicke的2006年两项散文学习实验中，重复阅读在5分钟测试上有优势，而先前提取练习在所研究的较长延迟上带来更好保持。这里的材料、学生、练习与延迟都属于结论范围；不能推出任何测试、任何难度和任何学习者都会同样获益。设计教学还需考虑反馈、提取是否成功、负担与迁移。[10](#ref-psych-retrieval)

## 学习 经验怎样改变预测和行为

### 条件作用 强化与惩罚

**学习**是与经验有关、相对持久的知识或行为潜能变化；当下表现还受疲劳、动机和情境影响。习惯化是反复刺激后反应减少的一类非联结学习，应与感受器适应、运动疲劳区分。观察、规则理解和探索也可以产生学习，不是所有改变都靠奖励塑造。[11](#ref-psych-learning)

**经典条件作用**研究线索与事件关系怎样形成预测，**操作性条件作用**研究行动与后果的关系怎样改变后续行动。强化以行为随后增加来定义，惩罚以行为随后减少来定义；“正/负”指增加或移除刺激，不是道德评价。负强化是移除某种刺激后行为增加，不等于惩罚。例如按键使干扰声停止，若以后按键更多，才符合该负强化关系；仅知道声音停止还不够。[11](#ref-psych-learning)

**消退**既可指停止原有强化关系的程序，也可指随后条件反应下降的现象。它不自动等于旧学习彻底抹除；反应在某些情境或时间后重新出现，提示需要区分既有关系与新的情境学习。[11](#ref-psych-learning)

### 预测误差模型与阻塞

Rescorla–Wagner模型用已有预测与实际结果的差来更新联结强度。对同一试次中出现的线索i，一种合并速率参数的写法是

$$
V_{i,n+1}=V_{i,n}+\eta_i
\left(\Lambda_n-\sum_{j\in C_n}V_{j,n}\right).
$$

V为模型联结强度，Λ为该试次结果支持的渐近量，C为出现的线索集合，η为有效学习速率；原模型中它可由线索和结果参数的乘积构成。所有出现线索应依据更新前的总预测同时计算误差。这里的V没有被定义为神经电压，模型也不是关于所有人类学习的完整定律。[12](#ref-psych-rw)

设Λ=1、ηA=ηB=0.2，先让A单独与结果配对20次，VA=1−0.8²⁰约0.98847。随后A、B一起出现并继续给结果15次，B最终仅约0.005762；若两线索都从0开始，15次复合训练后各约0.499765。旧线索已能很好预测结果，新线索可获得的误差很小，这说明模型怎样产生**阻塞**式预测。只有在本例VA恰为1时，B更新才严格为0，有限预训练不能写成完全零。[12](#ref-psych-rw)

## 思考 语言与决策

### 表征 规则与启发式

**认知表征**指系统用来保持和使用信息的形式；概念帮助把不同事物按可用关系组织，推理则从已有信息导出结论。行为上相同的答案可能由规则、记忆实例或近似策略产生，需要新材料、反应时间、错误模式与迁移来区分。

**启发式**是简化判断和搜索的策略。在特定任务中偏离某种规范标准可称为偏差，但应先说清标准、信息和代价。快速近似在某些环境里可能有效，不能把人与一个知道全部信息的理想模型比较后，就概括为“人不理性”。语言也不只是声学分类：词义、句法、语境和共同知识共同参与理解，实验应控制材料经验与表达要求。[13](#ref-psych-decision)

### 条件概率与先验发生率

设某声音类别A占10%，一个线索在A中出现率为80%，在非A中为20%。在1000次指定事件中，A且有线索为80次，非A且有线索为180次。因此看到线索后为A的概率是80/260，约30.77%，不是80%。这是条件概率方向不同，不是在描述某人实际一定怎样判断。[13](#ref-psych-decision)

这里的Bayes规则给出指定模型中的概率更新。是否据此选择A还取决于错判代价、收益和行动目标；概率最大者不总是期望损失最小的行动。先验也不等于随意偏见，它可以来自场景发生率，但必须说明来源和适用范围。

### 反应更慢不自动说明加工更差

**速度与正确率权衡**指某些任务中，改变作答谨慎程度能够同时改变速度与错误。一种简化双选择扩散模型假设证据X按dX=vdt+sdW积累，从0出发，碰到+a或−a就作答，另加非决策时间t₀。v为平均漂移，s为扩散尺度，a为边界距离；W为标准Wiener过程，在很短时间dt内，随机增量dW的均值为0、方差为dt。它用来描述模型中的连续噪声，不表示每个真实心理过程都一定如此变化。参数与刺激质量、策略及其他环节的关系要靠数据检验。[14](#ref-psych-ddm)

在a、v、s都为正、其余条件固定的上述简化模型中，上边界命中概率与平均总反应时间为

$$
\begin{aligned}
P_+&=\frac{1}{1+\exp(-2va/s^2)},\\
\mathbb E[RT]&=t_0+\frac{a}{v}\tanh\!\left(\frac{av}{s^2}\right).
\end{aligned}
$$

固定v=s=1、t₀=0.3秒且将上边界定义为正确，a=0.5、1、2时，模型正确率约0.731、0.881、0.982，平均总反应时间约0.531、1.062、2.228秒。证据单位为任意模型单位，v与s分别具有证据/秒、证据/根号秒单位。这里变化的是边界，不能把慢反应直接解释成较低能力，也不能从均值和正确率两个数唯一反推出真实参数；拟合通常还要检验正确与错误反应的分布。[14](#ref-psych-ddm)

## 情绪与动机 体验 身体和行动目标

### 情绪不是一个可由单指标读取的标签

**情绪**涉及对事件的评价、主观体验、生理变化和行动倾向；这些成分可以相关，也可能不完全一致。愉快度与唤醒度是有用维度，但两个坐标并不能穷尽情绪意义，也不意味着同一表情或高唤醒总对应同一种情绪。[15](#ref-psych-emotion)

尖锐声音可能引起身体警觉，个人却因知道它是实验提示而报告并不害怕。研究者要分别记录声音属性、解释、身体与报告，不能见到心率或瞳孔变化就唯一认定某种内心状态。情绪会影响交流与判断，表达也受社会规范和文化意义约束；图8是功能关系示意，不是一套已定论的情绪发生顺序。[15](#ref-psych-emotion)[21](#ref-psych-culture)

### 动机决定目标与投入 但不能包办解释

**动机**涉及行动的方向、启动、强度与维持，**目标**是期望达到的状态。外在奖励、兴趣、价值、预期成功和成本都可能影响选择。内在与外在动机不是两种互斥人格；同一行为也可以同时服务多个目标。[16](#ref-psych-motivation)

在听觉实验中，难度提高可能引发更多努力，也可能在目标不值得或成功希望很低时引起放弃。因此成绩、主观费力、实际投入和疲劳需要分别测量。“表现差是因为不努力”若没有可独立核查的证据，只是把结果改名，不能构成机制解释。[16](#ref-psych-motivation)

## 毕生发展 人格与个体差异

### 年龄差异与一个人的变化不同

**发展**研究功能随生命历程、成熟与经验怎样变化，不仅研究儿童，也包括成年与老年。不同能力的轨迹可以不同；同龄者也可能有很大差异。横断研究比较不同年龄的人，纵向研究追踪同一批人，二者会受到不同的队列、练习与选择性流失影响。[17](#ref-psych-development)[18](#ref-psych-aging)

图9虚构两批人在同一日历时点分别为40岁80分和60岁66分，表面年龄差为14分；各自追踪20年却都只降4分。它说明队列或其他群体差异可以混入横断比较，不是在断言现实年龄效应都是队列效应。儿童任务还需匹配语言理解、动作和参与方式；未完成任务不必然等于没有相关能力。[17](#ref-psych-development)

### 特质是倾向 不是把人装进互斥盒子

**人格特质**描述跨一定时间和情境的典型感受、想法与行为倾向。大五中的开放性、尽责性、外向性、宜人性和神经质是常见维度；每个维度可以继续分解，五因素也不是所有文化和目的下唯一完整的人格理论。较高外向性不表示每次都说话更多，特质与情境都参与具体行为。[19](#ref-psych-traits)

能力、兴趣、状态和特质也不能混成一种总分。常模说明某个参照样本中的相对位置；百分位不是答对百分比，标准化分数也不自动具有跨人群可比性。翻译、任务熟悉度和测量结构需要核查，尤其不能把语言不熟造成的低分直接命名为低认知能力。[4](#ref-psych-measurement)[25](#ref-psych-ethics)

### 组均值不能替代对个体的观察

图9另设两组正态分布，均值0与0.5、标准差都为1；重叠面积约80.26%。这是纯数学示例，不对应任何性别、文化或听力人群。均值不同仍可大量重叠，知道组别不能确定某个人的分数。讨论真实群体差异还需报告分布、测量可比性、选择与环境，不能直接推成先天或不可改变的原因。

## 社会 文化与心理学的应用

### 他人和情境是解释的一部分

**社会心理学**研究实际、想象或隐含的他人及社会情境怎样与思想、情绪和行为有关。规范规定群体认为适当的做法，社会影响涉及他人改变判断或行动的过程，归因则涉及人怎样解释事件与行为原因。观察到顺从或沉默时，应同时检验信息、关系、权力和任务条件，不能直接推出固定人格。[20](#ref-psych-social)

同样的听觉回答可能受是否当众、对说话者身份的理解、交流礼貌和是否担心出错影响。这些不必然是要清除的“噪声”：研究纯知觉机制时可以控制，研究真实交流时也可以成为重要对象。实验室控制与日常适用性需要共同考虑，而不是由其中一个自动保证另一个。[20](#ref-psych-social)

### 文化与样本代表性

**文化**包括人们共同学习、使用并持续变化的意义、实践与规范，不能等同国籍，也不意味着群体内部完全一致。翻译相同字面不保证同一题在不同环境里有同样含义。跨文化比较需要检验测量可比性，并记录教育、语言、生活条件与抽样方式。[21](#ref-psych-culture)

大学生、线上志愿者或单一城市样本可以有效回答某些问题，但结论推广到儿童、老年人、不同语言人群或日常交流时，需要额外证据。组均值更不能作为判断某个个体的捷径。

### 基础知识怎样进入教育 临床与人因

教育心理学研究教学、学习与评价，健康和临床相关领域研究适应、困难及干预，人因与组织心理学研究人与工具、任务和工作环境的配合。实际应用除统计差异，还要考察持续获益、负担、公平、可接受性和实施条件。心理学研究、心理咨询、临床诊断和医学治疗是有关联而职责与训练要求不同的活动；一项基础任务或网络问卷不能单独完成这些复杂评估。[1](#ref-psych-scope)[25](#ref-psych-ethics)

## 与神经科学和计算模型怎样配合

### 行为与神经数据相互约束

心理学问“要解释什么功能和行为”，[计算神经科学](../computational-neuroscience/)把机制假设写成可计算模型，[生物物理学](../biophysics/)进一步约束电、化学和能量实现。它们相互支持，但不存在从一个心理词语到一个固定脑区、再到一个唯一方程的简单对应。

**反向推断**是从观察到的神经活动推测心理过程。若某脑区在过程A时常活动，只知道活动出现仍不足以确认A：还要知道没有A时该活动多常见，以及A的先验发生率。它不是在任何情况下都无效，而是需要选择性、验证和概率条件。多变量解码在留出数据上成功，也只首先证明指定目标在该验证范围内可预测，不自动证明因果或完整理解。[22](#ref-psych-reverse)

### 计算解释需要超出画出一条像样的曲线

心理模型的变量要说明单位、可观察对应和约束；参数是否能够由现有数据区分，是**可辨识性**问题。两套机制都能拟合同一正确率曲线时，可通过新难度、反应时间分布、训练迁移或独立指标寻找不同预测。模型选择还应考虑复杂度与留出预测；拟合得好不等于模型内部过程就是人体真实过程。[14](#ref-psych-ddm)[22](#ref-psych-reverse)

## 统计 不确定性与可重复研究

### 谁独立 以谁作为推断单位

同一人做20题，题目反应往往相关；50人各做20题不能在所有推断中当成1000个独立的人。参与者、材料、班级和实验批次可能形成层级。应按研究目标保留相应抽样单位，使用恰当的重复测量、层级模型或聚类处理；材料的推广范围也不能被大量重复试次代替。[3](#ref-psych-design)

图10设每人m=20次记录，每次方差1，同一个人的任意两次相关ρ=0.2，不同人独立。在这个等相关、等次数模型里，总均值的方差为[ρ+(1−ρ)/m]/n。50人时，正确标准误约0.06928；误当1000次独立记录会得到0.03162。两者相差约2.191倍；等效样本量约208.33只是此方差公式的换算，不能代替50个独立参与者的实际设计与自由度。

### 效应量 区间与检验各自说明什么

**效应量**描述指定差异或关联的大小；**置信区间**在其模型与抽样程序成立时具有长期覆盖解释，不是固定真参数落在本次区间中的频率学概率。**p值**是在零假设和相应统计模型下，获得至少同样极端结果的概率；它不是零假设为真的概率，也不是效应大小或实际重要性。p较大不自动证明无差异，要评价“足够接近”，需明确实际可忽略范围并使用相应设计与分析。[23](#ref-psych-asa)

预注册提前说明主要问题、分析和排除规则，有助于区分验证与探索；探索仍有价值，但应诚实标明。开放代码和材料便于复算，新的样本复制检验结果能否再现，两者解决不同问题。完整报告失访、排除、多个指标和不理想结果，也有助于减少选择性报告。[24](#ref-psych-replication)[23](#ref-psych-asa)

### 复制结果不能变成全学科真伪率

Open Science Collaboration于2015年报告，对三个心理学期刊中100项研究进行复制，36%的复制达到其统计显著性指标。该项目主要涉及所选期刊2008年研究，不是对所有心理学随机抽样；显著性也不是唯一复制标准。因此不能说“心理学只有36%是真的”，也不能由一次复制未显著就确定原结论必假。应同时比较效应、精度、方法忠实性与适用情境。[24](#ref-psych-replication)

## 综合例子 怎样研究背景声是否影响记忆

### 先明确问题和可证伪的预测

把“噪声损伤认知”改成具体问题：在指定声级和材料下，背景谈话相对安静是否改变一组成年参与者对句子末词的即时复述与稍后回忆？分别记录即时可懂度和延迟记忆，才有机会区分输入已缺失与输入之后的保持、提取变化。即使即时成绩相同，也不能仅凭这两个指标唯一定位机制。[3](#ref-psych-design)[9](#ref-psych-memory)

可采用组内设计并平衡材料，避免同一材料反复学习造成条件串扰；在实验前规定练习、休息、声学校准、设备和退出处理。若奖励、可见口形或提示方式改变，要说明它们是实验因素还是控制条件。随机分派顺序并不能替代声级和材料控制。

### 分析和伦理从设计时开始

分析应保留参与者与句子的重复结构，报告比例差、效应区间和个体分布，并检查缺失与顺序效应。解释时排查可听度、语言熟悉度、策略和疲劳；“分数下降”不能独自证明工作记忆容量下降，更不能由这种短期任务推出长期脑损伤。

参与者应获得可理解的说明、退出方式及隐私信息；录音、可识别数据和敏感自陈要有适当管理。听力差异需要可达的交流安排，不能把没听清同意说明当成已理解。研究中的欺骗须有充分理由、适用审查及事后说明；APA伦理规范是专业来源之一，具体研究还要遵守所在地和机构的要求。[25](#ref-psych-ethics)

## 三个复算练习与阅读路线

### 练习一 看清总体反转的分母

```python
import numpy as np
ok = np.array([[81, 1], [19, 16]])
total = np.array([[90, 10], [20, 80]])
print("分层比例：", ok / total)
print("合并比例：", ok.sum(axis=1) / total.sum(axis=1))
print("两情境等权：", (ok / total).mean(axis=1))
assert np.all((ok / total)[1] > (ok / total)[0])
assert ok[0].sum() / total[0].sum() > ok[1].sum() / total[1].sum()
```

### 练习二 改变判据 保持模型敏感性

```python
import numpy as np
from scipy.stats import norm
k = np.array([0.0, 0.75, 1.5])
H, F = norm.sf(k - 1.5), norm.sf(k)
dp = norm.ppf(H) - norm.ppf(F)
c = -(norm.ppf(H) + norm.ppf(F)) / 2
print(np.column_stack([k, H, F, dp, c]))
assert np.allclose(dp, 1.5)
assert np.allclose(c, k - 0.75)
```

观察H、F一起变化。再问：若实际两种证据方差不同，为什么不能未经检验照搬这里的解释？

### 练习三 联结更新必须同时使用旧值

```python
import numpy as np
A, B = 0.0, 0.0
for _ in range(20):
    A += 0.2 * (1 - A)
for _ in range(15):
    error = 1 - A - B
    A, B = A + 0.2 * error, B + 0.2 * error
expected_B = 0.8**20 * (1 - 0.6**15) / 2
print(A, B, expected_B)
assert np.isclose(B, expected_B)
```

改变预训练次数，检查B为何从较大更新逐渐变成很小更新。若将同一试次的B更新错误地放在A更新之后并重新计算误差，会实现另一套算法，不能再称为上式的同时更新。
