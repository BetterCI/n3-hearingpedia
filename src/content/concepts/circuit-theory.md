**电路原理**（circuit theory）研究怎样用元件关系、连接结构以及电荷和能量约束，确定电网络中的电压、电流、功率及其随时间和频率的变化。它把复杂的电磁过程抽象为可求解的网络，同时要求说明抽象何时有效。电路图不是实物的缩小照片，而是对端口、连接和工作条件的模型。[1](#ref-ct-lumped)

在听觉研究中，一支麦克风为何接入不同输入端后电平不同？隔直电容为何会削弱低频？标为“32 Ω”的耳机为何不一定在所有频率都呈32 Ω？测量探头为何会改变被测波形？这些问题都需要先把源、负载、储能和测量过程分开。

本篇从基本定义展开，前置知识为代数、微积分和简单微分方程；[复变函数](../complex-analysis/)中的复数、[线性代数](../linear-algebra/)中的矩阵可帮助理解交流与网络分析。十幅图及全部数值均为原创理想模型或指定模拟，不是商品规格或听者实测。范围以集中参数、线性及小信号电路为主，并介绍运放和测量边界；不代替完整的电磁场、半导体或电力系统课程。

## 先定义物理量和模型边界

### 电荷 电流和电压

**电荷** $q$ 的单位是库仑（C）；沿指定方向的**电流**为 $i=dq/dt$，单位安培（A）。正方向由分析者规定，解出负电流表示实际电荷净流动与参考方向相反，不是“计算不合理”。金属中电子漂移方向与常用的正电荷电流方向相反。

**电压** $u_{ab}$ 是端点 $a$ 相对于 $b$ 的电势差，记为 $u_{ab}=v_a-v_b$，单位伏特（V）。写“某节点电压”时隐含了参考节点；把参考节点设为零不会把整个实物强制接到大地。电路中的“地”、机壳、信号公共端和保护接地需要按实际连接辨认，不能只因画了同一形状就认定物理关系完全相同。

电流是通过支路的量，电压是两个端点之间的量。不能问“电流在一个点上储存了多少”，也不能不指定参考端就给出完整电压含义。对电容，储存状态可用电荷或电压描述；电流表示电荷改变的速率。[2](#ref-ct-kirchhoff)[3](#ref-ct-elements)

### 功率的参考方向

采用**关联参考方向**：电流流入电压标记的正端。此时瞬时吸收功率 $p(t)=u(t)i(t)$，单位瓦特（W）；$p>0$ 表示元件从外界吸收能量，$p<0$ 表示向外送出能量。能量变化为 $\Delta W=\int p(t)\,dt$，单位焦耳（J）。电源也可吸收能量，电容和电感也可在一段时间内向外释放能量。

“正端”是电压参考标记，不保证它在每一时刻真的比另一端高；“电流流入正端”也是参考约定。若换用非关联方向，吸收功率应写成 $-ui$。先统一约定，再解释正负，比看到负号就改变箭头更可靠。

### 为什么能把导线画成一个节点

**集中参数模型**把电阻、电容、电感等效应集中到元件中，把理想连接导线视为等电位。一个重要条件是电路尺寸与互连传播延迟，相对信号的空间和时间尺度足够小；还需要把显著的寄生电容、寄生电感和外部耦合纳入模型。[1](#ref-ct-lumped)

例如，若波在互连中的传播速度取 $2\times10^8$ m/s，20 kHz对应波长约10 km；短音频连线常能近似为集中网络。但同一装置中若存在很快的开关边沿，相关高频成分、长导线和接地回路仍可能重要。不能只依据声音的最高频率，就忽略电路内部所有高频过程。

节点法中的理想节点不单独积累未建模的净电荷，回路中的显著时变磁通则应由电感、互感或等效感应源表示。若忽略这些条件，直接把电磁系统压成简单电阻网络，就可能误用守恒方程。

## 元件方程和电源

### 电阻 电容与电感

恒定线性**电阻**满足 $u=Ri$，$R$ 的单位为欧姆（Ω），电导 $G=1/R$ 的单位为西门子（S）。$R>0$ 时 $p=Ri^2=u^2/R\ge0$，理想电阻不储存状态，吸收的电能按模型耗散。[2](#ref-ct-kirchhoff)

恒定线性**电容**满足 $q=Cu$，因而 $i=C\,du/dt$；$C$ 的单位为法拉（F）。恒定线性**电感**在关联方向下满足 $u=L\,di/dt$，$L$ 的单位为亨利（H）。若将零状态作为能量零点，有

$$
W_C=\frac12Cu^2,\qquad W_L=\frac12Li^2.
$$

这些是可恢复储能，不是已经耗散的热量。对时变电容，应从 $i=d(Cu)/dt$ 出发；磁饱和、迟滞或其他非线性电感也不能直接套用恒定 $L$ 的全部结论。[3](#ref-ct-elements)

“电容隔直、电感通直”只是在适当直流稳态下的简写。电容可保持非零直流电压，电感可承载非零直流电流；刚切换时仍要满足初始条件。在没有冲激电流的条件下电容电压连续，没有冲激电压时电感电流连续；理想电容直接接理想突变电压源等模型可能恰好要求冲激，不能把连续性说成无条件禁令。

### 独立源 受控源 开路与短路

**理想电压源**规定端口电压，由其余电路决定电流；**理想电流源**规定支路电流，由其余电路决定电压。它们不自动包含真实器件的输出电阻、最大电流、供电范围或功率限制。

**受控源**的输出由电路中另一电压或电流决定。例如电压控制电流源 $i_o=g_m u_c$，跨导 $g_m$ 的单位是S；电压控制电压源的电压增益则无量纲。受控源可描述放大器和小信号器件；网络求等效电阻时不能随意把它关掉。[4](#ref-ct-dependent)

理想**开路**规定电流为零，端口电压可非零；理想**短路**规定电压为零，电流可非零。两个不同电压的理想源直接并联等连接可能互相矛盾；无损理想回路也可能使某些电流不唯一。这通常提示模型缺少内阻或约束冲突，不能把无穷大或无解当真实装置的最终工作状态。

### 非线性与小信号

二极管的电流电压关系一般非线性，叠加原理不直接适用。若已确定直流工作点 $(U_Q,I_Q)$，可以对小扰动线性化，例如 $\delta i\approx g_d\,\delta u$，其中 $g_d=(di/du)_Q$。工作点与增量必须分开，且扰动范围要足够小。[5](#ref-ct-diode)

小信号模型可用于分析麦克风前置级或偏置电路附近的响应，但当信号使器件进入截止、饱和或明显失真时，需要回到非线性模型。把小信号增益乘任意大的输入，不会自动得到真实输出。

## 基尔霍夫定律与系统分析

### 节点 支路 回路和两个守恒式

**节点**是理想导线直接相连的端点集合；**支路**连接两个节点并承载所定义的支路电流；**回路**是沿连接返回起点的闭合路径。电路画得相近不代表相连，画得远也不代表不同节点；应按导线和连接点读拓扑。

**基尔霍夫电流定律**（KCL）在上述节点模型下写为 $\sum_k i_k=0$，例如统一把离开节点的电流取正。它源于电荷守恒。**基尔霍夫电压定律**（KVL）在适用的集中回路模型中写为 $\sum_k u_k=0$，沿回路逐段计入电压升降。对于显著外部时变磁通，需补入相应感应效应，不能把“任何路径的电场积分恒为零”当一般电磁定律。[1](#ref-ct-lumped)[2](#ref-ct-kirchhoff)

串联要求中间连接处没有额外分流，因此各元件电流相同；并联要求两端分别接在同一对节点，因此电压相同。两只电阻即使竖着并排画，也不一定并联。

### 节点电压法

先选参考节点，再把每条电阻支路电流写为 $(v_a-v_b)/R$，对未知节点列KCL。线性电阻网络可写为 $Gv=j$：矩阵对角项汇总连接到该节点的电导，非对角项为两个未知节点间电导的负值；已知源节点贡献进入右侧。[6](#ref-ct-node)

图2中，1 V已知源经 $R_1=1$ kΩ接节点A；A经 $R_2=2$ kΩ接地，经 $R_3=1$ kΩ接B；B经 $R_4=1$ kΩ接地，并有0.2 mA从地注入B。于是

$$
\frac{V_A-1}{1000}+\frac{V_A}{2000}+\frac{V_A-V_B}{1000}=0,\qquad
\frac{V_B-V_A}{1000}+\frac{V_B}{1000}=0.0002.
$$

各式用V、Ω、A，可得 $V_A=0.550$ V、$V_B=0.375$ V。图中四条电阻电流依次为0.450、0.275、0.175、0.375 mA，A处满足0.450=0.275+0.175，B处满足0.175+0.200=0.375。全部电阻耗散0.525 mW，恰等于两个源合计供出的功率。这个能量复核独立于“方程解出了数字”这一事实。

若理想电压源跨在两个未知节点之间，可以用**超节点**的KCL配合电压差约束；也可使用**改进节点分析**，将源电流作为附加未知量。不能把理想电压源硬改成一个零欧姆电阻再除以零。

### 网孔法 线性与可解性

对平面电路可选取各**网孔**，为每个网孔设环流并列KVL；共享电阻的支路电流是相应网孔电流的代数差。网孔不是任意回路的同义词，网孔法的常规形式要求可平面嵌入的拓扑；一般回路分析的范围更广。[6](#ref-ct-node)

线性方程解的唯一性还依赖参考选择、连接和源约束。全浮置网络可能只确定电位差，不确定绝对节点电位；理想源约束冲突时可能无解。分析前应检查拓扑，求解后检查KCL、KVL、量纲和功率，而不是通过盲目增大数值精度来掩盖模型问题。

## 等效电路 叠加与负载

### 叠加什么 如何关闭源

在线性网络中，可分别计算独立源对电压、电流的贡献，再相加。将独立电压源置零等价于短路，将独立电流源置零等价于开路；真实源的内阻仍在，受控源仍按控制关系工作。动态网络若有初始储能，还要计入其零输入响应，不能在每次计算中重复或遗漏。[7](#ref-ct-linear)

功率不是线性变量。例如同一电阻的两项电流 $i_1,i_2$ 叠加后，功率是 $R(i_1+i_2)^2$，一般不等于 $Ri_1^2+Ri_2^2$。先叠加电压或电流，再按完整结果求功率。

### 戴维南和诺顿等效

线性二端网络在端口关系可用有限等效参数表示时，可写成**戴维南等效**：电压源 $V_{\mathrm{th}}$ 串联 $R_{\mathrm{th}}$；等价的**诺顿形式**为电流源 $I_{\mathrm N}=V_{\mathrm{th}}/R_{\mathrm{th}}$ 并联 $R_{\mathrm{th}}$，这里先讨论非零、有限电阻的情形。交流时用对应复阻抗，某些理想源或奇异端口需单独处理。[7](#ref-ct-linear)

$V_{\mathrm{th}}$ 可由端口开路电压取得。求等效电阻时，置零独立源，再从端口施加测试电压或电流，利用比值确定；保留受控源。含有源元件的网络可能呈负的增量电阻，不能把所有等效电阻都默认成被动正电阻。

### 为什么接入测量设备后电压变了

两个10 kΩ电阻对1 V源分压，开路输出是0.5 V，端口等效电阻是5 kΩ。若再接10 kΩ负载，输出为

$$
u_o=0.5\frac{10000}{5000+10000}=\frac13\ \mathrm V.
$$

也可直接把下方电阻改成 $10\,\mathrm{k}\Omega\parallel10\,\mathrm{k}\Omega=5\,\mathrm{k}\Omega$ 求解，两种方法一致。这里 $\parallel$ 表示并联，两个电阻的并联值为 $R_aR_b/(R_a+R_b)$。

对电压型麦克风的简化模型，源电阻取2 kΩ，输入电阻10 kΩ时电压传输比为0.8333，改为100 kΩ时约0.9804。真实麦克风还可能有偏置、耦合、复输出阻抗和最大负载等条件；这些数字不指向具体型号。学习这里的目标是识别加载，而不是凭输入电阻一个参数评价整套录音质量。[23](#ref-ct-mic)

## 一阶电路与初始条件

### 从电流守恒得到RC微分方程

理想电压源 $V_s$ 经电阻 $R$ 给接地电容 $C$ 充电，电容电压记为 $u_C$。由KCL和元件方程，

$$
C\frac{du_C}{dt}=\frac{V_s-u_C}{R},\qquad
u_C(t)=V_\infty+(U_0-V_\infty)e^{-t/\tau},\quad \tau=RC.
$$

后一个式子用于切换后拓扑固定、驱动恒定的情形，$U_0=u_C(0^+)$，$V_\infty$ 是该情形下的最终电压。**时间常数** $\tau$ 表示偏离最终值的量衰减到原来的 $e^{-1}$，不是等到 $\tau$ 以后才发生响应。[8](#ref-ct-first)

图4取 $R=10$ kΩ、$C=1$ µF、$U_0=0$、$V_s=1$ V，$\tau=10$ ms；在10 ms时电压为0.6321 V、电流为36.79 µA。5个时间常数后达到最终变化量约99.33%，仍非数学上的完全稳态。

### 自然响应 强迫响应与等效时间常数

**零输入响应**由初始储能引起；**零状态响应**是在零初始条件下由输入引起，线性网络的完整响应为两者之和。对稳定的一阶恒定驱动，还常写成“最终值加衰减暂态”；不同教材对“自然、强迫”的分解方式可能不同，应看清具体定义。

只有一个独立储能状态且网络可化成合适一阶形式时，可由电容端看到的等效电阻求 $\tau=R_{\mathrm{eq}}C$，求电阻时置零独立源并保留受控源。含有源反馈或负等效电阻时可能不稳定，不能预设所有指数都衰减。[9](#ref-ct-first-complete)

对串联RL电路，电感电流是状态，$\tau=L/R$。断开一个带电流的真实电感时，电流连续性可能通过寄生电容、其他电流通路或高电压体现；简单“电感立即变成开路”通常不是充分模型。

### 用能量再次检查

零初始电压的理想电容由恒定源经电阻充电至 $V_s$，源供能 $CV_s^2$，电容最终储能 $CV_s^2/2$，电阻耗散另外一半。图4分别是1 µJ、0.5 µJ和0.5 µJ；在这一特定模型中，电阻大小改变充电速度而不改变总耗散。

这不是所有充电方式都损失一半能量的普遍定律。若输入缓慢变化、初始电压非零、加入电感回收能量或有其他通路，能量分配会变。理想模型的“最终”还隐含切换后电路能够达到该稳态。[17](#ref-ct-energy)

## 正弦稳态 相量和阻抗

### 相量采用RMS还是峰值

对固定角频率 $\omega$ 的正弦稳态，本篇采用**有效值相量**：

$$
u(t)=\sqrt2\,\operatorname{Re}\{\underline U e^{j\omega t}\},\qquad
\underline U=U_{\mathrm{rms}}e^{j\varphi},\quad \omega=2\pi f.
$$

下划线表示复相量，$j^2=-1$；电工中用 $j$ 避免和电流 $i$ 混淆。相量包含幅值和相位，本身不再带共同的时间因子。教材若采用峰值相量，功率公式会多出相应的 $1/2$ 因子，不能混用。[10](#ref-ct-impedance)[11](#ref-ct-phasor)

对于纯正弦，$U_{\mathrm{rms}}=U_{\mathrm{peak}}/\sqrt2$；一般波形有效值由 $\sqrt{T^{-1}\int_0^T u^2(t)\,dt}$ 定义，不能一概除以 $\sqrt2$。含多个频率时，应在各频率分别分析再回到时域，不把不同频率的相量直接当同一个数相加。

### 阻抗和导纳

在关联方向下定义**阻抗** $Z=\underline U/\underline I$，单位Ω；**导纳** $Y=1/Z$，单位S。对恒定理想R、L、C，

$$
Z_R=R,\qquad Z_L=j\omega L,\qquad Z_C=\frac1{j\omega C}.
$$

这是微分在固定频率下对应乘 $j\omega$ 的结果。电感电压领先电流90°，电容电流领先电压90°；并不是说电容在任何输入下都把信号固定提前四分之一秒。

写 $Z=R+jX$ 时，$R$ 是实部，$X$ 是电抗。串联阻抗相加，并联导纳相加；复数分压同样来自KCL与KVL。相量法描述稳态特解，不自动包含刚上电的暂态或初始能量。

### RC低通 高通与加载

串联R、并联接地C，输出跨C且不再加载时，$H_{\mathrm{LP}}(j\omega)=1/(1+j\omega RC)$。串联C、输出跨接地R时，$H_{\mathrm{HP}}=j\omega RC/(1+j\omega RC)$。两者的截止角频率为 $\omega_c=1/(RC)$，$f_c=1/(2\pi RC)$；在各自通带增益为1的约定下，截止处幅值为 $1/\sqrt2$，约−3.0103 dB。[12](#ref-ct-filters)

若低通输出又接电阻 $R_L$，则

$$
H_L(s)=\frac{R_L}{R+R_L+sRR_LC}
=\frac{R_L}{R+R_L}\frac1{1+s(R\parallel R_L)C}.
$$

它同时改变直流增益和极点。图5用 $R=R_L=10$ kΩ、$C=10$ nF，空载 $f_c\approx1591.55$ Hz；加载后直流增益为0.5，极点频率约3183.10 Hz。加载曲线的−3 dB位置应相对它自己的低频增益判定，不能固定寻找绝对−3 dB。[12](#ref-ct-filters)

隔直电容与输入电阻形成的高通，可直接影响音频低端。例如忽略源阻抗，1 µF串联电容驱动10 kΩ输入，截止约15.92 Hz，但20 Hz幅值仍只有约0.7825，即约−2.13 dB。截止低于20 Hz不等于20 Hz已经没有衰减；实际还要考虑其他电容、偏置回路及源阻抗。

## 二阶电路 阻尼与共振

### 从两个储能状态得到二阶方程

串联RLC由理想电压源驱动，输出取电容电压，可得

$$
LC\,\ddot u_C+RC\,\dot u_C+u_C=v_s(t),\qquad
s^2+2\alpha s+\omega_0^2=0,
$$

其中 $\alpha=R/(2L)$，$\omega_0=1/\sqrt{LC}$，**阻尼比** $\zeta=\alpha/\omega_0$。$u_C(0)$ 与 $i_L(0)=C\dot u_C(0)$ 给出两个初始条件；不能只指定电容电压就认为问题完整。[13](#ref-ct-second)

对于 $R,L,C>0$ 的这个二阶模型，$\zeta<1$ 为欠阻尼，$\zeta=1$ 为临界阻尼，$\zeta>1$ 为过阻尼。欠阻尼暂态振荡角频率 $\omega_d=\sqrt{\omega_0^2-\alpha^2}$，并非一概等于 $\omega_0$。

图6取 $L=10$ mH、$C=1$ µF、零初始状态、1 V阶跃。电阻40、200、500 Ω分别对应 $\zeta=0.2,1,2.5$；自然角频率均为10000 rad/s，即约1591.55 Hz。图中的超调由指定二阶模型产生，不意味着实际耳机或听者必有相同振铃。

### 共振要说明驱动和观察量

**共振**描述某一输入输出关系的频率响应出现增强等特征，需明确输出。在串联RLC中，理想电压驱动的电流幅值在 $\omega_0$ 达到最大；此时电感和电容电抗抵消，总阻抗为R。跨R电压同样在该频率最大。[14](#ref-ct-resonance)

对这个串联电流或跨R输出，品质因数 $Q=\omega_0L/R=1/(2\zeta)$，半功率带宽 $\Delta\omega=R/L$，所以 $Q=\omega_0/\Delta\omega$。R=40 Ω时Q=2.5、带宽约636.62 Hz。这些关系针对指定拓扑和观察量，不是所有二阶输出都可原样套用。

电容电压的幅值峰若存在，其频率为 $\omega_0\sqrt{1-2\zeta^2}$，要求 $\zeta<1/\sqrt2$。因此“瞬态会振荡”“电流共振在自然频率”“电容电压有幅值峰”是三个相关但不同的命题。

## 变换方法与网络接口

### 拉普拉斯变换保留初始状态

单边拉普拉斯变换用复变量 $s=\sigma+j\omega$ 将微分方程改写为代数式。对适当的函数和初始值约定，$\mathcal L\{\dot u\}=sU(s)-u(0^-)$，所以

$$
I_C(s)=C[sU_C(s)-u_C(0^-)],\qquad
U_L(s)=L[sI_L(s)-i_L(0^-)].
$$

零初始条件时才可单独用 $1/(sC)$ 与 $sL$ 作为完整支路关系；非零初始状态还对应额外项。把相量的 $j\omega$ 换成 $s$，但忘记初始能量，并不是完整的暂态分析。[15](#ref-ct-laplace)

**传递函数** $H(s)=Y(s)/X(s)$ 描述线性时不变系统的零状态输入输出关系。极点与自然模态相关；对无隐藏不稳定模态的常规有限维系统，左半平面极点意味着相应模态衰减。若发生极零抵消，单个外部传递函数稳定也不能单独保证全部内部状态稳定。只有在频率响应存在及初始暂态能适当衰减等条件下，$H(j\omega)$ 才可解释为稳态频率响应。

### 二端口和级联为何会互相加载

**端口**由一对端子组成，并规定电压方向及电流进入方向。对线性时不变**二端口网络**，在指定频率或零初始状态的s域，可用阻抗、导纳或传输参数描述，例如 $\begin{bmatrix}U_1\\U_2\end{bmatrix}=Z\begin{bmatrix}I_1\\I_2\end{bmatrix}$，其中两个电流都定义为流入网络。并非所有参数形式在每个频率都存在，需检查开路、短路条件与矩阵可逆性。

若使用传输矩阵，采用 $\begin{bmatrix}U_1\\I_1\end{bmatrix}=T\begin{bmatrix}U_2\\-I_2\end{bmatrix}$ 的一致端口约定，级联可按顺序相乘。负号反映两级连接处端口电流方向相反。矩阵的A、D项无量纲，B项为Ω，C项为S，量纲可帮助发现写反的参数。

直接把两个“空载电压增益”相乘，通常忽略了级间负载。只有接口条件确实满足各自增益定义，或已经把加载计入端口模型时，相乘才正确。电声设备中的电端口还会通过换能机制连接机械和声学端口；电路等效模型不能省略这些耦合后继续解释所有声学行为。[15](#ref-ct-laplace)

### 互感与理想变压器

两个线圈的时变磁通可相互耦合。在线性互易模型中，若电压均从点端量向非点端、电流均流入点端，可写 $u_1=L_1\dot i_1+M\dot i_2$、$u_2=M\dot i_1+L_2\dot i_2$。改变一个绕组的参考方向会改变相应互感项符号；点标记说明相对极性，不表示能量流动方向。[16](#ref-ct-mutual)

该模型储能为 $(L_1i_1^2+L_2i_2^2+2Mi_1i_2)/2$；对被动磁储能，电感矩阵须半正定，因此 $|M|\le\sqrt{L_1L_2}$。这不是所有材料与工作状态下都恒定的参数关系，饱和和损耗需要扩展模型。

理想无损变压器以端口约束为模型：匝数比 $n=N_1/N_2$ 时，按相容的点端约定 $u_1=nu_2$、$i_1=-i_2/n$，故 $u_1i_1+u_2i_2=0$；接在次级的负载可反映为初级的 $n^2Z_L$。真实变压器还存在励磁电流、漏感、电阻和频率限制，不能仅用理想匝比描述。

## 交流功率与负载匹配

### 有功 无功和视在功率

采用前文RMS相量、关联参考，**复功率**为

$$
\underline S=\underline U\,\underline I^{\,*}=P+jQ,\qquad
P=U_{\mathrm{rms}}I_{\mathrm{rms}}\cos\varphi,\quad
Q=U_{\mathrm{rms}}I_{\mathrm{rms}}\sin\varphi.
$$

星号表示共轭，$\varphi=\arg U-\arg I$。$P$ 是平均有功功率，单位W；$Q$ 是无功功率，单位var；**视在功率** $|\underline S|=U_{\mathrm{rms}}I_{\mathrm{rms}}$，单位VA。在这个正弦稳态约定中，感性负载Q为正，容性为负。[17](#ref-ct-energy)[18](#ref-ct-power)

电压1 V RMS施加到指定负载 $32+j24$ Ω，电流为 $0.020-j0.015$ A，即25 mA RMS；有功20 mW、无功15 mvar、视在25 mVA，功率因数0.8。瞬时功率有时为负，表示储能返回，但平均仍吸收20 mW。若误把 $|\underline U|^2/|Z|$ 当有功功率，会得到25 mW而非20 mW。

对非正弦信号，平均有功仍由 $\langle ui\rangle$ 定义，RMS也仍有定义，但不能只用一个相角的余弦解释所有失真功率因数。耳机电阻上的耗散功率还不直接等于声功率或耳内声压；需要[电声换能器](../electroacoustic-transducer/)及耦合条件。[18](#ref-ct-power)

### 最大功率传输不等于所有音频接口的目标

对正源电阻 $R_{\mathrm{th}}$ 的直流戴维南源，纯电阻负载吸收 $P_L=V_{\mathrm{th}}^2R_L/(R_{\mathrm{th}}+R_L)^2$，在 $R_L=R_{\mathrm{th}}$ 时最大。对单频且实部为正的复源阻抗，在可自由选择复负载等条件下，最大有功传输对应共轭匹配 $Z_L=Z_{\mathrm{th}}^*$。[7](#ref-ct-linear)

这不表示电压型音频接口应处处阻抗相等。高输入阻抗通常可减轻电压加载，耳机放大器的低输出阻抗可减少负载阻抗变化造成的电压响应变化；代价、噪声、电流能力和稳定性也需要一起考虑。被动等阻匹配的源内阻与负载耗散相等，最大负载功率并非最大效率。不同用途应先说目标是电压传输、功率传输、噪声还是传输线反射。

## 运算放大器与反馈

### 理想运放和虚短的条件

**运算放大器**的简化开环关系为 $u_o=A(u_+-u_-)$。理想模型取开环增益无限、输入电流为零、输出电阻为零，但实际运放依赖电源供能，输出电压和电流有限。[19](#ref-ct-opamp)

在负反馈、闭环稳定且未超出线性工作范围等条件下，较大的开环增益使 $u_+\approx u_-$，称“虚短”；输入电流近似为零称“虚断”。虚短不是真正连接导线，两个输入端不会因此自动相互传送电流。开环比较、正反馈、饱和或高频增益不足时，不能直接使用虚短。

理想反相结构将输入经 $R_{\mathrm{in}}$ 接到反相端，输出经 $R_f$ 反馈到同一端，非反相端接参考地。虚短令反相端电位近似零，虚断使 $(u_{\mathrm{in}}-0)/R_{\mathrm{in}}=(0-u_o)/R_f$，因而信号增益为 $-R_f/R_{\mathrm{in}}$。同相结构把信号接非反相端，$R_f$ 从输出接反相端，$R_g$ 从反相端接地；反馈分压满足 $u_-=u_oR_g/(R_f+R_g)\approx u_{\mathrm{in}}$，得到增益 $1+R_f/R_g$。[20](#ref-ct-active)

### 有限增益 带宽和稳定性

对同相结构的理想反馈分压系数 $\beta$，闭环增益为 $A(s)/(1+\beta A(s))$。若采用单主极点 $A(s)=A_0/(1+s/\omega_p)$，则低频闭环增益为 $A_0/(1+\beta A_0)$，闭环极点为 $\omega_p(1+\beta A_0)$。这只是一种受限运放模型。[19](#ref-ct-opamp)

图8指定 $A_0=10^5$、主极点10 Hz、$\beta=0.1$，低频增益约9.999，闭环极点约100.01 kHz；增益带宽积近似1 MHz。一般电压反馈运放的带宽近似关系涉及**噪声增益**，反相电路的噪声增益为 $1+R_f/R_{\mathrm{in}}$，不等于其信号增益的绝对值。多极点、容性负载及其他反馈架构不能只靠这一乘积判断。[22](#ref-ct-ti-specs)

负反馈也不是无条件稳定：相移和环路增益可能导致振荡，需要检查实际闭环与反馈网络；正反馈还可用于比较器迟滞等非线性功能。用负反馈近似推导出的结果，不能直接搬到正反馈电路。[21](#ref-ct-feedback)

### 输出摆幅 压摆率与输入范围

**输出摆幅**是给定供电和负载下能达到的输出范围；**压摆率**SR限制输出随时间变化的最大速率。对正弦 $u_o=V_p\sin(2\pi ft)$，最大斜率为 $2\pi fV_p$。20 kHz、1 V峰值输出需要约0.1257 V/µs；小信号带宽足够并不保证大信号不会受SR限制。[22](#ref-ct-ti-specs)

图8右图只将10倍理想输出裁剪到人为设定的±2 V，说明静态限幅；没有模拟压摆率或真实器件恢复过程。实际还要检查输入共模范围、差分输入限制、偏置电流、失调、输出电流与负载稳定性。所谓“轨到轨”也应按数据手册条件理解，不能等同在任何负载下精确到达电源轨。

## 从电路计算走向可靠测量

### 麦克风电平和前置增益

**麦克风灵敏度**连接声压输入与电输出。模拟电压型灵敏度常以mV/Pa或相对于1 V/Pa的dB给出；数字麦克风则可能按dBFS及其规定信号定义报告，二者不能不经转换直接比较。[23](#ref-ct-mic)

例如，教学上指定灵敏度10 mV/Pa，1 Pa RMS的单频输入对应10 mV RMS开路输出；20倍理想前置增益会得到0.2 V RMS，但必须计入加载、频率响应、供电和峰值余量。若10 mV本来是峰值，就不能再把它直接当RMS使用。电路电平标度还需与声压级及[校准](../audiometric-calibration/)连接，增益增大不表示输入信噪比必然提高。

### 仪表输入阻抗和接地

电压表或探头并非完全不取电流，常可先建模为输入电阻与电容的并联。若被测源为开路电压 $V_s$ 串联 $R_s$，探头 $Z_p=1/(1/R_p+j\omega C_p)$，则测量端电压为 $V_sZ_p/(R_s+Z_p)$。[24](#ref-ct-probe)

图9指定 $R_s=10$ kΩ，对比 $1$ MΩ∥100 pF与10 MΩ∥10 pF两种教学负载。前者直流幅值比约0.9901，看似影响很小，但其电容带来的极点约160.75 kHz，高频幅值与相位会继续变化。探头的标称倍率或直流电阻不能单独描述这种影响。

测量回路还可能引入接地回路、引线电感和共模误差。常规接地示波器的参考夹通常与保护地相连，不能把它当作任意浮动端；应按仪器说明选用相应差分或隔离测量方式，不能靠移除保护地来实现浮地。这里讨论的是测量模型，不把数学参考地当成实际保护接地的替代。[24](#ref-ct-probe)

### 热噪声 谱密度与带宽

在经典热平衡模型和适用频率范围内，电阻R的开路**单边电压噪声功率谱密度**为 $S_v(f)=4k_BTR$，单位V²/Hz；幅度谱密度为 $\sqrt{4k_BTR}$，单位V/√Hz。$k_B=1.380649\times10^{-23}$ J/K，T为绝对温度。对平坦噪声与理想矩形带宽B，$u_{n,\mathrm{rms}}=\sqrt{4k_BTRB}$。[25](#ref-ct-noise)

指定R=10 kΩ、T=300 K，幅度谱密度约12.87 nV/√Hz；在20 kHz矩形噪声带宽内为约1.820 µV RMS。B是噪声积分带宽，不一定等于实际滤波器的−3 dB频率。若噪声源互不相关，叠加的是均方值或功率谱；有相关性时还需交叉项。

对归一化直流增益为1的一阶低通，**等效噪声带宽**为

$$
B_{\mathrm{eq}}=\int_0^\infty |H(j2\pi f)|^2\,df
=\frac{\pi}{2}f_c=\frac1{4RC}.
$$

在图10的理想RC中，仅计算该电阻热噪声经电容端传递的全频积分，得到 $\langle u_C^2\rangle=k_BT/C$。R=10 kΩ、C=10 nF时，等效带宽2500 Hz，噪声约0.6436 µV RMS。该关系依赖经典噪声、理想网络和积分模型；真实放大器还存在电压噪声、电流噪声、低频噪声及其他干扰，不能把它当全部系统噪声。[25](#ref-ct-noise)

## 可复算的例子与学习自检

### 节点解与功率守恒

下例仅需NumPy，复现图2；电阻使用Ω、电压使用V、电流使用A，右端0.0002 A为向B注入的电流。

```python
import numpy as np
G = np.array([[1/1000+1/2000+1/1000, -1/1000],
              [-1/1000, 1/1000+1/1000]])
VA, VB = np.linalg.solve(G, np.array([1/1000, .0002]))
i = np.array([(1-VA)/1000, VA/2000, (VA-VB)/1000, VB/1000])
loss = np.sum(i*i*np.array([1000., 2000., 1000., 1000.]))
supply = 1*i[0] + VB*.0002
print(VA, VB)           # 约0.55 V、0.375 V
print(loss, supply)     # 均约0.000525 W
assert np.isclose(loss, supply)
```

这里的电流源向B送入电流，因此它供出的功率按 $V_B\times0.2$ mA计入。若电流源方向反转，右端与源功率符号都需相应改变。

### 相量功率与时域积分

本例复现图7，比较复功率的实部与完整周期的瞬时功率平均。

```python
import numpy as np
U, Z = 1+0j, 32+24j       # U采用RMS相量
I = U/Z
S = U*np.conj(I)
f = 1000.
t = np.arange(10000)/(10000*f)  # 一个周期，不重复末端点
u = np.sqrt(2)*np.real(U*np.exp(2j*np.pi*f*t))
i = np.sqrt(2)*np.real(I*np.exp(2j*np.pi*f*t))
print(I, S, np.mean(u*i))       # 0.02-0.015j A；0.02+0.015j VA；0.02 W
assert np.isclose(np.mean(u*i), S.real)
```

将源相量幅值误设为峰值而仍使用RMS功率公式，会导致倍数错误；保留两种方法的对照有助于及时发现。

### 用微分方程检查RC阶跃

下例用SciPy的数值积分与解析解比较。时间轴用秒，初始电压为零；误差容限只针对这组指定模型。

```python
import numpy as np
from scipy.integrate import solve_ivp
R, C, Vs = 1e4, 1e-6, 1.
t = np.linspace(0, .05, 501)
sol = solve_ivp(lambda t, u: [(Vs-u[0])/(R*C)],
                [0, t[-1]], [0.], t_eval=t, rtol=1e-9, atol=1e-11)
assert sol.success
exact = Vs*(1-np.exp(-t/(R*C)))
error = np.max(np.abs(sol.y[0]-exact))
print("maximum error / V", error)
assert error < 1e-7
```
