TRY LISTENING DIFFERENTLY

三个小实验，重新认识声音。

01 / 谐波

哼一个长音，再慢慢升高。

观察一组同步弯曲的细线。相邻谐波的间隔通常与基频相关；最强谱峰不一定是基频。

02 / 声道

保持音高，说「啊—衣—乌」。

谐波的间距可能相近，明亮频带的位置却在改变。声道的共振，让相近的音高具有不同元音色彩。

03 / 时频取舍

拍一下手，再改变 FFT 点数。

短脉冲留下竖向纹理。增大 FFT 点数会增加窗时长，改善稳定频率的区分，也使短事件在时间上扩展。

这里的图像与数值，怎样理解？

分析采用 Web Audio AnalyserNode 的 Blackman 窗，频谱时间平滑系数为 0。FFT 点数同时决定窗内样本数；窗时长 = N / 实际采样率，频率栅格间距 = 实际采样率 / N，栅格间距不等于实际频率分辨能力。频率下限为 50 Hz，上限受奈奎斯特频率约束。

颜色为 Web Audio 归一化谱幅度的分贝标度，上限 −15 dB，下限由动态范围设置；不等同于 PSD 或校准声压级。数字峰值是当前时域样本的最大绝对幅度换算为 dBFS。最强谱峰是离散频点的最大值，不是音高或共振峰估计。

每次画面更新读取当前分析帧，横向位置由音频时钟确定；后台中断以空白显示。这里没有固定分析帧移，也不导出完整 STFT。切换分析或显示参数会清除旧历史，避免混合标度。合成元音仅为教学用谐波包络模型，不是真人录音。

音频在当前浏览器内分析，不会上传或自动保存。合成演示默认静音，可勾选「播放声音」；麦克风始终不回放。麦克风需要 HTTPS 或 localhost 及浏览器授权；请求关闭降噪、回声消除与自动增益，实际处理由设备决定。停止或离开页面会释放音轨。
